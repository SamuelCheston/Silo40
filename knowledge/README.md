## 事实来源

优先级为：当前代码与测试 → `references/` 项目源参考 → `events/README.md` → `docs/research/` 设计研究。发现冲突时以代码为准并修正文档。

本次以本地 `main` 合流后的代码为准，核对至 `e37237d`。重点排除了早期单堡 World v2、全行动平铺、单主体阈值结局和旧 v2 存档等过期描述。

## 维护约定

1. 修改世界构成、管线、行动门控、结局、API、存档或 RNG 行为时同步对应主题。
2. 不用旧 parity 或旧模拟分布证明新机制；KI 条目同时记录修复与受影响产物。
3. 未从代码或现有项目文档确认的内容标注“未核实”。
4. 生产门控、旧机制 fixture 和 LLM/Agent 控制模式必须分别说明，不能混写验证结论。
5. 命令与验证失败要如实记录，不通过跳过测试、删除断言或静默降级制造绿灯。
