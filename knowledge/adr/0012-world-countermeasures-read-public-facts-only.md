# ADR-0012 · 世界的反制只读公开事实、只产成本、藏在日常小动作里

| 状态 | 日期 | 依据 |
| --- | --- | --- |
| 已接受 | 2026-11-15 | [20 世界的反制设计](../../docs/research/20-world-countermeasures-design.md) §1/§3/§4/§5 |

## 背景与问题

玩家推动情报流通与组织逃跑时，地堡权力方需要真实的反应，否则推进玩法没有对手；但反制一旦读玩家私有状态、直接判负或弹窗告知，就同时破坏三条既定纪律——信息对称（10 §8.4：玩家 `B` 只决定行动与证据强度，反向不成立）、资格先于加权的仲裁结构（12 §2.2）、以及"玩家从日常里读出信号"的呈现口径（开局禁止廉价引导、失败线提示只报告已发生事实）。反制系统需要一个长期边界，防止后续批次在强度压力下逐条突破。

## 决策

- **反制的输入只允许是公开事实**：曝光 `E`、公开证据 `Q`、痕迹完成键计数、筹备与信道账本、部门戒备、部门信念层对"泄漏事实"的 `B/π`（"有人在传某件事"是部门可知的风声，不是玩家心里的确信）。任何反制判定不得读取玩家私有信念层、玩家 AP 或任何仅玩家可见的状态。
- **反制的效果只允许是成本**：AP 变贵、月份变长、信道变窄、关系变冷、动作暂时灰置（必须可恢复）、怀疑度按既有公式贡献增量。反制不得直接写结局资格、不得直接判负、不得永久锁定动作；通向失败结局的唯一通路是既有的怀疑度封顶硬护栏，反制只能贡献增量，不能设置封顶。
- **反制的呈现只走既有反馈通道**：月度故事、行动回执、门控灰置原因、数字面板、征兆聚合。禁止"你被发现了"类告知、禁止显示反制概率、禁止点名结局；反制事件文案只描述发生的事，不指认玩家为对象。
- **档位纪律**：反制分三档（指标恶化→链路掐断→个体被盯上），档位越高越要求归属到玩家个人行为的公开痕迹；低档反制只指向群体与信道，不归属玩家。反制不得跳档。
- **反制必须与测试重调同批落地**，判据同 [18 §7.2](../../docs/research/18-time-permeation-design.md) 与 [ADR-0011](./0011-opening-bias-needs-test-retuning.md)；反制参数过紧时修参数，不放宽测试、不白盒关闭反制。

## 被否掉的替代方案

- 单一"隐蔽值"总计量：不可读（玩家无法反推因果）、不可反制（没有应对面），且必然滑向"隐蔽值满→被抓"的直接判负形态。
- 反制直接判负或直接写资格：在仲裁之外新增投票主体，违反资格先于加权与"玩家是干涉者不是指挥者"（ADR-0010）。
- 弹窗或专属 UI 告知反制状态：摧毁"从日常里读出来"的乐趣，违反禁止廉价引导的既有口径；且告知本身成为玩家可刷的免费预警。
- 让宣传充当反制手段：既有裁决（`silo1_purge_exposed` 注释）——宣传是玩家的扩音器，不是权力方的反制器。

## 后果与代价

- 反制强度天然受限：不能靠"世界变聪明"解决推进玩法过易的问题，只能靠成本抬升；若推进玩法仍过易，应回到经济（17）与时间（18）旋钮，而不是松这条边界。
- 反制必须可被玩家反推：每个反制事件都要有公开事实来源，设计批次需逐条写明"玩家能从哪读出来"，写不出就不进内容。
- 怀疑度封顶是《除名》唯一通路：反制对怀疑度的全程净贡献受预算约束（20 分册 §6.2 起点 0.25），保证失败仍是玩家贪的选择后果。
- 与 [ADR-0011](./0011-opening-bias-needs-test-retuning.md) 同构：反制批次合并前必须交出测试账，缺账不得实装。
