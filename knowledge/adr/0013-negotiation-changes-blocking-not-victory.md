# ADR-0013 · 谈判/妥协只改变谁在阻碍谁，不产生胜利

| 状态 | 日期 | 依据 |
| --- | --- | --- |
| 已接受 | 2026-11-15 | 谈判层落地批次（feat/mayor-rebel-negotiation）；[18 谈判/妥协层设计](../../docs/research/21-negotiation-compromise-design.md) |

## 背景与问题

市长与叛乱方的谈判/妥协层补上了立场生产层的占位：市长面对叛乱有镇压、谈判、妥协三条路，谈判可持续通气，最后一刻妥协也成立。这一层的产出必须与既有结算纪律对齐——否则谈判会变成第二个胜负开关。

## 决策

- **谈判不产生胜利**：谈判/妥协的任何结果都不写结局资格、不发放胜利；最终结算仍只读逃出去多少人（承接 [ADR-0008](./0008-escape-gate-to-outcome-layer.md)）。
- **谈判只改变"谁在阻碍谁"**：产出写入顶层立场的权重输入（保障可信度、立场重估）与组织事实（接管/不接管），经容量、存活率、追踪自然结算为人数差异。
- **三方取舍都是带权重的随机决策**：市长（镇压/谈判/妥协）、叛乱方（接受/拒绝、姿态）、IT（不干涉/破坏/观望）各自独立裁量；权重可归因（相对实力、正统性、压力、既有承诺、性格/特质），每个决策点在谈判决策日志留下归一化权重与因子摘要。任何状态下每个档位保留裁量地板，不存在"叛乱 ≥ X → 必须妥协"的阈值锁死。
- **妥协须对方接受**：市长让步开出提案时，接受是叛乱方的带权决策；叛乱方递出条款时，市长让步即接受条款（提议方不否决自己的提案）。拒绝是合法结果。
- **妥协后叛乱方可不接管市长职位**：接管（委员会正统性改写、立场以新权重重估）或不接管（带组织能力转向逃跑/外溢）是玩家抉择；未选时结算不读加成。
- **单 RNG 纪律**：全部取样经引擎单一 RNG 流，月度回合内固定顺序（市长 → 叛乱方 → IT）；未开信道的运行不消耗任何新 RNG。

## 被否掉的替代方案

- 谈判结果直接授予《越岭》资格或结局：违反"结算只读逃出人数"，谈判变成胜负开关，与 ADR-0008 冲突。
- 一次性通牒交换（报价 → 立即表态）：抹掉持续磋商与拖延的演出空间，也与"市长不必立刻表态"的原型不符。
- 阈值触发妥协（叛乱达标 → 强制妥协）：人物决策退化成 if-else，失去自由裁量（承接 ADR-0007 的否定项）。

## 后果与代价

- 谈判层状态（`Silo.Negotiation`）永不进仲裁、永不进结局权重；今后不得把谈判事实接入任何资格判定。
- 信道崩塌（镇压打断/IT 曝光）与拖延都是合法结果：玩家侧反馈必须如实呈现，不得伪装成进展。
- 叛乱按月侵蚀市长正统性（接既有 `MayorLegitimacy`，ADR-0007 后果条）；该侵蚀是纯算术，不消耗 RNG。
- 接管不保证顶层配合：立场仍以带权取样重估，接管只改变权重。
