# ADR-0014 · 反制只抬成本与风险、不困死玩家；怀疑度只由组织行为驱动，不由囤积驱动

| 状态 | 日期 | 依据 |
| --- | --- | --- |
| 已接受 | 2026-11-15 | 移除 `escape_prep_audit_seizure` 与落地组织怀疑度响应层的提交（feat/escape-prep-suspicion）；[20 世界的反制设计](../../docs/research/20-world-countermeasures-design.md) 修订 |

## 背景与问题

筹备层原反制是审计没收（`prep_exposure ≥ 0.5` 且 IT 阻挠时没收已修服 −2，6 月冷却）。它造成反向梯度：准备得越重、暴露越高、被没收得越多，重准备反而更吃亏——与"准备是有价值的"这一逃离模型的基本盘直接冲突。同时它把"囤了多少物资"变成了惹眼的东西，而设计者要的口径是：准备本身不惹眼，惹眼的是组织行为。

## 决策

- **审计没收整体移除**：触发条件、内容条目、叙事一并删除；任何反制不得扣减囤积账本（防护服/补给/材料）与外溢信道。
- **反制只抬成本与风险，不困死玩家**：筹备层反制的全部后果是成本与风险的上浮（戒备、恐慌、safeguard 风险、日后更重的追踪），不直接判负、不没收、不永久锁定；玩家永远还有路走。safeguard 通道全程净贡献 ≤0.25，单独到不了硬护栏 1.0。
- **怀疑度只由组织行为驱动**：筹备层的组织怀疑度只由动员范围（演练、预案功能位、照护与生产组织）与通信频次规模（外溢信道、保障磋商）累积；囤积（修服/开库/划拨/囤备）永不抬高怀疑度。组织行为停了，怀疑度按月衰减（同淡忘口径）。
- **IT 的选择是带权随机，不是阈值 if-else**：怀疑度到门槛后 IT 必须三选一——镇压；不镇压但自己把 1 号蒙住（占 IT 资源、暴露风险随月上浮）；什么都不做（自由裁量，但承担后果）。权重因子可归因（残余力量/怀疑度深度/R_op 预算/safeguard 压力/保障可信度/IT 立场），决策日志留痕（归一化权重＋因子摘要）。随机源走引擎单一 RNG 流（ADR-0007/0013 同构）：未激活的运行不取样。
- **不镇压又蒙不住时，safeguard 风险上升**：后果落在"日后更贵、更窄"（出发追踪基数加重），不是当场判负。

## 被否掉的替代方案

- 保留没收、只调参数（降频率/改门槛）：反向梯度是结构性的——只要惩罚随准备量放大，重准备就吃亏；调参治不了。
- 让囤积也抬高怀疑度（"物资缺口显眼"）：把准备本身变成惹眼的东西，玩家被迫在"准备"与"不被注意"之间二选一，违背"准备有价值"的基本盘；惹眼的应当是组织行为。
- IT 响应用阈值 if-else（"怀疑度 ≥ X → 镇压"）：阈值抹掉裁量，玩家可精确卡线；与立场/谈判层的带权决策口径不一致（ADR-0007/0013）。
- 不镇压的后果当场判负（蒙不住 → 直接被 1 号清洗）：反制直接判负在仲裁之外新增投票主体，违反 ADR-0010/0012，也违反"不困死玩家"。

## 后果与代价

- 筹备期的对抗从"藏物资"转向"控制组织节奏"：玩家读的是组织怀疑度的风声（月度故事、戒备数字），应对是停下大动静让风声淡，或抢在响应前完成组织。
- 囤积的唯一代价是暴露记账（喂出发追踪）；若囤积玩法因此过强，应回到追踪与容量旋钮，不得复活没收。
- 新增一个受控 RNG 取样点（决策抽取与蒙蔽暴露抽取）：未产生组织怀疑度的运行逐位不变；parity 基线（无筹备动作）不受影响。
- IT 蒙蔽成为资源汇：弱势 IT（低 W、低 R_op）蒙不住大事，蒙蔽会自己崩塌——叙事同构于"弱势的权力方收手是自保"。
