# 项目概览与当前可玩范围

## 1. 项目定位

Silo40 是基于《羊毛战记》世界观的单机策略原型，技术栈为 Wails v2、Go、React/TypeScript、SQLite 和 goja。玩家不是地堡市长，也不是在经营 40 号，而是 **40 号派往外堡的特工**：通过情报、关系、秘密行动和有限的跨堡通道影响驻地历史。

普通桌面版是完整可跑的三堡模拟，不是早期单堡 World 骨架。所有规则在 Go 后端与其托管的 JS 内容层执行，前端只提交意图并渲染快照。

## 2. 普通开局的真实世界

| 内部 ID | 实体 | 玩家关系与能力 |
| ---: | --- | --- |
| 1 | 从 2–17 号按 seed 确定的驻地 | 玩家实际所在地；普通行动、职业行动和驻地 operation 都作用于它 |
| 2 | 完整模拟的 Silo 1 | 有独立 AI、月度结算和 Archives 部门；仅开放情报与欺骗通道 |
| 3 | 带正典链条的 Silo 18 | 只可观察；N1–N9 按绝对时间强制生效，玩家不能干预 |

驻地编号由 `seed ^ 0x40a17` 的独立随机流派生，不消耗 gameplay RNG。`World.PlayerSiloID`、`Agent.SiloID` 和 `Agent.StationSiloID` 均指向驻地。

**40 号不创建 Silo 实体**：没有人口、部门、派系、楼层或 tick，只是叙事中的派出方。普通 API 请求应同时设置 `include_silo1=true` 和非空 `neighbor`，才能得到上述三堡；测试仍保留较少实体的兼容场景。

## 3. 一局当前怎么玩

1. 输入姓名，选择部门与特质；首次试玩可选 IT 以获得更细的外部情报档位。
2. 开局只有本职业 2 个碎片和 Gather Info。成功执行后，完成节点把阶段从 `arrival` 推到 `first_signal`。
3. 使用 Share Info、Build Connection 等逐步出现的行动；成功 Share Info 后进入 `archive_awakened`。
4. 根据关系、威望、宣传和阶段条件使用职业行动、驻地 operation 与 Silo 1 限定通道。
5. 管理 AP、怀疑度、两条通道的 Exposure 和反间谍阶段，观察世界事件与派系变化，直至硬失败或历史分流结局。

行动门控不是纯 UI 隐藏：未解锁行动不下发；已解锁但条件不足的行动以灰项和原因下发；服务端两条执行入口都会再次拒绝无效请求。只推进月份不会代替成功行动推进这两个剧情阶段。

## 4. 已实现的主要系统

- **三堡月度世界**：固定堡序、本地结算、跨堡信号、Silo 1 状态、正典节点与玩家 operation 的统一编排。
- **信息与人际**：碎片搜集/分享、真假信息、人脉、威望、宣传、怀疑度和职业行动。
- **人口与派系**：cohort 思潮、关键 Resident、距离聚类、派系持久 ID/Stance/Memory/Demands。
- **秘密 operation**：驻地情报/策反/欺骗/黑市，Silo 1 情报/欺骗；AP 成本、1–2 月延迟、目标实测 delta、Exposure 和反间谍。
- **多实体结局**：硬失败护栏，加上玩家、驻地派系、关键人物和 Silo 1 共同贡献的 INFORMATION/TIME/REBELLION/EXCLUSIONIST 加权仲裁。
- **历史引导附加分**：按已结算 operation 的目标 before/after 实测变化计分，不把自然演化或正典覆写冒充玩家贡献。
- **存档**：v7 单槽存档，保存三堡、阶段、永久解锁、operation、历史影响和仲裁记录。
- **外部操作员**：`/debug/agent/*` 让 AI 在 NPC 决策点真实选择并导出样本；`cmd/agenthost` 提供无 GUI 宿主。
- **可选 LLM 顾问**：默认关闭，支持 shadow/on 和决策日志回放，不是 Agent 操作员模式的替代品。

## 5. 目前仍属于原型的地方

- 行动门控只有窄开局和少量解锁示例，不是完整剧情行动树。
- 加权结局的所有权重、系数和最低阈值均为 `TODO(balance)` 占位；没有结局分布或平衡验收。
- operation 是固定效果通道，不能组成任意目标、长期渗透网络；Silo 1 的 Archives 尚无专属行动树。
- Silo 18 是正典观察对象，不提供自由分支人物模拟；40 号没有返回、调任或经营玩法。
- 只有单活跃存档槽，没有存档管理器；pending operation 未完成时不能手动保存。
- 试玩产物目标是 Linux amd64 + GTK3/WebKitGTK 4.1；Windows/macOS 包与多桌面视觉走查不属于当前交付。
- 大规模 Agent 采样仍未开放；当前接口与 smoke 链路不等于训练数据已定型。
