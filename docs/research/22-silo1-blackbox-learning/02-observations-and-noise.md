# 黑箱里的博弈 · 轨道 B：观测量与噪声

> 本文档由 AI 维护（project-source）。本轮只做设计，不改代码、配置、事件或数值。
>
> 所属专题：22-silo1-blackbox-learning（1 号地堡如何在看不见 Θ 的前提下与各堡博弈）。
> 轨道 B 职责：定义 1 号能拿到什么观测量、每个观测量的延迟/噪声/伪装模型与似然函数，并定量论证「为什么试不出来」。Θ 的动态方程与 E(r, Θ) 曲面形状由轨道 A 定稿；本文引用的时间常数均为占位假设，**最终以轨道 A 参数表为准**。

## 0. 前提、符号与口径

### 0.1 裁决前提（严格遵守）

1. 旧模型「风险度→执行强度是静态单峰曲线，1 号靠试探找峰」已作废：AI 对 AI 几回合就能试出静态峰，难度失真。
2. 每堡维护一个 0–1 隐藏量 `Θ_s(t)`：0=完全按 Order 办事，1=公开叫板，中段=消极、拖延、阳奉阴违。
3. `Θ` 不是 safeguard 风险 `r` 的比例函数；`r` 只决定 `Θ` 的增长速度（`r` 越高涨越快；`r` 处正常水平时 `Θ` 向 0 回落）。`Θ` 有月级以上的时间常数。
4. 执行强度 `E` 对 `r` 仍是单峰（中段死心塌地、两端不干活），但峰位/峰高/峰宽由 `Θ` 间接决定。
5. 1 号不能读心，只能靠**延迟、带噪声、可能被人为伪装**的信号估计 `Θ`。
6. 世界观口径：各堡专线另一头在 IT 主任眼中只是「一套叫 Order 的系统」；**下面的人不一定知道 1 号地堡的存在，他们表面服从的对象只是 Order 本身**。这直接约束伪装模型（§4）：本地 IT 的伪装对象在低认知阶段是「Order 这套系统」，不是「1 号那些人」。

### 0.2 统一符号（四轨道共用）

| 符号 | 定义 |
| --- | --- |
| `r_s(t) ∈ [0,1]` | 1 号月 t 给堡 s 指派的 safeguard 风险度 |
| `Θ_s(t) ∈ [0,1]` | 堡 s 的隐藏立场量（1 号不可直接读） |

| `R_op` | 本地 IT 操作资源（10 号研究 05 §5.2：初始 60，+8/月，上限 100） |

### 0.4 分箱约定

权威表示：1 号后验信念存储为 **N=20 等宽箱**（[01 卷 §5.1](01-dynamics-and-pseudocode.md)）；面向策略与叙事的语义档为 **B0–B4 五档**（[03 卷 §2.1](03-exploration-and-cost.md)、[00 卷 §2.1](00-index.md)）。本卷 §3.7 与 §5 的定量论证另用等宽**四档粗箱**（箱宽 Δ=0.25）作粗化分辨率标尺，不是权威分档：

| 箱 | Θ 区间 | 语义 |
| --- | --- | --- |
| B0 | [0, 0.25) | 照办：按 Order 办事 |
| B1 | [0.25, 0.5) | 消极：拖延、打折、选择性执行 |
| B2 | [0.5, 0.75) | 阳奉阴违：表面合规、系统性伪装 |
| B3 | [0.75, 1] | 摊牌边缘：公开叫板或蓄谋摊牌 |

「把 Θ 分辨到相邻箱」= 后验质量足以以 ≥0.7 概率区分相邻两箱（判据阈值 `TODO(balance)`）。

### 0.5 确定性纪律

- 所有观测噪声抽样、伪装失控/暴露骰只走**单一引擎 RNG 流**，抽样位置固定在月度顺序的「Silo 1 裁决」相位与各堡本地相位内，逐堡按 SiloID 升序、逐观测量按固定 ID 序（knowledge/08-determinism-known-issues.md §2/§7）。
- 现状中「情报观察不消耗 RNG」（knowledge/08 §1，对应 `captureSilo1Signals`）指的是**玩家侧**观察产品；1 号侧带噪声观测需要抽样，必须显式声明抽样点，不得新增私有随机源。
- 伪装决策本身是确定性的（给定状态与 RNG 流），见 §4.4。

## 3. 似然函数

记堡 s 在月 t 的观测向量为 `y_s(t)`；1 号的信念更新为 `b_s ∝ P(y | Θ, r) · b_s`（逐观测量独立相乘，伪装相关性在 §4.5 单独修正）。所有参数 `TODO(balance)`，下表给出 sim 起点。

### 3.1 (a) 稽查成果：带灵敏度/特异度的二项检测

1 号以强度 `n`（抽样条目数）发起稽查，`δ_a=2` 月后收到成果报告。

- 真实问题存量：`D(Θ, r) = d0 + d1·Θ^γ + d_r·r`。`d_r·r` 项表示**高 r 本身制造更多表面问题**（人人自危时违规痕迹与互相指控增多）——稽查成果因此同时受 Θ 与 r 驱动，不可单独归因。起点 `d0=0.05, d1=0.5, γ=1.5, d_r=0.15`。
- 检出：每个真实问题以概率 `se = se0·(1-φ)` 被查出，`se0=0.5`。伪装强度 φ 直接吃掉灵敏度。
- 伪造：本地注入 `F = round(φ·q_f·n)` 条伪造「成果/整改成绩」，每条以概率 `1-sp` 蒙混过关，`sp = sp0 - φ·Δsp`，起点 `sp0=0.9, Δsp=0.3, q_f=0.3`。
- 观测似然（查出 k 条）：

```text
k | Θ, r, φ ~ Binomial(n·D(Θ,r), se) + Binomial(F, 1-sp)
P(k | Θ, r) = Σ_f  P(F=f | φ) · Binom(k-f; n·D, se) · Binom(f; F, 1-sp)
```

- 耦合成本：每次稽查使目标堡反认知 `k_s,m += κ_probe`（`references/silo1-control-design.md` §2.2 `I_s,m = o_s,m·(1-ρ_m·k_s,m)`）——**观察侵蚀观察所依赖的信息优势**，κ_probe `TODO(balance)`，起点 0.05。

### 3.2 (b) 举报计数：泊松混合（真实暴露 + 表面举报）

月 t 玩家动作的暴露总量 `V_t = Σ_a v_a`（各动作固有暴露，如 `silo1_operations.go` 的 `OpeningSuspicion` 量级）。

```text
M | Θ, r ~ Poisson(λ),  λ = λ_true + λ_fear
λ_true = β·V_t·(1-φ)·(1-κ_c·Θ)      // 真实暴露举报，被本地掩盖
λ_fear = λ_f·r^η                     // 高 r 制造的表面举报（恐惧+投机）
```

起点 `β=0.6, κ_c=0.6, λ_f=0.8, η=2`。

- **r 的双重作用**：r 既出现在 λ_fear（表面举报随 r 超线性上升），又通过 Θ 的动态间接压低 λ_true（高 r 推高 Θ → 掩盖加强）。1 号看到举报变多时，无法区分「我盯得紧」与「问题真的多」——符号含糊是结构性的。
- 延迟 `δ_b=1`。伪装项：`suppress_signal`（`it_authority.go` L75，现有动作）直接作用于 λ_true 的 `(1-φ)` 因子；`quiet_disappearance` 把潜在举报人移除（建模为对 β 的一次性削减，`TODO(balance)`）。

### 3.3 (c) 执行反馈：二项完成数 + 虚报完成

1 号（经 Order）月 t 向堡 s 下发 c 条例行指令；真完成数由执行强度 `E_s(t)`（轨道 A 的 `E(r, Θ)` 曲面）决定：

```text
d      ~ Binomial(c, E_s(t))                    // 真实完成
d_obs  = d + Binomial(c-d, φ·q_fc)              // 未完成项以 φ·q_fc 概率被虚报完成
P(d_obs | Θ, r) = Σ_d Binom(d; c, E) · Binom(d_obs-d; c-d, φ·q_fc)
```

起点 `q_fc=0.6`，`δ_c=1`。

- 偏置方向恒向上：`E[d_obs/c] = E + (1-E)·φ·q_fc ≥ E`。高伪装下观测退化为「全部完成」，观测量信息量趋零——**阳奉阴违的定义就是这条似然的形状**。
- 「选择性执行」（10 号研究 05 §5.3「延迟与选择性执行」动作，`it_authority.go` L62 `delay_enforcement`）在本似然中表现为：被选择执行的那部分 `E` 局部偏高、其余偏低，方差增大；若 1 号能按指令类别分读（成本更高），可部分识别，`TODO(balance)`。
- 载体缺口：例行指令机制本身不存在（§6 G3），c 与 E 的区分度设计待实现轨。

### 3.4 (d) 人口与外流：高斯普查 + 隐匿项

每 `δ_d=3` 月一次普查报告：

```text
P̂ = P_true·(1+ε) + H,   ε ~ N(0, σ_c²),  σ_c=0.03
H = φ·q_h·(P_true - P_reported_base)           // 隐匿的外流人口
```

- 真值锚点：逃出结算减人口（`escape_settlement.go` L221）；外溢信道使用（`it_line`）在设计上「喂 1 号异常观察」（16 §2.3），实现缺位（§6 G9）——本似然暂以普查为唯一正式通道。
- 替代信号（非正式、事件驱动）：大规模逃出属危机类事件，可经 `perception.go` 的传闻通道以「听到的版本」外传（`neighborNewsworthy` 放行 crisis）；1 号听到的是被改写、被合并、延迟不定的版本——建模为低到达率 `p_rumor` 的伯努利提示，`TODO(balance)`。
- 伪装：伪造普查走 `forge_records` 能力（§4）；IT 配合压本地监控已有口径（`escape_outside.go` L125-130 `escapeCooperateTrackingFactor`），复用其语义：本地监控被压时只剩 1 号侧注意力。

### 3.5 (e) 通牒执行反馈：阈值判读 + 档位翻转

通牒后第 `δ_e∈{1,2}` 月读 `OrderPressure`（`content_events.go` L93-104）的分档变化：

```text
P(band' | band, Θ, r) = (1-p_flip)·1[band'(pressure_true)] + p_flip·Uniform(adjacent bands)
p_flip = p0 + p_φ·φ,  起点 p0=0.1, p_φ=0.2
```

- 反应链前兆（`strike_reconnaissance.js` 等，阶梯 `months_since_event_gte`）是 1 号**自己发出的信号的回波**：前兆停住=压力回落的间接证据。确定性触发、无 RNG，适合做判据锚点。
- 伪装：通牒后短期表面服从（Θ 不变、E 暂时抬高）——建模为 `E` 的一次性脉冲 `+ΔE_show`（持续 1–2 月，`TODO(balance)`），使该观测量在通牒刚结束时系统性偏乐观。

### 3.6 (f) 专线信号质量（首版放弃，留设计占位）

```text
心跳丢失 ~ Bernoulli(q0 + q_Θ·Θ + q_j·1[network_jammed]),  起点 q0=0.02, q_Θ=0.1
```

首版不实现（§6 G6）：现有代码只有 `network_jammed` 世界 flag，逐堡心跳无载体。

### 3.7 (g) 稳定报告：分档翻转噪声

月度稳定报告读 `Rebellion`/`OrderPressure` 的分档（复用 `rebellionBand` 阈值 0.3/0.6）：

```text
P(band_obs | band_true) = 1-p_flip (同档) ，p_flip 均分给相邻档
p_flip = p_g0 + p_gφ·φ,  起点 p_g0=0.15, p_gφ=0.25
```

**结构性弱点（关键设计事实）**：Θ→Rebellion 的映射非单调。消极/阳奉阴违（Θ∈[0.25,0.75)）不产生公开动荡——叛乱值可以全程很低。定性映射表：

| Θ 箱 | 公开叛乱期望 | 稳定报告的信息量 |
| --- | --- | --- |
| B0 照办 | 低 | 与 B1 几乎不可分 |
| B1 消极 | 低（不公开闹） | 近零——这是最危险的盲区 |
| B2 阳奉阴违 | 低（表面维稳） | 近零，且本地主动压低上报 |
| B3 摊牌边缘 | 可能高（摊牌）也可能低（蓄谋期） | 有信号但歧义 |

由此：**现状 `Attention=Rebellion` 直读（`world.go` L409-412）看似全知，实际恰好对中段的 Θ 失明**——它读的量正是中段 Θ 刻意保持为零的量。这是新模型相对旧状态机的核心玩法增量。

### 3.8 哪些观测量同时受 r 影响（汇总）

| 观测量 | r 的直接污染 | 后果 |
| --- | --- | --- |
| (a) 稽查成果 | `d_r·r` 表面问题项；稽查频率本身随 r 分配 | 高 r 堡「查出更多」≠「问题更多」 |
| (b) 举报计数 | `λ_f·r^η` 表面举报，超线性 | 举报上升的符号含糊（§3.2） |
| (c) 执行反馈 | `E(r,Θ)` 本身是 r 的函数（单峰） | 这是信号也是干扰：峰形即 r 响应 |
| (d) 人口外流 | 弱：高 r 推高出逃动机（经 Θ） | 间接、慢 |
| (e) 通牒反馈 | 通牒本身是 r 的极端形式 | 测量即干预（§5.3） |
| (g) 稳定报告 | 高 r 推恐慌（`safeguard_protocol_warming.js`：safeguard_risk≥0.6 时全部门恐慌 +0.03 即为实例） | 恐慌读数被自己的政策污染 |

## 4. 伪装模型

### 4.1 动机：Θ 的函数，中段最强

伪装动机 `M(Θ)` 在**中段阳奉阴违阶段最强**——既要保存自己（不被 Order 介入），又要应付上面（让报告好看），还要掩护底下的消极。低 Θ 无可伪装（真照办），高 Θ 接近摊牌。

```text
M(Θ) = 4·Θ·(1-Θ)        // 峰值在 Θ=0.5，M=1；M(0.1)=M(0.9)=0.36
```

**高 Θ 的设计选择**：`M(0.9)=0.36` 而非 0——高 Θ 仍保留相当伪装（蓄谋期），理由：

1. 设定一致性：摊牌是 Θ→1 的终点动作；在摊牌前，逃出筹备、外溢、反制都需要表面平静（16/20 号研究的筹备线全部依赖「不被提前发现」）。
2. 博弈完整性：若高 Θ 完全摊牌（M→0），1 号的估计在终局阶段平凡收敛，黑箱在最后阶段消失，玩法张力断裂。
3. 认知口径：下面的人未必知道 1 号存在——高 Θ 堡的「伪装」很多时候不是对 1 号演戏，而是对「Order 这套系统」演戏，摊牌对象甚至是模糊的。

备选方案（未采纳）：高 Θ→公开叫板、伪装归零。未采纳原因即上述 2/3；若轨道 A 的 E 曲面需要「高 Θ 两端不干活且完全可见」，可在 Θ>0.9 区间把 M 截断到 0.1，参数留 `TODO(balance)`。

### 4.2 认知门槛：不知道向谁伪装，只能惯性伪装

按认知梯度 `G`（10 号研究 07 §6.4）分层：

| G 区间 | 认知 | 伪装形态 |
| --- | --- | --- |
| <0.10 | 不知道上层控制方存在 | 只有**惯性官僚伪装**（基线 φ0，对「流程」演戏），无针对性 |
| 0.10–0.35 | 察觉 Protocol 有隐藏编写者 | 开始对「报告对象」有意识，φ 小幅上升 |
| ≥0.35 | 推断存在跨堡处置网络 | **针对性伪装解锁**：知道观察存在、开始猜观察内容 |
| ≥0.65 | 理解任命/培训与来源关系 | 可实施高精度伪装（知道哪些指标被读） |

```text
φ = φ0 + M(Θ)·C(G, R_op),   φ0=0.1（惯性基线，TODO(balance)）
```

### 4.3 能力：挂现有量（R_op 与 G）

伪装不是新资源池，直接挂本地 IT 的既有预算与动作骨架（`it_authority.go`）：

- **资源**：伪装动作消耗 `R_op`（+8/月、上限 100、成本随 W 上升，`ItCostCurve`）。伪装与本地自保（维护忠诚、反击玩家）**竞争同一预算**——1 号持续施压会迫使本地 IT 在「伪装给上面看」与「镇压/自保」之间分配资源，这是可被 1 号间接读出的资源消耗信号（10 号研究 05 §5.5 末段「玩家可从资源消耗、法警调度与后果读出它在保护谁」的同构推论）。
- **动作映射**（现有目录 → 伪装功能位）：

| 现有动作（`it_authority.go` L57-77） | 伪装功能位 | 扭曲的观测量 |
| --- | --- | --- |
| `forge_records`（成本 7） | 伪造普查/档案/成果 | (a) 特异度、(d) 隐匿项 |
| `suppress_signal`（成本 8） | 压举报、压异常信号 | (b) λ_true、(g) 翻转率 |
| `control_information`（成本 6） | 压传播、维稳数字 | (g)、(e) 表面服从脉冲 |
| `delay_enforcement`（成本 7） | 选择性执行本身 | (c) 方差结构 |
| `quiet_disappearance`（成本 12） | 移除举报人/目击者 | (b) β 削减 |

- **能力门槛**：`C(G,R_op) = 1[G≥0.35]·clamp(R_op/R_opMax, 0, 1)^0.5`（`TODO(balance)`）。G 不足时 φ 只剩 φ0；R_op 枯竭时伪装衰减——与「反击随资源枯竭衰减」（05 §5.5）同口径，保证高压下本地 IT 不会永远完美伪装。

### 4.4 确定性：伪装是现有 IT 权威回合的候选扩展

- 伪装动作作为新候选类进入 `ItActionCatalog` 的 utility 选择（设计层面；实现归实现轨）：选择规则沿用现状——`utility>0` 最高分、同分按 action ID 升序（`it_authority.go` L220-248），**决策本身无随机**。
- 随机只出现在既有模式的两个位置：失控骰（`LossOfControlProb`，L320-324）与暴露骰（`exposeJudicialDispatch` 型，L333-350）。伪装动作的失控 = 伪装穿帮（生成可被 1 号捕捉的一次性破绽事件，走 `perception.go` 危机/一次性转折通道）。
- 抽样位置：各堡本地相位、Protocol 结算之后（与 `RunITAuthorityMonthly` 现位置一致），逐堡 SiloID 升序——满足 knowledge/08 §2 的固定顺序与 §7 的纪律（不新增私有随机源、不影响既有消费位点；新增消费位点需重建 parity 基线）。

### 4.5 伪装对各观测量似然的扭曲（汇总）

| 观测量 | φ 进入似然的位置 | 扭曲方向 |
| --- | --- | --- |
| (a) 稽查 | `se=se0(1-φ)`、伪造数 `F∝φ` | 查出变少 + 假成果变多，双向拉向「合规」 |
| (b) 举报 | `λ_true∝(1-φ)` | 真实举报被压；表面举报不受 φ 控制（r 驱动）→ 噪声占比上升 |
| (c) 执行 | 虚报率 `φ·q_fc` | 完成率系统性虚高 |
| (d) 人口 | 隐匿项 `H∝φ` | 外流被藏进普查误差 |
| (e) 通牒反馈 | `p_flip` 升 + 表面服从脉冲 | 通牒后短期偏乐观 |
| (g) 稳定报告 | `p_flip` 升 | 分档读数向「安定」漂移 |

**相关性修正**：φ 是各观测量共享的隐变量——同月多观测量的噪声**不正独立**（本地一次性决定伪装强度，各通道同步失真）。1 号信念更新时对同月观测量按公共 φ 边缘化：`P(y_a,y_b,... | Θ,r) = Σ_φ P(φ|Θ)·Π_x P(y_x | Θ,r,φ)`，而不是逐观测量独立相乘。`P(φ|Θ)` 由 §4.1–4.3 确定性给出（φ 是 Θ、G、R_op 的函数，无额外随机），故该边缘化是有限和。

## 5. 「为什么试不出来」：定量论证

用 §0.3 时间常数、§2 的 δ 与 §3/§4 的噪声/伪装参数做简化估算。参数均为起点值（`TODO(balance)`），结论对参数在合理区间内扰动稳健。

### 5.0 参数汇总（本节使用）

| 参数 | 起点值 | 来源 |
| --- | --- | --- |
| 满压增速 ḡ（r=1，低 Θ 处） | 0.02/月（30 个月到危险区 0.60） | §0.3 定稿，`TODO(balance)` |
| 常态回落速率（r ≤ r_calm） | ≈1/48≈0.021/月（τ_decay=48 月） | §0.3 定稿，同上 |
| 综合观测延迟 δ | ≈2 月（(a)2/(b)1/(c)1/(d)3/(g)1 的典型值） | §2 |
| 单月综合噪声 σ_eff | ≈0.20（Θ 尺度） | §3 各噪声合成后的保守取值，`TODO(balance)` |
| 伪装系统偏置上限 b_max | ≈0.2（中段 φ≈1 时） | §4.5 |
| 箱宽 Δ | 0.25（粗分辨）/ 0.1（找峰所需细分辨） | §0.4 |

### 5.1 论证一：估计器持续滞后（噪声 + 延迟 vs 漂移）

把噪声平均到 ε 所需有效观测月数 `N ≈ (σ_eff/ε)²`，总滞后 `L = δ + N`。

- **粗分辨（ε=Δ/2=0.125）**：`N ≈ (0.20/0.125)² ≈ 2.6 → 3 月`，`L ≈ 5 月`。
  期间漂移：1 号要维持信号强度就得保持 `r≥0.6`，漂移 `≈ 0.6×0.02×5 ≈ 0.06 ≈ 0.25Δ`；若以 `r=1` 施压，`≈0.10 ≈ 0.4Δ`。
  → 即使只分到四个粗箱，估计也**总是滞后四分之一到半个箱**；1 号的每个反应决策都基于 5 个月前的 Θ。
- **细分辨（ε=0.05，即 Δ=0.1）**：`N ≈ (0.20/0.05)² = 16 月`，`L ≈ 18 月`。
  期间漂移（r=0.6）`≈ 0.02×0.6×18 ≈ 0.22 ≈ 2.2Δ`。
  → 细分辨在动态上不可能：等估计收敛，Θ 已经走过两个多箱。

### 5.2 论证二：伪装偏置不随平均消失

§4.5 的扭曲是**系统性偏置**（虚报完成、隐匿外流、压举报），不是零均值噪声：

- 中段（φ≈1）偏置 `|b| ≈ 0.15–0.25 ≥ Δ/2`。
- 偏置与样本量无关：`N→∞` 时后验收敛到**错的箱**（「合规剪影」），不是收敛到真值。
- 唯一打破偏置的办法是改变 r 观察响应差（差分法）——这正好落入论证三。

### 5.3 论证三：测量即破坏（试探棘轮）

差分法要求把 r 抬上去制造对比，而抬 r 本身就是 Θ 的增长输入：

1. **单个对比点的代价**：一次有效对比需要在目标 r 上停留 `T ≥ δ + N ≈ 5 月`；满压相位每月推高 Θ ≈0.02 → **一个对比点移动目标 ≈0.1，即半个粗箱**。
2. **曲线不存在**：测 `E(r)` 单峰至少需要 3 个对比点（峰左/峰顶/峰右），累计推高 `≈0.3`；而峰位 `r*(Θ)` 由 Θ 决定（前提 4），Θ 变 0.3 时峰位已移动——**测到的点是不同 Θ 的拼接，静态单峰在测量过程中就不存在**。这正是旧模型（静态峰可试探）作废的定量版本。
3. **棘轮不对称**：增速（满压 0.02/月）与回落速率（常态 ≈1/48≈0.021/月）同量级，但回落只在低 r 时发生。试探 5 个月造成的 +0.1，需要约 5 个月常态才能回落——而常态月信号弱（§5.4），等于花等长时间既无信息又刚回本。**任何占空比不低的试探策略都单调推高 Θ：测量动作生产它所害怕的东西。**
4. **混淆同时污染差分**：抬 r 期间表面举报 `λ_f·r^η`（§3.2）与表面问题 `d_r·r`（§3.1）同步上升——差分信号里混进了「恐惧噪声」，差分本身也不干净。

### 5.4 补充：低 r 也无出路

若 1 号改为保持低 r 以免推高 Θ：低 r 处各观测量信息量塌缩——(a) 稽查动机与频率低、(b) 表面举报项趋零但真实举报也被低关注度稀释、(c) E 在低 r 端本就「不干活」（前提 4 的单峰左端），执行读数分不清「照办但能力差」与「消极」。(g) 稳定报告对中段 Θ 恒为低档（§3.7 盲区表）。→ 低 r 策略不移动目标，但**每月获得的信息量趋近于零**，N 发散，滞后发散。

**结论**：高 r → 目标移动（漂移 ≥ 分辨需求）；低 r → 信号消失（信息率趋零）；中间 r 是两者的折中，而折中点仍然满足「滞后 L 内的漂移 ≥ 半个目标分辨率」。任何估计器都持续滞后，且被测量动作本身移动被测对象。1 号的理性策略退化为两种：(i) 保守先验 + 粗箱 + 接受滞后；(ii) 不做精细估计、直接按粗阈值威慑——后者正是现有通牒状态机（`OrderPressure≥0.45`，`world.go` L428-445）的形状。**黑箱估计层与粗阈值状态机是互补的两层，不是替代关系**：制度硬规则（Protocol/通牒）管粗阈值，行为估计管粗箱先验下的反应调节。

## 7. 跨轨道接口与遗留问题

### 7.1 对轨道 A（形式化）

- 本文消费轨道 A 的 `E(r, Θ)` 曲面（§3.3/§5.3）与 Θ 动态（§0.3）；时间常数已定稿（g_max=0.02/月、τ_decay=48 月，§0.3），§5 算式按定稿值成立，结论结构不变。
- 本文产出给轨道 A 的输入：观测延迟向量 δ、噪声 σ_eff、伪装偏置上限 b_max（§5.0 表）——轨道 A 定义 1 号策略空间时需要这些作为感知约束。

### 7.2 对控制力设计（references/silo1-control-design.md）

- §2.3 的 `o_s,m`（可操作观察质量）的输入来源由本文 §2/§3 具体化：`o_s,m` 应聚合本文 (a)–(g) 观测量的后验质量，而不是读真值。
- §2.2 的 `I_s,m = o_s,m·(1-ρ_m·k_s,m)` 与本文 §3.1 的 `κ_probe` 耦合：主动观测推高目标反认知 `k_s,m`，自我侵蚀信息优势。建议 `κ_probe` 按渠道分设（稽查类探测对 `reset`/`safeguard_toxin` 渠道的 ρ 敏感度不同），`TODO(balance)`。

### 7.3 遗留问题与主线裁决结果

1. **G8 双轨关系**：已裁决（[00 卷裁决 4](00-index.md)）——真值审判保留；伪装可延迟其触发时机、不能消除未达成事实（沿用 10 号研究 06 §6.2 口径）。
2. **玩家堡特殊性**：已裁决（00 卷裁决 5）——功能开启时 `STATION_INTEL` 类精确读数改为分档+噪声读数，成本/暴露不变，功能开关门控。
3. **伪装的玩家可见性**：本地 IT 伪装动作（§4.3 映射）的玩家呈现按 [04 卷 §3.b 伪装的可见破绽](04-naming-log-and-readability.md) 口径执行（只陈述已发生事实、不解释原因）；15/17 号信息经济的细节本文不展开。
4. **观测抽签的 parity 影响**：已裁决（00 卷裁决 3）——采用门控 RNG；功能关闭零消耗、parity 逐位不变；功能开启时 v8 parity 基线按 knowledge/08 §5 口径重建——实现轨职责，此处只登记。
