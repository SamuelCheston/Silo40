# 22-01 · 黑箱里的博弈：隐藏量动力学、执行强度单峰与 1 号估计/决策伪代码

> 性质：**机制形式化卷**（轨道 A，「黑箱里的博弈」四轨道系列第 01 卷）。只写规格，不含代码改动；数值一律 `TODO(balance)` 推荐初值。隐藏量最终命名由轨道 D 决定，本卷公式一律用 `Θ`。
>
> 前提裁决：旧模型「风险度 → IT 执行强度是一条静态单峰曲线，1 号靠试探找峰」**已作废**。理由：AI 对 AI 的循环比玩家快得多，几回合就能把静态峰试出来，难度失真。新模型：每堡维护一个 0–1 隐藏量 `Θ`，它**不是** safeguard 风险的比例函数——风险只决定它的**增长速度**（风险越高涨得越快；风险处于正常水平时向 0 **回落**）；执行强度对风险度仍是单峰形态（中段死心塌地、两端都不干活），但**峰位、峰高、峰宽随 `Θ` 移动**，不再是可读的静态参数；`Θ` 有明显的时间常数（月级、多季度到年级），1 号只能靠延迟、带噪声、且可能被底下人伪装的信号估计它。
>
> 对齐：[确定性纪律](../../knowledge/08-determinism-known-issues.md)、[1 号控制力设计 §5.3](../../references/silo1-control-design.md)（`R_s` 回答「是否进入介入评估」）、[威势状态与信息词汇 W/K/E/D/P/X](../10-it-control-credibility/03-prestige-state-and-information.md)、[21 谈判卷](../21-negotiation-compromise-design.md)与 [18 渗透卷](../18-time-permeation-design.md)（文档风格与存档升级先例）。

**世界观措辞纪律【裁决】**：各堡专线另一头在 IT 主任眼中只是「一套叫 Order 的系统」；下面的人不一定知道 1 号地堡的存在，他们表面服从的对象只是 Order 本身。因此 `Θ` 的语义是**主任对 Order 的立场**，而不是「对 1 号的立场」；本卷所有信号命名使用 Order 系统视角（回执、复核、例行汇报），措辞不暗示底下人知道 1 号存在。1 号的估计与决策是设计者/玩家视角的描述。

**历史校准锚【现状】**：40 号堡曾随 11 堡断联并干扰终止信号，被 1 号物理轰炸——这是 `Θ → 1` 在正典中的真实轨迹。本层不新增结局：高 `Θ` 的后果经由既有通牒/物理渠道（[world.go](../../internal/service/world.go) 反应链）表达。

## 2. 月度时间线与挂载点

### 2.1 既有阶段序【现状】

多堡月度 tick 固定为（[world.go](../../internal/service/world.go) 开头注释、[确定性纪律 §2](../../knowledge/08-determinism-known-issues.md)）：

```text
阶段 0a 延迟任务递减 → 0b AI 代操作 → 0c 18 号正典
→ 阶段 1 各堡本地结算 RunLocalPhase (SiloID 升序, 流水线步骤 1-6)
→ 阶段 2a 跨堡队列派发 → 2b 一号地堡裁决 runSilo1StateMachine → 2c 堡外群体维持
→ 阶段 3 时钟推进
→ 阶段 4 各堡后置 RunPostPhase (SiloID 升序, 流水线步骤 8-9)
```

[RunLocalPhase](../../internal/engine/engine.go) 内部与本卷相关的顺序：

```text
4 AdvanceAuthorityMonthly → 4.5 AdvanceProtocolMonthly → 4.6 RunITAuthorityMonthly
→ 4.7 DecayProfessionAlertness → 5 RunNpcTurn → 6 指标 → 7 胜负
```

其中 `RunITAuthorityMonthly`（[it_authority.go](../../internal/engine/it_authority.go)）是执行强度的现有落点【现状】。单堡路径按 `PrepareTick → RunLocalPhase → AdvanceSiloClock → RunPostPhase → Drain` 整体调用，与世界 tick 拆开调用的三相顺序一致（engine.go `UpdateSiloState` 契约）【现状】。

### 2.2 四个事件的挂载点【提案】

`r_s(t)` 采用**指派月索引**：1 号在月 `t` 的阶段 2b 做出决定，指令自月 `t+1` 的本地相起生效（Order 指令有一个月的传达时滞，与既有跨堡队列及 `SILO1_DECEIVE` 的 `DelayMonths` 延迟语义同构【现状，silo1_operations.go】）。裁决主递推式按字面成立：月 `t` 指派的 `r_t` 在月 `t+1` 本地相结算 `Θ_t → Θ_{t+1}` 转移。

| 事件 | 阶段 | 挂载位置 | 说明 |
| --- | --- | --- | --- |
| 1 号指派 `r_s(t)` | 阶段 2b 一号地堡裁决 | `runSilo1StateMachine` 既有内容之后新增「黑箱回合」，按 SiloID 升序 | 沿用 2b「读取全部堡阶段 1 后状态」的语义；零 RNG |
| `Θ` 结算 `Θ(t+1) = clamp01(Θ(t) + growth(r_t) − decay(Θ(t), r_t))` | 阶段 1 RunLocalPhase | 新步骤 **4.55**：在 4.5 Protocol 结算之后、4.6 IT 权威回合之前 | 读 `LastAssignedRisk`（= 上月指派的 `r_t`）；世界侧簿记，零 RNG |
| `E` 生效 `E(t+1) = E(r_t, Θ(t+1))` | 阶段 1 RunLocalPhase | 4.55 同步计算，写入月度生效槽，供 4.6 消费 | 不直接改写叛乱/恐慌（§4.4） |
| 观测产生 | 阶段 1 RunLocalPhase | 新步骤 **4.65**：在 4.6 之后、4.7 部门戒备冷却之前 | 反映结算后的 `Θ(t+1)`，按延迟 `δ_k` 入队；**唯一 RNG 消耗点**（门控） |
| 观测到达与信念更新 | 阶段 2b 黑箱回合 | 各堡回合开头抽干到期观测 | 延迟信号归属到它反映的那个月（§5.3）；零 RNG |
| RunPostPhase | 阶段 4 | **不新增任何内容** | 触发器/规则引擎阶段序不变 |

**回路延迟算术**（新模型对「旧模型作废」的机制回答）：`r_t` 在月 `t` 的 2b 指派 → 月 `t+1` 本地相才生效并产生观测 → 观测再经 `δ_k ≥ 1` 个月到达 → 1 号最早在月 `t+2+δ_k` 的 2b 看到关于 `r_t` 的第一个带噪回音。**行动→回音的最小回路 ≥ 3 个月**，叠加 `Θ` 的 15–30 月时间常数（§3），快循环无法在几回合内试出曲线形状。

### 2.3 为何不破坏确定性与既有阶段序

1. **阶段序不动**：只在 RunLocalPhase 内插入两个新步骤（4.55/4.65，既有步骤不重编号），并在阶段 2b 既有内容**之后**追加黑箱回合；RunPostPhase 完全不碰。单堡与多堡两条路径按同一三相顺序拆开执行，插入点在两条路径中一致。
2. **固定顺序**：所有逐堡循环按 SiloID 升序（既有纪律）；堡内观测按 `(到达月, 信号类型, 序号)` 升序抽干；信念箱与决策菜单按索引/数值升序累加；「只有严格更高分才替换当前选择」（既有纪律，knowledge/08 §2）。
3. **RNG 纪律**：信念更新与决策全程零 RNG；唯一消耗点是观测产生（4.65），受功能开关与「该信号当月是否产生」双重门控、按信号类型升序固定取样——与谈判层「仅当信道畅通时消耗 RNG；未开信道的运行不消耗任何新随机数，轨迹逐位不变」同先例（knowledge/08 §2）。**功能关闭 → 全步骤跳过 → 零新消耗 → 与 v8 parity 基线逐位一致。**
4. **无私有随机源、无 map 序浮点累加**：`Belief` 是定长切片，`PendingObservations` 是按确定性键排序的切片（rng.go 单一 RNG 流纪律）。
5. **专线干扰**：`WorldFlagNetworkJammed` 为真时，黑箱回合与既有通牒路径一样早退（[world.go](../../internal/service/world.go) G11 先例【现状】）：不更新信念、不签发新指派（`LastAssignedRisk` 沿用，断联期间最后一条指令继续生效）；在途观测**挂起**而非丢弃，于解扰后第一个月抽干。丢弃/挂起之选择标 `TODO(adjudication)`，见 §10。

## 3. Θ 动力学

### 3.1 裁决形式

```text
Θ_{t+1} = clamp01(Θ_t + growth(r_t) − decay(Θ_t, r_t))
```

- `growth(r)`：`r ≤ r_calm`（正常带上界）时为 **0**；`r > r_calm` 后单调上升并饱和。
- `decay(Θ, r)`：`r` 处于正常带 `[0, r_calm]` 时按时间常数 `τ_decay` 向 0 回落；压力升高时衰减被抑制。
- 硬要求【裁决】：持续最大施压需 **≥ 12 个月量级**才把 `Θ` 推入危险区（「常年施压才会人人自危」），禁止一两个月就爆。

### 3.2 候选 A（推荐）：分段线性加性

```text
x(r)        = clamp01((r − r_calm) / (r_full − r_calm))   // 超压归一化
growth(r)   = g_max · x(r)                                  // 线性上升, r ≥ r_full 处饱和
decay(Θ, r) = Θ · (1/τ_decay) · (1 − x(r))                // 向 0 指数衰减, 随压力抑制
Θ_{t+1}     = clamp01(Θ_t + growth(r_t) − decay(Θ_t, r_t))
```

推荐初值：`r_calm = 0.35`，`r_full = 0.85`，`g_max = 0.04/月`，`τ_decay = 30 月`（均 `TODO(balance)`，理由见 §9）。

**硬要求校验**：

- 持续 `r = 1`：`x = 1`，净增 `+0.04/月`，从 0 到 `θ_danger = 0.60` 需 **15 个月 ≥ 12** ✓。一两个月爆不了：两个月最大施压 `Θ ≤ 0.08`，仍在顺从带内。
- 持续 `r ≤ r_calm`：`Θ` 按 `τ = 30` 月指数衰减——一年安抚 `0.60 → 0.40`，两年 `→ 0.27` ✓（戒心消退缓慢）。
- 持续中等压力的平衡点：令净增为 0 得 `Θ_eq(x) = g_max·τ_decay·x/(1−x)`（越界取 1）：`x = 0.2`（`r ≈ 0.45`）→ `Θ_eq ≈ 0.30`；`x = 0.5`（`r ≈ 0.60`）→ `Θ_eq = 1.2 → 1`。**慢性轻度超压滋生中度戒心，持续高压才到危险区**——形状与叙事一致。
- 时间常数：建满至危险约 15 月（年级），衰减 `τ = 30` 月（多季度到年级）——「明显的时间常数」✓；短期试探（几回合）只能看到 `Θ` 的微小线性响应，看不出曲线形状。

### 3.3 候选 B：指数趋近

```text
Θ_∞(r)  = x(r) · θ_sat                                     // 平衡曲线
α(r)    = 1 − exp(−1/τ(r)),  τ(r) = τ_decay (r ≤ r_calm) 否则 τ_build
Θ_{t+1} = clamp01(Θ_t + α(r) · (Θ_∞(r) − Θ_t))
```

解析上优雅（持续恒定 `r` 时 `Θ` 指数趋近平衡、无过冲），但两个时间常数与平衡曲线互相耦合，后续调参难以归因，且不与裁决的加性主递推式字面一致。**不推荐**；保留作对照。

### 3.4 不对称性选择：建立快、消解慢【裁决推荐】

建满至危险（约 15 月）≈ 衰减时间常数（30 月）的一半。理由：

1. **叙事**：戒心由施压经历塑造，需要长期一致的温和才消退——「常年施压人人自危，短期安抚换不回信任」。
2. **玩法**：1 号施压是近乎不可逆的投资，不能靠短期安抚快速「修复」一个被推高的堡；同时封死快循环钻空子——「压两月、抚两月」的循环在建立快消解慢下棘轮净增为正（例：`Θ = 0.30` 时，两月最大施压 `+0.08`，随后两月安抚仅 `−≈0.025`）。
3. **世界观**：底下人服从的对象是 Order 本身；一旦「Order 的指令越来越苛刻」的认知形成，不会因为几道温和指令而消散。

## 4. 执行强度单峰 E(r, Θ)

### 4.1 峰形随 Θ 的移动（方向与叙事理由）

`E(r, Θ)` 对 `r` 单峰；峰位、峰高、峰宽均为 `Θ` 的单调函数：

| 量 | 形式 | 方向 | 叙事理由 |
| --- | --- | --- | --- |
| 峰位 `r*(Θ) = r_0 − k_shift·Θ` | 单调**左移** | `Θ↑` | 人人自危之后，曾经「正常」的压力已被视为苛待；只有更低的风险指派才显得可接受 |
| 峰高 `E_max(Θ) = e_0 − (e_0 − e_1)·Θ` | 单调**下降** | `Θ↑` | 阳奉阴违封顶出力：指令再「合身」，离心离德的 IT 也只出有限力气 |
| 峰宽 `σ(Θ) = σ_0 · (1 − k_width·Θ)` | 单调**收窄** | `Θ↑` | 容错窗口变窄：偏离甜蜜点的微小偏差就引发消极抵制或恐慌 |

推荐初值：`r_0 = 0.45`，`k_shift = 0.30`（`r*(1) = 0.15`），`e_0 = 0.95`，`e_1 = 0.40`，`σ_0 = 0.20`，`k_width = 0.50`（`σ(1) = 0.10`）。均 `TODO(balance)`。

### 4.2 候选公式

**候选 A（推荐）：高斯型**

```text
E(r, Θ) = E_max(Θ) · exp(−(r − r*(Θ))² / (2·σ(Θ)²))
```

理由：光滑无折点，快循环无法用差分定位折点（与「短期试探看不出曲线形状」一致）；两端尾部自然表达渐进恶化；峰位/峰高/峰宽三参数分离、各自独立依赖 `Θ`，校准与归因都简单。

**候选 B：分段线性帐篷函数**——简单、可手算，但在 `r*(Θ)` 与两肩存在折点，试探预算足够时可被差分定位；折点位置虽因 `Θ` 隐藏而间接隐藏，仍不如高斯稳健。**不推荐**。

**数值校验**：`Θ = 0`：`E(0.45) = 0.95`（峰）；`E(0) ≈ 0.08`（怠工）；`E(1) ≈ 0.02`（急性失能）。`Θ = 1`：峰移到 0.15、高 0.40、宽 0.10——`E(0.15, 1) = 0.40`，而旧甜蜜点 `E(0.45, 1) ≈ 0.004`：**1 号若沿用旧峰位指派，面对的是彻底失能**。

### 4.3 两端行为

- **低 `r` 端（`r ≤ r_calm`）**：`E` 落入尾部——怠工清闲：回执照打、指令照接、落实遥遥无期。但 `growth = 0`，`Θ` 不上涨：1 号以低执行强度换来不生事端。这是「两端都不干活」的左端。
- **高 `r` 端（`r → 1`）**：`E → 0`——急性失能：恐慌、空转、滥查、报告造假，越压越乱；且 `r > r_calm` 持续喂养 `Θ` 增长。右端双重昂贵：**现在执行差，未来更差**。

### 4.4 消费接口

`E_s(t)` 在 4.55 写入月度生效槽（`CurrentExecution`），消费方：

1. `RunITAuthorityMonthly`（[it_authority.go](../../internal/engine/it_authority.go) L190-267）：对 Order 意图方向的执行效用做折扣——执行强度的现有落点【现状锚点】。
2. 1 号反应链（[world.go](../../internal/service/world.go) L387-437）：通牒「实际落实力度」的折扣输入。

具体耦合形式（效用乘子 / 资源折扣 / 执行率）标 `TODO(adjudication)`，见 §10；本层只保证 `E` 的输出存在且确定。`E` **不直接改写**叛乱、恐慌等既有量，一切影响经由既有落点传递。

## 5. 1 号估计算法（N 箱后验）

### 5.1 离散化与先验

**箱数 `N = 20`（推荐；16–32 均可接受）**。理由：

- 箱宽 `0.05` ≤ 观测噪声 `σ`（0.10–0.15，§5.2）：更细不带来信息增益，只增内存；更粗则对 `θ_danger` 附近失去分辨率。
- `θ_danger = 0.60` 恰落在箱边界（`12/20`）上：危险区概率是一次箱求和，无跨箱插值。
- 单次更新 `O(N)`，为平凡常数。

**先验**（低 `Θ` 偏重 + 均匀地板）：

```text
b_0(i) ∝ (1 − ε)·exp(−λ·θ_i) + ε        // λ = 4.0 (先验均值 ≈ 0.22), ε = 0.05
```

理由：世界观默认「表面服从是常态」——绝大多数主任终其一生例行执行 Order，从不触及真相，因此先验质量集中在低 `Θ`；`ε` 均匀地板保证所有箱严格为正——高斯似然全域支撑，任何箱永不归零锁死：**延迟、带噪、被伪装的信号始终有机会翻转任何先验判断**（黑箱的核心要求）。

### 5.2 观测信号（全部 Order 系统视角）

1 号的眼睛就是 Order 系统本身；信号命名不暗示底下人知道 1 号存在【裁决】。

| 信号 `k` | 语义（1 号眼中） | 延迟 `δ_k`（月） | 噪声 `σ_k` | 伪装偏移 `d_k` |
| --- | --- | ---: | ---: | ---: |
| `receipt_delay` | Order 指令回执/执行回报的时延归一化 | 1 | 0.10 | 0.05 |

### 5.3 延迟观测的归因

观测在月 `t` 到达，反映的是月 `τ = t − δ_k` 的状态。候选方案：

- **候选 A（推荐）：噪声膨胀归因**。直接把观测当作对**当前** `Θ_t` 的带噪读数，有效噪声膨胀为

  ```text
  σ_eff² = σ_k² + (ρ̂·δ_k)²
  ```

  `ρ̂ = 0.05` `TODO(balance)` 是 **1 号自己对「主任立场每月最多能变多快」的上界假设**——它的内部经验参数，不读真实 `g_max/τ_decay`。真实最大漂移 `g_max = 0.04 < ρ̂`，即假设偏保守（轻微过散），是安全方向。误差界：`Θ` 在 `δ ≤ 2` 月内最多漂移 `0.08`，与观测噪声同量级，膨胀后验覆盖真实状态。
- 候选 B：严格后向投影——用已知动力学把似然回推到月 `τ`。**拒绝**：需要读取真实曲线参数，违反禁止读心裁决；且世界观里 1 号本就不该握有真实曲线。
- 候选 C：信念快照队列（对每个历史月保留信念副本，延迟观测更新对应副本再前向合并）。等价于 B 的动力学依赖，且状态膨胀。**拒绝**。

### 5.4 似然（含伪装混合）与更新

1 号不知道某条观测是否被伪装过，按其内部伪装率假设 `π̂(θ) = clamp01((θ − 0.30)/0.40)`（与产生侧同形式，但这是 1 号自己的模型，非读取世界参数）做边缘化：

```text
L_i = (1 − π̂(θ_i))·φ(y; θ_i, σ_eff) + π̂(θ_i)·φ(y; θ_i − d_k, σ_eff)
b_i ← b_i·L_i / Σ_j b_j·L_j
```

`φ(·; m, s)` 为均值 `m`、标准差 `s` 的高斯密度。同月多条观测按**信号类型升序**逐条应用。全程零 RNG。

### 5.5 输出

```text
Θ̂_s      = Σ_i b_i·θ_i                        // 后验均值（点估计）
P_danger = Σ_{θ_i ≥ θ_danger} b_i              // 危险区概率（决策直接用）
[θ_lo, θ_hi] = 包含 90% 质量的最短箱区间 (升序扫描)   // 不确定性
```

**禁止读心审计**：本节输入仅有观测队列（带噪 `y` 值）与 1 号内部参数（先验、`ρ̂`、`π̂`、内部响应模型）；任何步骤不读真实 `Θ`、不读 `growth/decay` 参数、不读 `E` 曲线参数。

## 6. 1 号月度决策规则

### 6.1 决策菜单与硬失败线

菜单 `R = {0.00, 0.05, ..., 0.95}`（21 点）。上界 `0.95 < 1.0`：决策层**不自愿触碰 DEATH 线**——`SafeguardRisk ≥ 1.0` 触发 DEATH 是既有硬失败语义【现状，models.go】，保留为内容事件推动的渠道，不是 1 号的最优解候选。

### 6.2 1 号内部执行模型（它自己的理论）

1 号用与真实同族的高斯形式建模执行强度，但参数是**它自己的**（基线初值与真实参数相同——1 号的理论大致正确，只是不全知：它读不到真实 `Θ`，只读自己的信念）；误设与在线学习留给轨道 C：

```text
Ê(r; θ) = Ê_max(θ)·exp(−(r − r̂*(θ))² / (2·σ̂(θ)²))
```

### 6.3 期望效用 argmax

```text
U(r) = Σ_i b_i·Ê(r; θ_i) − κ·r          // 期望执行强度 − 压力代价
r(t) = argmax_{r ∈ R} U(r)
```

- `κ = 0.10` `TODO(balance)`：高压指派的注意力/暴露代价（风险度本身是稀缺的政治资源，且高 `r` 区间 `Ê` 已塌，代价项阻止无意义施压）。
- **确定性平局**：菜单升序遍历，**只有严格更高分才替换**当前选择——平局保留更小的 `r`（与 it_authority.go「同分按 action ID 升序」、knowledge/08「只有严格更高分才替换」同口径）。零 RNG。

### 6.4 探索接口（留给轨道 C，先声明签名）

```text
ProbeProposer(s, b_s, ctx) -> (r_probe float64, ok bool)
// ok = true 时以 r_probe 覆盖 argmax 结果；
// 必须是纯确定性的，或经引擎唯一 RNG 流、按 SiloID 序消耗（禁止私有随机源）；
// 使用后写 ProbeCooldown（存档字段，§8），每月 −1，归零前不再触发。
```

### 7.2 复杂度

每堡每月：信念更新 `O(N·K)`（`K` = 当月到达观测数 ≤ 3）；摘要 `O(N)`；决策 `O(N·M)`（`M = 21` 菜单点）；`Θ` 结算与 `E` 计算 `O(1)`；观测产生 `O(3)`。全游戏 `O(S·N·(K+M))`；`K`、`M` 为固定常数，故为 **`O(S·N)`**，与目标 `O(S·(N+|信号|))` 同阶（`N = 20` 时约 5×10² 次浮点运算/堡/月，相对既有结算量可忽略）。

### 7.3 RNG 消耗规范

| 步骤 | RNG 消耗 | 次数（每堡每月） | 顺序 |
| --- | ---: | ---: | --- |
| 观测到达/信念更新/摘要/决策 | **0** | 0 | —（纯确定性） |
| 观测伪装判定 | `DrawFloat64` | ≤ 1（每产生信号） | 信号类型升序 |
| 观测噪声 | `DrawFloat64` ×2（Box-Muller） | ≤ 2（每产生信号） | 紧随同信号伪装判定之后 |

- 信念更新与决策**全程零 RNG**（强烈建议项，已按此设计）；若轨道 C 的探索需要随机，必须经引擎唯一 RNG 流（[rng.go](../../internal/engine/rng.go) `DrawFloat64/DrawIntn`）、按 SiloID 序消耗，禁止私有随机源。

- 取样顺序固定写死：堡按 SiloID 升序，堡内信号按类型升序，伪装判定先于噪声取样。
