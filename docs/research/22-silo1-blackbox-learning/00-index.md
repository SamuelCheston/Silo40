# 22-00 · Silo 1 黑箱学习：总览、统一口径与主线裁决

> 本文档由 AI 维护（project-source）。本系列只写设计与规格，不改代码、配置、事件或数值；实现归实现轨（「曲线与两个指标的本体」）。
>
> 前提裁决：旧模型「风险度 → IT 执行强度是一条静态单峰曲线，1 号靠试探找峰」**已作废**——AI 对 AI 的循环比玩家快得多，几回合就能把静态峰试出来，难度失真。新模型：每堡维护一个 0–1 隐藏量，safeguard 风险度只决定它的**增长速度**（风险正常时向 0 回落）；执行强度对风险度仍是单峰，但峰由隐藏量间接决定；1 号只能靠延迟、带噪声、可被伪装的信号维护信念。详见 [ADR-0015](../../../knowledge/adr/0015-silo1-blackbox-learning.md)。

## 2. 统一符号与命名裁决

| 符号 | 范围 | 含义 |
| --- | --- | --- |
| `r_s(t)` | `[0,1]` | 1 号在月 `t` 给堡 `s` 指派的 safeguard 风险度（1 号的控制变量）。功能开启时经既有 `SafeguardRisk` 字段落地（§5.1） |
| `Θ_s(t)` | `[0,1]` | 隐藏量。**最终命名：`self_preservation` · 自保**（[04 卷 §1.3](04-naming-log-and-readability.md)）：执行链对 Order 指令的自保姿态——执行指令时给自己留多少后路。0=完全按 Order 办事，1=公开叫板，中段=消极、拖延、阳奉阴违 |
| `E_s(t)` | `[0,1]` | 执行强度：本地执行链透过 Order 实际落实 1 号意图的力度。对 `r` 单峰，峰位/峰高/峰宽由 `Θ` 间接决定（[01 卷 §4](01-dynamics-and-pseudocode.md)） |
| `b_s(·)` | N 箱单纯形 | 1 号对 `Θ_s` 的分箱后验信念。**权威表示：N=20 等宽箱**（[01 卷 §5.1](01-dynamics-and-pseudocode.md)） |
| `φ_s(t)` | `[0,1]` | 本地伪装强度（动机 × 能力，[02 卷 §4](02-observations-and-noise.md)） |
| `L(t)` | `≥0` | 1 号问责量【合理外推】（[03 卷 §3.3](03-exploration-and-cost.md)） |

命名合规要点（详见 04 卷）：「自保」的对象是**指令附带的风险**，不需要知道风险来自谁——措辞全程无需提及 1 号，满足「下面的人不一定知道 1 号地堡存在、表面服从的只是 Order 本身」的世界观口径。代码/存档/调试用标识符 `self_preservation`，叙事文本用中文「自保」；01 卷存档字段的 `Theta` 实现时跟随为 `SelfPreservation`。

**「两个指标」的所指**：任务书中实现轨要实现的「曲线与两个指标」，本系列口径下即 **`Θ`（自保，隐藏存量指标）与 `E`（执行强度，派生指标）**；`r` 不是新指标，是 1 号的控制变量，经既有 `SafeguardRisk` 字段表达。

### 2.1 信念箱与语义档的两层结构

- **信念存储层**：N=20 等宽箱（箱宽 0.05），1 号后验的唯一权威表示（01 卷）。
- **语义档层**：B0–B4 五档（[03 卷 §2.1](03-exploration-and-cost.md)：`[0,0.10)` 服从 / `[0.10,0.30)` 摩擦 / `[0.30,0.50)` 阳奉阴违 / `[0.50,0.70)` 抵制 / `[0.70,1]` 抗命），用于探索策略、决策日志与叙事表述。02 卷 §0.4 的四档粗箱（Δ=0.25）只是该卷定量论证的粗化，不是权威分档。

### 2.2 风险档位 R0–R5 与 r 数值的映射

03 卷的六档姿态与 01 卷的 21 点决策菜单（0.00–0.95，步长 0.05）按区间映射，边界锚定动力学参数：

| 档位 | r 区间 | 动力学意义 |
| --- | --- | --- |
| R0 静默 | `[0.00, 0.10)` | 深度回落区 |
| R1 例行 | `[0.10, 0.35]` | `r ≤ r_calm`：Θ 全速回落，不增长 |
| R2 关注 | `(0.35, 0.50]` | 越过 `r_calm`：Θ 开始增长 |
| R3 施压 | `(0.50, 0.65]` | 中段增长 |
| R4 高压 | `(0.65, 0.85]` | 接近饱和点 `r_full` |
| R5 满压 | `(0.85, 0.95]` | `g_max` 饱和增长；菜单上界 0.95 避开 DEATH 线 1.0 |

## 3. 权威参数定稿（时间常数）

本节经历两轮裁决：首次定稿（`g_max=0.02/月`、`τ_decay=48 月`）已被**裁决 13 作废**——反应太慢（被刀架脖子两年半才进危险区不成立）。现行定稿如下，核心形状为**反应快、暴露慢**（数值本身仍为推荐初值，全部 `TODO(balance)`，等待 sim 校准；完整参数表以 [01 卷 §9](01-dynamics-and-pseudocode.md) 为准）：

| 参数 | 定稿值 | 理由 |
| --- | --- | --- |
| `g_max` | **0.12/月** | 反应快（裁决 13）：满压 1–2 个月明显抬头（+0.12–0.24），**5 个月**到危险区 `θ_danger=0.60`（裁决 3–6 月），约 **6 个月**进叫板档、**8–9 个月**到 Θ=1（裁决 6–12 月） |
| `τ_decay` | **15 月** | 裁决 12–18 月量级，不拖更久；一年安抚 0.60 → ≈0.27 |
| `r_calm` / `r_full` | 0.35 / 0.85 | 不变（01 卷 §9） |
| `θ_danger` | 0.60 | 不变；与 N=20 箱边界对齐 |
| `θ_defy` | **0.70** | 叫板阈值（裁决 13 新设）= 03 卷 §2.1 B4 抗命档下界 |
| `ρ̂` | **0.15** | 1 号内部漂移上界假设；必须 > `g_max` 才保持保守过散（01 卷 §5.3） |
| `q_fc` | **0.75** | 虚报率：按「阳奉阴违带观测平坦化」校准（02 卷 §5.2） |

定稿后的关键推导（各卷正文已同步）：满压净增 +0.12/月；持续中等压力平衡点 `Θ_eq(x) = 1.8·x/(1−x)`（`g·τ = 1.8`，x 为超压归一化）——`x=0.2`（r≈0.45）即深入阳奉阴违带（Θ_eq≈0.45），`x ≳ 0.36`（r≳0.53）发散到 1；棘轮不对称 **1:3**（建立 5 月 vs 消解 τ 15 月），「压两月、抚两月」净增 +0.20。**不可探性的主防线已从时间常数转移到观测伪装**：抬头后的第一反应是阳奉阴违（表面照办、底下敷衍、暗中准备），对 1 号基本不可见——02 卷 §5 已按重算值重做论证（测到的是服从，不是自保）。

## 5. 与实现轨的接口契约

1. **`SafeguardRisk` 的权威语义**：功能开启时，该字段的基线是 1 号指派的 `r`（决策菜单上界 0.95），内容事件继续按既有 `silo_metric_delta` 效果在基线上叠加增量；`≥ 1.0` → DEATH《寂堡》硬线不变、仍由内容事件推动，1 号决策层永不自愿触碰。功能关闭时该字段行为逐位不变。
2. **真值与信念严格隔离**：实现必须同时维护真值 `Θ`（世界侧，4.55 结算）与信念 `b`（1 号侧，2b 更新）两套读数；任何让 1 号决策读到 `Θ` 真值或 `E` 曲线参数的路径都是违规（ADR-0015 禁止读心）。
3. **确定性与 parity**：信念更新与决策全程零 RNG；唯一 RNG 消耗点是观测产生（门控、按 SiloID 升序、信号类型升序固定取样）。功能关闭 → 全步骤跳过 → 与既有 parity 基线逐位一致；功能开启 → 按 knowledge/08 §5 重建基线。
4. **挂载点**：`r` 指派挂阶段 2b 既有内容之后（黑箱回合）；Θ/E 结算挂 RunLocalPhase 新步骤 4.55；观测产生挂 4.65；RunPostPhase 不新增。既有阶段序与步骤编号不动（01 卷 §2）。
5. **缺口处置**：02 卷 §6 缺口清单中「等实现轨补」各项（稽查机制、举报管道、例行指令账本、人口报告通道、注意力预算载体、异常观察计数器、表面服从脉冲）由实现轨按该清单落地；「放弃」项（专线心跳）首版不做。
6. **内容事件**：03 卷 §5 的征兆事件 ID 为内容立项建议，本轮不写事件文件；信念驱动的表现挂既有 `failureOmenKeys` 征兆键的触发资格，不新造征兆（04 卷 §3.c）。
