## 3. 威势状态与信息系统

### 3.1 状态变量

| 符号 | 范围 | 含义 |
| --- | --- | --- |
| `W` | `[0,100]` | 幕后威势 |
| `K` | `[0,1]` | Judicial 法警与 IT 内部的加权忠诚 |
| `E` | `[0,1]` | 阴谋曝光高水位 |
| `D/P` | `[-1,1]` | 法警执行履约、人事连续性 |
| `X` | `[-1,1]` | **稀有异常外部信号**；常态为 0，不是月度指令 |
| `R_op` | `[0,100]` | IT 内部操作资源与可用法警时间的统一抽象 |
| `R_s` | `[0,1]` | Safeguard 风险 |

对 `D/P/X` 的渠道 `k`：

```text
V_k,t = clamp(Σe qe·2^(-age_e/half_life_k)·r_e·a_e,t·v_e,t, -1, 1)
```

默认半衰期 12/18/24 月。`r` 是结果，`a` 是 IT 归因，`v` 是联盟内知悉覆盖；同一 `fact_id` 只记一次。

### 3.2 月度更新

```text
K = 0.65·l_Bailiff + 0.35·l_ITInternal

W_eq,t = clamp(50 + 25K_t + 12D_t + 10P_t + 12X_t - 40E_t, 0, 100)
α      = 1 - 2^(-Δt/8)
W_t+1  = clamp(W_t + α(W_eq,t-W_t) + Σδe, 0, 100)
```

初始两块忠诚均为 0.8，`K=0.8`、`W_eq=70`。月 tick `Δt=1`，0 月不做被动漂移；冲击队列只消费一次。`E` 不随时间自动消退，新的履约和忠诚维护可以对冲。

外界通常不知道 IT，因此 `D/P/X` 主要使用法警系统和 IT 内部的知悉与归因，不把 Mayor 或普通部门的评价写进 `K`。

### 3.3 分层事实、版本与曝光

每个观察者 `p` 对事实 `e` 持有：

- `B_e,p∈[0,1]`：事实发生的确信度；
- `π_e,p,v`：事实成立时各解释版本的条件概率，`Σvπ=1`；
- 联合质量 `b_e,p,v=B_e,p·π_e,p,v`。

```text
E_now = clamp(Σe qE_e·Σg w_g·B_e,g·Σv π_e,g,v·a_e,v, 0, 1)
E_t   = max(E_t-1, E_now)
```

`E` 只在部门×阶层与具名人物 belief 层聚合，玩家自己的 `B` 不直接进入。普通事实若要形成“IT 幕后掌权”的外部归因，必须能连接到**法警受 IT 主任直接调度的证据链**；其他事故、档案或传闻本身不自动生成该归因。

Protocol 可以证明存在更高层处置规则，但单独读到 Protocol 仍不能证明当前 IT 正在操纵 Judicial；covenant 所需的公开归因仍需法警调度链。

### 3.4 碎片单次获取成功率

```text
p_get = clamp(
  0.55·f_prof·(1-0.45·mismatch)·(1-0.60·alert_d)
  ·(1+0.35·related_f)·access_c,
  0.05, 0.95
)
```

| 因子 | 范围 | 含义 |
| --- | --- | --- |
| `f_prof` | 0.75–1.25 | 玩家职业与材料的适配，不提供全知 |
| `mismatch` | `[0,1]` | 行为与目标部门规范冲突，见 §7.1 |
| `alert_d` | `[0,1]` | 目标部门戒备；失败探查和信息管控可提高 |
| `related_f` | `[0,1]` | `max_k related(f,k)·B_k,p`，只取最强相关项 |
| `access_c` | 0.60–1.15 | 渠道接触能力，与证据可靠性分开 |

| 渠道 | `access_c` | `reliability_c` |
| --- | ---: | ---: |
| 本职业内部记录 | 1.15 | 0.90 |
| 原始档案/实物 | 0.85 | 0.95 |
| 可信线人 | 1.00 | 0.70 |
| 签署证词 | 0.90 | 0.75 |
| 市面传闻 | 0.60 | 0.35 |

失败不增加 `B`，只结算 AP、检测和戒备；成功产生一次观察而非直接确信。`observation_id` 去重，不能重放 RNG 或收益。

### 3.5 多次吸收与版本更新

```text
s_i   = reliability_c·(0.85+0.15·related_f)·independence_i
B_new = 1 - (1-B_old)·(1 - s_i/(1+0.25·n))
```

`independence_i`：独立来源 1，同源转述 0.25，完全重复 0；`n` 是此前有效观察数。

| `s=0.65` 的有效观察数 | `B` |
| ---: | ---: |
| 1 | 0.650 |
| 2 | 0.832 |
| 3 | 0.905 |
| 4 | 0.940 |
| 5 | 0.960 |

第三次基本确定，第五次仍非 1。版本用贝叶斯更新：

```text
π_new(v) = π_old(v)·likelihood_i(v) / Σu π_old(u)·likelihood_i(u)
```

因此事实确信高，不等于“IT 主导”版本确信也高。

### 3.6 确信度与行动资格

| 玩家 `B` | 可支撑 | 不能支撑 |
| --- | --- | --- |
| `<0.30` | 私人笔记、猜疑 | 作为事实分享 |
| `0.30–0.59` | 带低置信标签的 rumor | 正式举报、归档 |
| `0.60–0.84` | 定向调查、私下对质、交叉取证 | 公开证据、covenant |
| `≥0.85` | 正式举报、申请归档 | 未经核验直接公开 |
| `≥0.90` 且材料可公开 | 核验后发布公开证据 | 绕过发布渠道与受众反应 |

`B≥0.90` 后不再增加行动收益。分享强度 `s_share=B_player·transmit_c·receptivity_g`，接收方再更新自己的 `B/π`，不存在 `E+=B_player`。

### 3.7 公开证据 `Q`

```text
Q = clamp(Σe qP_e·B_e,Judicial·π_e,Judicial,IT_unlawful
          ·public_provenance_e·public_coverage_e, 0, 1)
```

`public_provenance`：私人猜疑 0，匿名传闻 0.3，公开证词/未核验记录 0.6，已核验档案或市面可查原始记录 1。`public_coverage` 是实际公开覆盖率。

covenant 还要求至少两个独立事实满足 `B_Judicial≥0.85`、provenance≥0.8、coverage≥0.60。核心法警调度事实建议 `qP=0.60`，使两份高确信、高覆盖证据能够实际达到 `Q≥0.85`，而不是理论上永远差一点。

公开证据先经 `E` 降 `W`，再经 `Q` 开 covenant 门，是串联效果，不重复扣威势。
