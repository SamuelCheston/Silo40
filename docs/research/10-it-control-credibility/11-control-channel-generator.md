# IT 幕后权力：威势、Protocol 能动性与 Judicial 三方附着 · 控制通道对话生成器与三条路径衔接

> 拆分自 [IT 幕后权力：威势、Protocol 能动性与 Judicial 三方附着](../10-it-control-credibility.md)；目录、章节映射与出处见该索引。

#### C.上层控制方 干预与 控制通道 对话生成器

控制通道 不是孤立 AI，而是连接上层控制方 管理员的界面；主任起初可以以为自己面对机器。本生成器只保留抽象情报机制，不包含具名人物、对白、场景或可识别的具体剧情。

**开启条件：** `J≥1.0` 的异常预警、存在级审查、权威覆写或继承异常。每次对话含稳定 `dialogue_id`，每句有 `utterance_id`；同一句话不重复产出。

**可生成的抽象异常类型：**

| 异常类型 | Fact | Observation 与支持的 Version |
| --- | --- | --- |
| 生死权声明 | 对话通道声称能够终止整个地堡，并在局势压力升高时重复警告 | 对话记录支持“存在一个掌握全堡生死的更高权柄”；其是否为人类管理员仍由后续 Version 竞争 |
| 越级任命 | 正常内部继承程序被对话通道直接越过并指定继任者 | 任命记录支持“存在高于本地主任的任命权”，形成 `g_reflection=0.15` 的程序异常 |
| 主动解释或命令 | 对话通道提供本地主任无从获得的处置依据或跨域信息 | 对话记录支持“存在外部信息来源”，具体内容与泄漏量仍由本次 utterance 决定 |

**泄漏量由什么决定：**

```text
leak_i = clamp(
  base_utterance + 0.20·urgency + 0.20·provocation
  + 0.15·operator_slip + 0.10·G - 0.15·operator_discipline,
  0, 1
)
```

- `base_utterance`：一般警告 0.25、解释 0.35、直接命令 0.45、越级任命 0.60；
- `urgency=min(1,J/1.5)`：局势越紧急，管理员越可能越过标准措辞；
- `provocation∈[0,1]`：主任是否拿具体矛盾质问；
- `operator_slip/discipline∈[0,1]`：人类管理员的失言程度与话术纪律；
- `G` 只影响主任能识别多少异常，低 `G` 仍保留原始对话 Observation，不会把关键句藏掉。

**主任怀疑是事件式而非线性。** 另设 `H_channel∈[0,1]` 表示“控制通道 背后存在人类/更高权柄”的怀疑：

```text
H_channel,new = 1 - (1-H_channel,old)·(1-leak_i·independence_i)
```

独立新命令为 1，同类新措辞为 0.25，完全重复为 0。`H_channel` 跨 0.35/0.65 时解锁更具体的追问；`G` 仍由交叉验证和参悟推进，二者不合并。

**对 `W` 与行为模式分开：**

- 每个不同泄漏若被法警或 IT 内部联盟知悉，产生 `δW_leak=-(2+4·leak_i)`：本地 IT 主任并非最高权柄，联盟对本地权力稳定性的判断受损。
- 泄漏若进一步公开，只再经受众 `B/π→E` 影响 `W`，不得另加一次“公开泄漏 shock”；内部威势损失与外部曝光是不同受众通道。
- `G/H_channel` 不直接给 `W` 正负奖励。认知提高后，主任可能更准确预判介入、减少 Protocol gap，经 `D/P` 间接增强 `W`；也可能因知道对方并非全知而减少高风险清理，短期削弱 `W`。结果由后续行为决定。

**玩家促使质问的手段：**

1. 制造可预警的 Protocol 偏离，使 控制通道 必须反复警告，为主任提供矛盾素材；
2. 向主任投放两份互相冲突的执行结果，提升 `provocation`；
3. 影响继承危机或暴露前任处置，使任命程序成为可见异常；
4. 通过 IT 内部人员提供“生死权来自哪里”“谁有权任命继任者”的问题线索。非 IT 玩家不能直接呼叫 控制通道，除非先获得密室与对话权限。

#### 三条路径与现有设计的衔接

- 三条路径均遵守文档 11：结构化 `Fact/Version` 由内容注册表锁定，Observation 只实例化一次；LLM 若用于润色，也不能改变泄漏量、条款、证据资格或 `B/π`。
- Relic 是可没收实物，Protocol 参悟是事后认知事件，控制通道 对话是独立人际情报渠道；三者不能合并成统一“读书进度”。
- 控制通道 仅作为极端介入中的抽象情报通道，不保留来源人物、对白或具体事件；与“平时只读 Protocol”不冲突。
- 旧版 `G` 的泛化累积被本节的事件式生成器细化，**不改变 S 曲线、Judicial 三方附着、`E/Q` 聚合或 Safeguard 硬失败**。
- 实物没收不会删除已存 Observation，但会影响公开核验；同一实物、同一参悟键、同一句 控制通道 话语均不能反复刷 `G/W/E/Q`。
