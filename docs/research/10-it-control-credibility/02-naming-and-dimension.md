## 2. 命名与量纲

### 2.1 候选

| 候选 | 衡量什么 | 相对比较 | 正文与 UI 感觉 |
| --- | --- | --- | --- |
| **幕后威势** | 极小联盟对 IT 协调、庇护、赏罚和收场的预期 | 比“震慑力”包含履约，比“统治惯性”更能主动维护，不像“幕后支配”那样易被误读为兵力 | “IT 的幕后威势正在崩解”；“幕后威势：摇摇欲坠”。**采用** |
| 统御预期 | 各方对 IT 继续统御组织的预判 | 定义准确，但比“幕后威势”学术化 | “统御预期：低位”，清楚但偏论文 |
| 震慑力 | 对 IT 发现并惩罚违抗的预期 | 简短，却覆盖不了 Protocol 处置、前途与内部真相 | “震慑：衰退”，易误导为纯暴力 |
| 统治惯性 | 服从因习惯和胜负预期延续 | 能解释墙倒众人推，但弱化 IT 能动性 | “惯性：减弱”，偏被动 |
| 幕后支配 | IT 对组织与岗位的支配状态 | 有力，但最易被理解成资源与武力存量 | “支配：瓦解”，资源化倾向明显 |

“确信度”只用于信息，不用于命名 `W`。`W` 初始 70，玩家普通 UI 只看有情报支持的区间：`不可动摇 / 仍然稳固 / 出现裂痕 / 普遍观望 / 墙倒众人推`。
