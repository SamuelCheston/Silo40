## 1. 地堡（Silo）总体结构

### 1.1 规模与形制

| 设定项 | 内容 | 可信度 |
| --- | --- | --- |
| 楼层数 | 144 层，单一中央螺旋楼梯贯穿顶底 | 【原著明确】 |
| 人口 | 约 10,000 人；不同叙事版本会给出更精确的统计口径 | 【原著明确】+【改编侧抽象】 |
| 禁电梯 | 公约严禁机械化垂直运输（电梯、滑轮），层间移动只能步行 | 【原著明确】+【改编侧抽象】 |
| 放大镜禁令 | 超过一定倍率的放大镜被限制，防止居民观察过细之物 | 【改编侧抽象】 |
| 地堡数量 | 50 座人口地堡 + 1 座指挥堡；另有第 51 个目的地“Seed” | 【原著明确】 |
| 布局 | 各地堡相距仅数百米，成片分布于一片废墟城市郊外数英里处 | 【原著明确】 |
| 建造年代 | 2049 年完成设计，2052 年封堡 | 【原著明确】 |

### 1.2 楼层职能分布（抽象分区）

不同叙事版本给出的楼层锚点略有差异，但垂直分区稳定：

| 区带 | 典型职能 | 机制作用 |
| --- | --- | --- |
| 顶层 | 食堂与外景大屏、治安官办公室、关押“想出去者”的拘留区、通往地表的气闸 | 信息展示、执法入口、清洁仪式的舞台 |
| 上层 | Judicial 办公室、管理层公寓、IT 办公室 | 正式权力与隐蔽权力重叠区 |
| 上层隐蔽区 | 监控室藏于清洁用品间暗门之后 | 全堡摄像头的物理入口 |
| 中层 | 医疗中心、分段医院、农场与磨坊 | 人口健康、食物生产与配给 |
| 下层 | 矿层入口、副治安官驻点 | 资源开采、刑罚劳动、基层执法 |
| 底层 | 机械区、发电机房、地下水泵 | 能源、水、空气与结构维护 |
| 底层之下 | 封闭 cavern 与掘进机 | 终局逃生设施与禁忌知识 |

小说侧的对应关系是：IT 位于地堡上部、掌握服务器与真相；Mechanical 位于 Down Deep（最底层），负责发电机、泵与空气；市长与副手可以徒步下行约 100 层到 Down Deep 面试机械师。【原著明确】

### 1.3 Cavern 与掘进机

- 地堡最底部、约 30 英尺厚混凝土板之下，有一个横跨整个堡体周长、高数层的圆柱形 cavern，内有建造地堡时使用的巨型掘进机，底部有浅水层与一条通往巨大金属门的隧道。【改编侧抽象】
- 小说对应物：每座地堡底部都埋着一台隧道掘进机，全部指向同一方向——指向 Seed；机械师出身的市长可以启动本堡掘进机横向挖向邻堡。【原著明确】
