## 5. 遗留科技与禁令

### 5.1 公约与处置手册

- **公开公约**：规定堡内生活的基本规则，包括出去请求不可撤销、禁电梯/滑轮、限制高倍放大镜、法官弹劾条件、生育与家庭条款等。多数居民只一知半解。【原著明确】+【改编侧抽象】
- **处置手册**：指挥堡内部运行的应急程序手册，规定叛乱、失联、清洁失败等情境的处置梯度；不覆盖所有未知条件。【原著明确】
- **隐藏终局文件**：与公开公约同名但内容不同的终极计划，规定数百年后只保留一座地堡并终止其余（含指挥堡）。【原著明确】
- **改编侧扩展**：本地 IT 主管可读的应急手册、上级处置文件与隐藏指令通道，构成“公开规则—内部手册—终极文件”三层信息资产。【改编侧抽象】

### 5.2 Relic（遗物）制度【改编侧抽象】

- 定义：大革命前的一切物品均为违禁遗物，持有违法，可判矿役；少数物品（如手表）可登记合法化。
- 常见类型：存储介质、个人随身物品、日用品与包装、影像设备、旧世界地理与生活读物、旧版书籍。
- 分级与刑罚：存在颜色或等级分级的违禁品清单；矿役是常见刑罚。
- 小说对应：硬盘是最高违禁品，持有即重罪；“想出去”与硬盘共同构成两条主线禁忌。【原著明确】

### 5.3 记忆药物（遗忘机制）【原著明确】+【改编侧抽象】

| 机制 | 内容 |
| --- | --- |
| 指挥堡轮班药物 | 值班员服用钝化记忆与情感的药物；重置时全堡投药抹忆 |
| 供水投药 | 记忆药物可经供水系统全堡投放，抹去数周至数年记忆 |
| 免疫个体 | 少数人对药物天然免疫，成为历史记忆的活载体 |
| 极端后果 | 大规模抹忆可导致自杀、儿童被遗忘而饿死等次生灾难 |

### 5.4 长期地下生活综合征【改编侧抽象】

- 症状梯度：不自主抽搐 → 四肢震颤 → 疼痛痉挛 → 平衡失调 → 认知衰退 → 神经系统停摆。
- 官方叙事：把病症解释为外部环境或生活方式问题，并用宣传标语维持秩序。
- 病因假说：血液病、维生素缺乏，或长期地下生活导致的自然反应。
- 制度接口：患者可获得执法豁免或特殊岗位安排，成为可被政治利用的群体。
