# 可改编桥段研究：游戏事件与结局母题

> 用途：直接作为 `events/` 新事件（history / special / crisis / player_action）与结局设计的选题库。
> 每条桥段给出：机制内核、可信度、到 Silo40 现有系统的映射建议。
> 口径：只保留可复用的机制与结构，不写具体人名、组织名、集数与可指认剧情；需要举例时用功能位描述。

## 0. 与现有内容的衔接

仓库已有事件的母题与本研究的对应关系（只读核对，未改动）：

| 已有事件 | 对应母题 |
| --- | --- |
| `histories/archive_truth_broadcast` | 真相被劫持到全堡屏幕；记忆管制与传播竞速 |
| `histories/silo1_destroyed_signal` | 指挥堡终局：建堡者引爆指挥堡 |
| `special/outside_signal` | 拒洁者走出视野，信条被击穿 |
| `special/pro_foreign_awakening` | “外面其实没毒”的思潮觉醒（旧硬盘发现线） |

## 1. 清洁与外部（pro_foreign 轴核心事件源）

### 1.1 “想出去”死刑链【原著明确】

- 桥段：任何角色公开表达“想出去”→ 不可撤销地送出清洁 → 全堡围观死亡以强化信条。
- 机制内核：信条的自我再生产——处刑本身是宣传。
- 映射：可作为 `rules` 事件：当某部门恐慌高且有 pro_foreign 觉醒者时触发“公开清洁”，短期压恐慌、长期积累 history burden / 合法性损耗。

### 1.2 拒洁者走出视野【原著明确】+【改编侧抽象】

- 桥段：清洁者拒绝清洁、走出摄像头视野；全堡目击“他没死”。
- 机制内核：单一不可解释事件瞬间击穿信条；邻堡叛乱可以由此点燃。
- 映射：`special` 事件链起点：触发条件=防护服质量（Mechanical 暗助）+ 处刑对象特质；后果=pro_foreign 思潮跳变 + 叛乱值上升；应急手册的“准备战争”预案可作为后续 `crisis`。

### 1.3 真相广播与记忆管制【改编侧抽象】

- 桥段：叛乱方劫持全堡屏幕播放外部绿景；当局对目击者投“焦虑治疗药”抹忆。
- 机制内核：真相传播 vs 记忆管制的竞速。
- 映射：`special` 事件，双分支：投药成功→恐慌下降但合法性暗损（隐藏计数器）；投药失败→思潮不可逆转变。已有 `archive_truth_broadcast` 可扩展此分支。

### 1.4 头盔幻觉与胶带阴谋【原著明确】

- 桥段：清洁者看到的绿世界是面罩投影；防护服被 IT 用劣质胶带暗中做成必死品；气闸“惰性气体”实为纳米虫。
- 机制内核：处刑工具的供应链是 IT 的暗权；Mechanical 换胶带=底层技术对顶层垄断的第一次反杀。
- 映射：`player_action`（Mechanical 背景特工）：“暗中改良防护服”——改变后续清洁事件结局概率；IT 阵营可反制（审计胶带库存）。

## 2. 大革命与记忆政治（history burden 轴核心事件源）

### 2.1 自我污名化重置【改编侧抽象】

- 桥段：IT 主管为阻止上级清洗，主动焚书、清空服务器、向供水投记忆药，再把一切嫁祸给叛军；自己身败名裂，后代被罚做苦役。
- 机制内核：“拯救者被写成罪人”——官方叙事与真实历史的永久背离；被抹掉的历史成为 history burden。
- 映射：`histories` 事件模板：叛乱临界时，IT 特工可发动“自我污名化重置”：叛乱清零、信息碎片清空、但埋下 N 年后觉醒的定时事件（对应 `history_burden_awakened`）。

### 2.2 加密档案与解码钥匙【改编侧抽象】

- 桥段：真相被写成加密档案，解码需要特定一本书的指定页；百年后由法官→IT→矿役犯逐手破译。
- 机制内核：真相以碎片形式跨世代接力（对应游戏的“信息碎片”系统）。
- 映射：`histories` 收集链：存储介质（碎片 A）+ 特定书籍（碎片 B）+ 解码者（技术角色）= 解锁“多堡网络与终止机制”情报，开放新的结局路线。

### 2.3 年度纪念仪式【改编侧抽象】

- 桥段：每年庆祝“平叛胜利”：漂浮灯、楼梯滑梯、市长演说；官方戏剧重演被篡改的历史。
- 机制内核：仪式化记忆——合法性维护工具，但也是真相派的渗透窗口。
- 映射：周期性 `rules` 事件：凝聚力小幅恢复；若 history burden 高，则有概率在庆典中触发“记忆闪回”（觉醒事件）。

### 2.4 记忆保存网络与地下日记【改编侧抽象】

- 桥段：民间网络以儿童旅行指南等遗物保存旧世界记忆，被投药与绝育式镇压；运输工的日记记载了镇压规模与死亡人数。
- 机制内核：记忆保存者=活的 history burden 载体；被镇压越狠，觉醒时爆发越强。
- 映射：`special` 事件：发现记忆保存节点→选择镇压（合法性+ / 未来叛乱风险+）或默许（信息碎片+ / 秩序派不满+）。

## 3. 部门政治与堡内战（部门/阵营事件源）

### 3.1 百层下行面试【原著明确】

- 桥段：市长与副手徒步下行 100 层到 Down Deep 面试机械师——一次“上层亲自下去”的政治姿态。
- 机制内核：垂直距离=政治成本；亲临底层是合法性投资。
- 映射：`player_action`（市长/特工）：“下行巡视”——消耗时间/体力，换取 Mechanical 忠诚度与情报。

### 3.2 代理市长夺权链【原著明确】

- 桥段：市长死亡 → 依公约由 IT 主管自动代理 → IT 借此清洗异己、安插傀儡。
- 机制内核：继承规则是政变的合法外衣。
- 映射：`rules` 事件：任何市长死亡事件后自动评估“代理接任”分支；合法性低的代理市长会触发部门不合作（生产力惩罚）。

### 3.3 堡内战剧本【改编侧抽象】

阶段化桥段：

1. 嫁祸与通缉（把政敌之死嫁祸给机械部门）；
2. 断供围困（停止向下层配送）→ 反被夺农场层；
3. 路障推进（逐层拉锯）；
4. 眼线战（胁迫技术人员做眼线、用手语演假情报骗过监控）；
5. 炸断楼梯（物理分割地堡）。

- 机制内核：垂直地堡的内战=逐层争夺的战线 + 后勤（食物/水）+ 信息战。
- 映射：`crisis` 事件链“堡内战”：以楼层为战线，每回合结算补给与士气；炸楼梯=不可逆的地堡分割（上下两区独立结算，直到修复）。

### 3.4 法官弹劾威胁【改编侧抽象】

- 桥段：公约规定法官弹劾条件；“威胁弹劾”本身就足以迫使 IT 主管让步——结果逼出谋杀。
- 机制内核：程序性制衡在威权下的异化。
- 映射：`player_action`（Judicial/特工）：“发起弹劾动议”——不必然成功，但改变 NPC 行为（可能诱发对方极端行动）。

## 4. 指挥堡与存亡级事件（结局源）

### 4.1 分层输送管网【改编侧抽象】

- 桥段：指挥堡通过实体管网向失守地堡泵毒；唯一反制=找到并封死对应管段。
- 机制内核：悬在头顶的处刑开关 + 一条可被工程手段切断的命脉。
- 映射：终局级 `crisis`：叛乱值突破阈值 → 终止倒计时；玩家可在倒计时内完成“封管”任务链（需要 Mines/Mechanical 协作 + 牺牲），否则全堡终止（坏结局）。

### 4.2 重置 vs 终止的抉择【原著明确】+【改编侧抽象】

- 桥段：指挥堡面对叛乱的两档处置：重置（减口+抹忆+清档）或终止（全灭）；本地 IT 的自我清洗是第三选项。
- 机制内核：统治者面对的“成本排序”：杀光 > 洗脑 > 让步。
- 映射：多结局分支判定：叛乱强度 × 信息碎片暴露程度 → 触发重置结局（游戏继续但记忆清零、历史包袱清零+暗埋）或终止结局（Game Over）。

### 4.3 Silo 40 的断联战争【原著明确】

- 桥段：Silo 40 率 11 堡切断与指挥堡的联络、干扰终止信号，把“反抗”输出给邻堡；指挥堡被迫物理轰炸。
- 机制内核：跨堡串联是指挥堡唯一无法远程解决的局面——也是玩家（若扮演多堡视角）的“联盟结局”原型。
- 映射：`histories` 事件“邻堡断联”：某编号地堡停止应答→思潮事件（pro_foreign/恐惧双向波动）；与项目名 Silo40 直接呼应，可作彩蛋或主线。

### 4.4 隐藏指令通道的祛魅【改编侧抽象】

- 桥段：IT 主管用自首试探，证明隐藏指令通道并非全知系统，而是“有人在说话”——“人是可以被打败的”。
- 机制内核：对不可见权威的祛魅=终局反抗的心理前提。
- 映射：`special` 事件链终点：积累足够信息碎片后，玩家可解锁“通道背后是人”情报，开放“对抗指挥堡”结局线。

### 4.5 掘进机与 Seed【原著明确】

- 桥段：堡底封存的掘进机全部指向 Seed；机械师挖通邻堡隧道救了约 200 人，也招来本堡的毁灭；最终幸存者徒步穿越毒尘带抵达 Seed。
- 机制内核：建造者留下的出路一直存在，只是没人被允许知道；逃生与毁灭同源（隧道既是生路也是靶子）。
- 映射：**最佳真结局模板**：需要（a）堡底 cavern 情报（信息碎片）、（b）Mechanical 修复掘进机、（c）承受指挥堡的报复窗口、（d）带队穿越毒尘带。失败分支=隧道被炸/毒气灌入（对应 `silo1_fallout`）。

### 4.6 反派公开赴死【改编侧抽象】

- 桥段：前 IT 主管公开自首、认领一切罪名以换取停止投药，无防护服走向外面，死于枯树下，临终想象绿叶与鸟鸣。
- 机制内核：反派以自我牺牲为反抗争取窗口——“注意力经济”式的最后行动。
- 映射：NPC 结局事件：高威望反派角色可触发“公开赴死”，效果=全堡注意力被吸引 N 回合，期间秘密行动成功率大增。

## 5. 结局母题总表

| 结局母题 | 原型 | 触发轮廓 | 基调 |
| --- | --- | --- | --- |
| 终止（远程毒剂/管网） | 原著与改编多处地堡命运 | 叛乱失控 + 封管失败 | 坏结局 |
| 重置（抹忆续命） | 2212 年重置；改编侧大革命后重置 | 叛乱临界 + IT 选择重置 | 循环结局（新周目，记忆清零） |

## 6. 写作注意事项

1. 采用设定前先查 01/04 篇确认该设定属于原著结构还是改编侧抽象，避免混搭。
2. 标注【存疑】的桥段（如分层管网拓扑、地下日记死亡人数）落地前建议复核原著或项目配置。
3. 台词层面不要照搬原著或改编原文（版权），只借结构与意象。
4. 改编侧后续季播内容播出后，第 4.5/4.6 等“尚未改编”桥段需重新对照，避免把新剧情误当原创。
