## 0. 摘要

1. **第一裁决（§1）**：被经营的偏置必须**注入 22 系列既有观测管线**，禁止并行假数据通道。三条理由：22-00 裁决 9 规定观测管线是 `b_s` 的唯一写者；并行流会在 1 号侧形成两套互相矛盾的观测，矛盾本身免费送给 1 号拆穿线索，违背「单次看都无害」的设计目标；注入复用既有 RNG 消耗位点，parity 与实现成本最低。
2. **注入映射总表（§2）**：六通道（equipment / schedule / reports / ledger / census / timing）的 `(Cov_c, Bias_c)` → 22 管线确切注入点的完整映射，覆盖两条管线：22-01 §5.2 三信号管线（改产生侧参数 `p_disg_eff / d_k_eff / σ_k_eff`）与 22-02 §3 观测量 a–g 似然管线（改 `se / sp / λ_true / q_fc / H / p_flip / ΔE_show`）。
3. **确定性保证（§3）**：注入是**零 RNG 的确定性映射**，只改分布参数、不改抽样结构——4.65 仍是每信号 1 次伪装判定骰 + 2 次噪声取样，消耗次数与顺序逐位不变。由此「功能开启时消耗位点不变、功能关闭时逐位不变」成立（§3.3 论证）。
4. **φ 与盲区状态的关系（§5）**：22-02 §4 的标量 `φ`（动机 × 能力）继续作总门；本系列的 `(Cov_c, Bias_c)` 是 `φ` 的**通道分解与累积**——`φ` 决定「愿不愿意、有没有能力伪装」，盲区状态决定「伪装分布到哪些通道、积累了多深」。合成规则 `φ_c = clamp01(φ·h(Cov_c))`，`h(0)=1` 保证零状态恒等。22-02 §4.5 的共享隐变量从单一 `φ` 扩展为 `(φ, {Cov_c, Bias_c})`：真值侧仍是点质量（有限和性质不变），但 1 号侧不执行该边缘化（零感知原则），模型误设正是经营收益的来源。
5. **1 号侧零感知（§6）**：注入全部发生在世界侧产生端；1 号侧（2b）改动 = 0 行——不读任何盲区状态、不新增参数、照常按自己的似然模型处理被污染的观测。唯一例外（04 卷拆穿产生的强观测）仍然是「观测管线内的一条观测」，不开第二写者。
6. **开关语义（§8）**：本系列功能建议作 22 黑箱总开关下的**子开关**；子开关关闭时注入退化为恒等映射、相对 22 基线逐位不变。盲区状态存档字段归属 04 卷，零值 = 未经营 = 恒等映射 = 旧档逐位不变。

统一符号沿用 22 系列，不另起：`r`、`Θ`（`self_preservation`·自保）、`E`、`b_s`（N=20）、`φ`、`G`、`R_op`；三信号 `receipt_delay / execution_gap / line_tone` 及其 `δ_k / σ_k / d_k` 参数（22-01 §5.2）；观测量 (a)–(g) 及其似然参数（22-02 §3）。本卷新增符号仅限 §2.1 的注入约定量（`ι_c`、`ῑ_k` 与诸注入系数），全部派生于 04 卷状态。

## 1. 第一裁决：注入既有管线，禁止并行假数据

**【裁决】** 被经营的偏置只能以「修改 22 管线产生侧分布参数」的方式注入，不得另建任何并行观测/假数据通道。本裁决是本卷其余全部内容的前提，与 22-00 的各条裁决一致。

### 1.1 理由一：22-00 裁决 9——`b_s` 的唯一写者

22-00 §4 裁决 9：「观测管线（4.65 产生 → 2b 信念更新）是**唯一写者**；决策层/探索层只读」。这条裁决划定了 1 号信念的单一事实来源。并行假数据通道只有两种落法，都违规：

- **并行流也写 `b_s`**：出现第二个写者，直接违反裁决 9；且两个写者的更新顺序、归一化与确定性纪律都要重新协调，22-01 §7 的复杂度与 RNG 规范全部失效。
- **并行流不写 `b_s`、另维护一套信念**：1 号同时持有两套信念，决策必须仲裁两者——仲裁规则本身又需要读两套输入，等于把裁决 9 的单一写者问题后移一层，还多出第二套似然模型（22-02 §3 之外再造一套），与 22-00 裁决 4 的双轨分离（真值审判 / 黑箱估计各一条轨）语义冲突——第三条轨没有裁决依据。

注入则天然满足裁决 9：偏置在世界侧产生端改写观测的分布参数，观测照常入队、照常由 2b 抽干，`b_s` 仍然只有一个写者。

### 1.2 理由二：并行假数据 = 免费送给 1 号的拆穿线索

本系列的设计目标是「**单次看都无害**」：每一条从被经营通道流出的观测，单独看都必须是一条平平无奇、符合 Order 报告体系常态的坏消息缺失/好消息。并行通道在结构上做不到这一点：

1. **两套观测必然互相矛盾**。并行流与真管线各自独立带噪（否则它就是无噪特权通道，违反黑箱前提）；两个独立噪声源对同一隐藏量给出的读数必然出现不可忽略的分歧。
2. **矛盾本身是信息**。22-02 §5.2 已证明：对单一偏置流，1 号唯一打破偏置的办法是制造对比（差分法）。并行流恰好**免费提供了一组现成的对比**——1 号无需抬 `r`、无需付出试探棘轮代价，只需比较两条流的响应差，就能定位「哪条流被动过手脚」。22-02 §5.3 论证的「测量即破坏」保护（差分必须付出 Θ 代价）被并行通道无偿绕过。
3. **矛盾升级出「通道被接管」的推断**。即使 1 号不做显式差分，22-01 §5.4 的伪装混合似然也会让「系统性偏低且互相打架」的两条流把后验推向「有组织的隐瞒」一侧——并行通道不是加深盲区，而是**生产拆穿盲区的证据**。

注入不存在这个问题：被污染的观测只有一条流，偏置混在噪声里（22-02 §5.2「伪装偏置不随平均消失」正是其收益机制），1 号没有任何免费对比可用。

### 1.3 理由三：parity 纪律与实现成本

- 注入复用 22-01 §7.3 的既有消耗位点：**零新增 RNG 消耗位点**。注入映射是确定性函数（零 RNG），只在既有取样之前修改被取样分布的参数。22-00 裁决 3 要求的「功能开启时重建基线」一次性覆盖本系列，不需要第二次重建。
- 并行通道则需要自己的一整套门控、逐堡顺序、消耗位点声明与 parity 口径（knowledge/08 §2/§7 的全部纪律重走一遍），实现成本与审计面都翻倍，且每新增一个消耗位点都是一次潜在的确定性事故面。

**被否选项**：并行假数据通道（上述三理由）；「在 2b 侧按盲区状态修正似然」（违反 §6 零感知原则，1 号侧读世界侧状态 = 读心，违反 ADR-0015）；「在延迟队列里替换已入队的观测」（改写已产生的观测等价于第二写者，且破坏 22-01 §5.3 的归因记录）。

## 2. 注入映射总表（本卷核心交付物）

### 2.1 注入约定量与通用纪律

04 卷状态（**以 04 卷为准**）：每堡每通道 `c` 维护盲区厚度 `Cov_c ∈ [0,1]`（该通道的信息在多大程度上已被本地经营接管/改写）与被经营偏置 `Bias_c`（该通道把数字向「平静/合规」方向系统性扭曲的养成深度；本卷假设其已归一化到 `[0,1]` 且非负——偏置方向固定朝「平静」，与 22-01 §5.2 伪装偏移 `−d_k`「把报告粉饰得更平静」的方向同构；若 04 卷采用带号或更高维的 `Bias_c`，注入式只需把 `ι_c` 换成相应投影，结构不变）。

本卷定义两个派生量：

```text
ι_c := Cov_c · Bias_c                    // 通道 c 的「有效经营量」∈ [0,1]
ῑ_k := Σ_c w_{k,c} · ι_c                 // 信号 k 的有效经营量（权重和为 1，固定通道序累加）
```

**通用纪律**（违反任一条即视为实现缺陷）：

1. **确定性**：注入是零 RNG 的确定性映射，输入只有常数（本卷参数表）与 04 卷存档状态；在既有 RNG 取样**之前**完成参数准备，不与取样交错。
2. **只改参数、不改结构**：注入只修改分布参数（概率、偏移、噪声尺度、似然参数），不改变抽样次数、顺序与队列结构。
3. **零状态恒等**：`(Cov_c, Bias_c)` 全零（含旧档零值、子开关关闭）时，全部注入式退化为 22 基线参数，逐位不变（§8 三层 parity）。
4. **固定累加序**：凡多通道加权求和，一律按本卷规范通道序 **equipment → schedule → reports → ledger → census → timing** 累加，禁止 map 遍历序，避免 ULP 漂移（knowledge/08 §2 Relations 先例的同口径约束）。
5. **逐项上限（cap）**：每个注入项都有显式上限；上限既是平衡护栏，也保证深经营下观测仍保留噪声外观（偏置藏在噪声里，「单次看都无害」）。
6. **动机门控**：所有加在似然参数上的偏置类注入项都含 22 管线自身的动机因子（管线 A 为 `p_disg(Θ')`——`d_k` 增量经伪装判定事件隐式门控；管线 B 为 `φ`）——`φ` 继续作总门（§5）。两类结构性例外：**噪声膨胀**只挂 `Cov_c`（盲区使信息失去真值锚定，无论有无伪装动机，经手改写的通道都积累口径噪声）；**(e) 表面服从脉冲**的放大不含 `φ`（22-02 §3.5 基线脉冲本就不经 `φ` 门控，经营放大保持同构）。

## 3. 管线 A：三信号管线（22-01 §5.2，4.65 产生侧）

### 3.1 注入形式与公式

22-01 §5.2/§7.1 的产生侧（4.65，读结算后 `Θ'`）：

```text
for k in [receipt_delay, execution_gap, line_tone] 升序:
    if k 当月不产生: continue
    disguised := DrawFloat64() < p_disg(Θ')          // RNG 消耗 1 次
    bias := disguised ? −d_k : 0
    η    := BoxMuller(DrawFloat64(), DrawFloat64())  // RNG 消耗 2 次
    y    := clamp01(Θ' + bias + σ_k·η)
    入队 {到达月 = 当月 + δ_k, 反映月 = 当月, k, y, seq}
```

注入**只替换三个分布参数**，循环结构、信号顺序、RNG 调用全部不动：

```text
ῑ_k      := Σ_c w_{k,c} · ι_c                                  // 固定通道序
p_disg_eff(Θ') := clamp01( p_disg(Θ') · (1 + b_p · ῑ_k) )      // 伪装概率（动机门控 = 其自身）
d_k_eff        := min( d_k + b_d · ῑ_k , d_k^cap )             // 伪装偏移
σ_k_eff        := min( σ_k · (1 + b_σ · Σ_c w_{k,c} · Cov_c) ,
                       σ_k · (1 + s_max) )                     // 噪声膨胀（只挂 Cov_c）
disguised := DrawFloat64() < p_disg_eff(Θ')                    // 仍是 1 次，同一位点
bias := disguised ? −d_k_eff : 0
η    := BoxMuller(DrawFloat64(), DrawFloat64())                // 仍是 2 次，同一位点
y    := clamp01(Θ' + bias + σ_k_eff·η)
```

| 系数 | 含义 | 推荐初值 | 理由 |

| `b_p` | 伪装概率的经营放大系数 | 1.0 | 满有效经营量（`ῑ_k=1`）使系统性粉饰概率翻倍（clamp 前）：经营使「粉饰」从主任的临机决定变成流程默认——概率项是最直接的承载 |

### 3.3 关键论证：为什么消耗位点不变、关闭时逐位不变

**结构不变性**：注入式与 22 基线的唯一差异是三个标量参数（`p_disg_eff ≥ p_disg`、`d_k_eff ≥ d_k`、`σ_k_eff ≥ σ_k`）的取值。`DrawFloat64` 的调用次数（每信号 3 次：1 判定 + 2 噪声）、调用顺序（信号类型升序、判定先于噪声）、比较与乘除的位置全部不变——22-01 §7.3 RNG 消耗规范表逐行成立。注入计算本身零 RNG，且发生在取样之前的参数准备段，不与消耗交错。

由此得到三层确定性结论（与 knowledge/08 §2 谈判层/筹备层先例同口径）：

1. **总开关关闭**（22 黑箱功能关）：4.65 整步跳过，零新消耗，与 v8 parity 基线逐位一致（22-00 裁决 3、22-01 §2.3-3）。本系列不改变这一层。
2. **总开关开启、子开关关闭**（§8）：注入退化为恒等映射，三个参数回到 22 基线值——同一 RNG 流、同一参数、同一比较，产生侧输出与 22 基线**逐位一致**。
3. **总开关开启、子开关开启**：消耗次数与顺序与第 2 层完全相同（位点不变），仅参数值不同导致同一随机数映射到不同的 `y`——这是数值差异，不是结构差异，不新增 parity 重建要求（§8.3）。

**门控语义**：注入的生效条件是 `总开关 ∧ 子开关 ∧ 04 卷状态已初始化`（§8.2），三者任一为假即回落到 22 基线参数。专线干扰（`network_jammed`）期间观测的产生与在途丢弃按 22-00 裁决 2 处理，注入参数不参与丢弃判定、不新增语义。

## 5. φ 与盲区状态的关系裁决

### 5.1 两层结构

**【裁决】** 22-02 §4 的 `φ = φ0 + M(Θ)·C(G, R_op)` 继续作**总门/动机层**；本系列的 `(Cov_c, Bias_c)` 是 `φ` 的**通道分解与累积层**。两层回答不同的问题：

| 层 | 量 | 回答的问题 | 时间形态 |
| --- | --- | --- | --- |
| 动机/能力层（22-02 §4） | `φ`（标量） | 愿不愿意、有没有能力伪装；本月总伪装意图多强 | 瞬时：当月 `(Θ, G, R_op)` 的函数 |
| 分布/累积层（本系列） | `(Cov_c, Bias_c)`（六通道向量） | 总意图分布到哪些报告通道；每个通道的长期经营积累了多深 | 累积：月度簿记（动力学与存档以 04 卷为准） |

动机层是「水龙头」，累积层是「管网」：水龙头决定有没有水流，管网决定水流到哪些出口、各出口的水压积累了多久。`φ=0`（无动机或无能力）时，再深的管网也没有水——无可隐藏时（低 `Θ` 真照办），被经营的通道也如实传输，全部偏置类注入项为 0（噪声膨胀与 (e) 脉冲放大为结构性例外，§2.1 纪律 6），这与 22-02 §4.1「低 Θ 无可伪装」完全一致。注意 `φ` 的实际下界是惯性基线 `φ0=0.1`（22-02 §4.2）：被经营通道在无针对性动机的堡里仍有一小份惯性官僚伪装——经营出的流程自己会运转，但份额小。

### 5.2 合成规则

通道 `c` 的**有效伪装强度**：

```text
φ_c = clamp01( φ · h(Cov_c) )
h(Cov) = 1 + a_h · Cov^α_h
```

| 系数 | 推荐初值 | 理由 |
| --- | ---: | --- |
| `a_h` | 0.5 `TODO(balance)` | 满盲区厚度（`Cov=1`）使通道有效伪装强度至多 ×1.5；深盲区里伪装更省力（流程代办、脚本现成），同样的动机产出更强的通道级伪装 |
| `α_h` | 0.7 `TODO(balance)` | 凹形（边际递减）：盲区基础设施的通道收益递减——第一个改写环节收益最大，其后每层加码的收益下降 |

约束性质：

1. `h(0) = 1` → `φ_c|_{Cov=0} = φ`：零状态恒等（§2.1 纪律 3）在合成规则层面同样成立。
2. `φ` 仍是上界来源：`φ=0 ⇒ φ_c=0`，总门语义保持（动机门控，§2.1 纪律 6）；`φ` 的实际下界 `φ0` 见 §5.1。
3. `φ_c` 是本卷对「通道有效伪装强度」的**汇总表述**；§3/§4 的具体注入式采用与之等价的「基线项 + 经营增量项」展开形式（例如 `φ·(q_fc + b_c·ι)` 即 `φ` 乘上通道放大），保证每个注入点独立 clamp、不越界。
4. **预算守恒问题**：22-02 中 `φ` 是各观测量**共享的强度**（§4.5 共享隐变量），不是切分的预算，故逐通道放大不违反 22 模型内的任何守恒。但若 03/04 卷的预算模型（`R_op` 消耗、手段成本）要求「全通道伪装强度之和 ≤ 能力上限」的守恒，则需追加归一化层（如 `φ_c ← φ_c·φ/Σφ_c`）——本卷暂不加，交主线裁决（§10 遗留 #1）。

### 5.3 相关性修正的演进（22-02 §4.5 在本系列下如何变）

22-02 §4.5：同月多观测量共享隐变量 `φ`，噪声不正独立；1 号按公共 `φ` 边缘化 `P(y_a,y_b,...|Θ,r) = Σ_φ P(φ|Θ)·Π_x P(y_x|Θ,r,φ)`；因 `φ` 是 `(Θ, G, R_op)` 的确定性函数，该边缘化是有限和。

本系列下，真实数据生成过程的共享隐变量扩展为 `(φ, {Cov_c, Bias_c})`：

1. **真值侧：有限和性质数学上保持**。`φ` 是 `(Θ, G, R_op)` 的确定性函数（22-02 §4）；`{Cov_c, Bias_c}` 是 04 卷确定性累积（零 RNG 月度簿记）。给定完整世界状态，联合分布仍是**点质量**——「有限和」退化为单点，性质不变。
2. **1 号侧：不执行、也不能执行该边缘化**。执行它需要读盲区状态（禁止读心，ADR-0015），或对六通道 × 两量维护信念分布并逐月更新——即使每量只离散 3 箱，组合空间 `3^12 ≈ 53 万`，且需要先验与更新模型，等于让 1 号「知道盲区存在并估计其深度」，与零感知原则（§6）冲突，也极易滑向准读心。
3. **结论**：1 号继续使用 22 的单 `φ` 边缘化（2b 代码零改动，22-01 §5.4 的伪装混合与 22-02 §3 的似然族原样运行）。由此产生的**模型误设**——1 号假设的伪装上界是 `φ`，而真实通道偏置达到 `φ·h(Cov_c)` 加经营增量——正是盲区经营产生收益的机制：22-02 §5.2「伪装偏置不随平均消失」依然成立，且后验向「合规剪影」收敛得更快、更深。1 号的对策（若未来引入通道健康度信念）需另立专题（§10 遗留 #4）。

注入不修改信息停滞判据（连续 `N_stall` 次试探后验无实质变化 → 强制冷却）。深经营通道的效果是**让信息停滞更早、更频繁地发生**——这正是 22-03 该条款预言的场景（「该堡的观测信道可能已被伪装完全接管」），本系列为其提供了组织化的产生机制，判据本身零改动。

## 8. 开关与存档语义

### 8.1 存档字段归属

`(Cov_c, Bias_c)` 的字段定义、存档归属、版本号与升级器全部归 **04 卷**（以 04 卷为准）。本卷对存档的唯一要求：

1. 字段在观测产生相位（4.65 与各观测量世界侧结算点）可读；
2. **零值语义**：字段零值 = 未经营 = `ι_c = 0` = 注入恒等映射——旧档升级后行为逐位不变（与 22-01 §8「零值 = 功能未启用 = 旧档语义」同口径）；
3. 读取按 §2.1 纪律 4 的固定通道序。

### 8.2 开关裁决建议：同一总开关下的子开关

**【裁决建议】** 本系列功能不作独立总开关，而是 22 黑箱功能总开关之下的**子开关**（`blindspot_injection_enabled`）。生效条件：

```text
inject_active := blackbox_enabled ∧ blindspot_injection_enabled ∧ 04 卷状态已初始化
```

理由：

1. **寄生性**：注入只作用于观测管线的分布参数；总开关关闭时管线本身不运行（4.65 跳过、2b 黑箱回合跳过），子开关无所附着。若设为平行独立开关，等于为「不存在管线时的注入」定义语义——必然引出独立门控与独立 parity 口径，与第一裁决矛盾。
2. **二层粒度满足关闭纪律**：子开关关闭 → 注入恒等映射 → 相对「总开关开启的 22 基线」逐位不变（§3.3 第 2 层），在第二层粒度上复现 knowledge/08「功能关闭零变化」的纪律形态。
3. **事故面最小**：子开关零 RNG（注入是确定性映射），其开/关不改变消耗结构，只改变参数值——确定性事故面限于数值差异，不存在「消耗位点漂移」类事故。

子开关默认值建议：**开**（否则本系列恒为空转）。默认值最终随 04 卷合入时的配置口径定，登记备查。

### 8.3 三层 parity 口径

| 层 | 开关状态 | 轨迹口径 |
| --- | --- | --- |
| 1 | 总开关关 | 4.65/2b 黑箱步骤整体跳过，零 RNG 消耗 → 与 v8 parity 基线逐位一致（22-00 裁决 3，本系列不改变此层） |
| 2 | 总开关开、子开关关 | 注入恒等映射 → 参数与 22 基线相同，同一随机数产生同一观测 → 相对 22 基线逐位一致 |
| 3 | 总开关开、子开关开 | 消耗次数与顺序同第 2 层（位点不变），仅参数值不同 → 无新增结构差异；22-00 裁决 3 要求的「功能开启重建基线」一次性覆盖本系列，基线按默认配置（子开关开）构建，不需要第二次重建 |

注：第 3 层相对第 2 层是「有意改行为」，按 knowledge/08 §5 口径，受控基线以固定配置构建；子开关作为配置项固定在基线配置中，其切换属配置对比，不属基线替换。

## 10. 遗留问题（交主线裁决项）

1. **`h(Cov)` 放大的守恒**：本卷暂不做「全通道伪装强度之和 ≤ 能力上限」的归一化（22 的 `φ` 是共享强度而非预算，模型内无守恒约束）。若 03/04 卷的预算模型要求守恒，需追加归一化层并回改 §5.2——交主线裁决。
2. **22-02 §3.7 与 §4.5 的表述张力**：§3.7 的翻转概率「均分给相邻档」（对称），§4.5 汇总表为「分档读数向『安定』漂移」（定向）。本卷按「基线对称 + 经营增量定向」实现，未推翻 22 任何表述；请主线澄清 22 口径（以 22 为准）。
3. **拆穿强观测的似然形式**：`σ`、`δ`、是否绕过伪装混合，待 04 卷定义；并请主线确认其「观测管线内的一条观测」归属（与 22-00 裁决 9 的一致性已由 §6.2 论证）。
4. **1 号侧通道健康度信念**：是否允许 1 号未来对 `{Cov_c}` 维护信念（扩展 22-02 §4.5 边缘化空间）。首版不做（§5.3 组合爆炸 + 零感知原则）；若立项，需重写 2b 似然结构与 parity 口径，另立专题。
5. **制度性自主偏置**：本卷裁决经营增量项受动机门控（`φ` 或 `p_disg(Θ')` 因子），`φ→0` 时无偏置。若 04 卷累积动力学产生「流程自主运转」语义（无当月动机也维持偏置，仅靠 `φ0` 惯性份额不够），需主线裁决是修改门控形式还是修改 04 卷语义。
6. **22-02 §3.4 `q_h` 无推荐初值**：`H = φ·q_h·(…)` 中 `q_h` 未给起点值。本卷 (d) 注入以相对放大形式定义、不受阻；`q_h` 初值归 22 实现轨/sim。登记为 22 表述缺口（非本系列新增缺口）。
