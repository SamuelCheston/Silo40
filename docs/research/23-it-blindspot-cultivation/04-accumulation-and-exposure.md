## 0. 摘要

1. **累积状态是逐堡、逐通道的世界侧簿记**。本系列固定六通道：`equipment`（监控设备）、`schedule`（盲区排班）、`reports`（报表计量）、`ledger`（回执账本）、`census`（人口物资普查）、`timing`（上报时机）。每通道一个**盲区厚度** `Cov_c(t) ∈ [0,1]`，01/02 卷声明的手段月度增量经 03 卷力度缩放后累入，带衰减（时间常数 `τ_cov` 建议 30 月，**短于** Θ 的 `τ_decay=48` 月——盲区比戒心更容易被人员轮换、设备更换、口径重定义磨掉）。
2. **被经营偏置 `Bias_c(t)` 是 22-02 §5.2「偏置不随平均消失」论证的世界侧来源**：它随 `Cov_c` 生长，方向恒定向「合规/安定」一侧（单向过滤器，不是零均值噪声），在观测产生（22-01 §2.2 的 4.65 步骤）处注入对应观测量。22-02 的 `φ` 是**当月主动伪装流量**，`Bias_c` 是**累积进报告管线本身的结构性偏置存量**——主任换了、当月没演戏，偏置仍在。
3. **痕迹账本**是拆穿的原料：每次手段使用在世界侧留下可追溯痕迹（维修单、口径变更记录、回执统计形状……），保留期 36 月量级。1 号不能直读账本，只能通过稽查抽样与统计形状间接捕捉。
4. **失真不是一次性错，是几十个月的缓慢锁定**：单次手段偏置 ≈0.002 ≪ 观测噪声 σ≈0.10–0.18，完全不可见；持续经营 30–40 月后多通道偏置叠加到 0.10–0.15（2–3 个箱宽），1 号后验被逐月推入「合规剪影」箱。22-01 §5.1 的 ε 地板只保证真值箱概率永不归零（可恢复），**不保证估计归零**——只要观测持续被同一方向的偏置过滤，每月观测都在给错误箱加似然。
5. **跨通道互相掩护是累积的高级形态**：报表圆普查、回执圆报表——同源偏置在交叉验证的**差值**中互相抵消，1 号的交叉核对读到「一致」，反而强化了错误信念。能打破闭环的只有真值锚定通道（Protocol review 读真值、物资消耗真值）与爆发期强观测。
6. **怀疑计数器 `Susp_s(t)` 慢累积、权重式、不是阈值开关**：单次破绽几乎不动它（最强单源证据增量也够不到查证线）；从零到触发需数十月计。怀疑度经**权重式耦合**抬高该堡在 22-03 探索层的探索优先级与不确定性 `U_s`，不直接改 `r`、不直接写 `b_s`。
7. **分阶段拆穿**：起疑（交叉验证开始）→ 查证（针对性稽查，本地进入「迎检」状态——迎检压低证据产出，但骤变本身留下新证据）→ 坐实（窗口内 ≥2 个独立来源证据汇拢，或 Protocol 制度化穿帮与低箱剪影的对照）。任何单一破绽不得直接触发拆穿。
8. **拆穿后果全部走既有通道，不新造惩罚机制**：信任崩塌表达为一条高质量负向观测注入观测管线（裁决 9：`b_s` 唯一写者是管线）；更严监控经 22-03 探索层参数；惩罚经 Protocol 介入链（`warning → correction → override → assessment`）与既有反应链口径；**Θ 不加任何新写入口**——拆穿后 Θ 上升只能是「1 号抬 `r` → Θ 按既有动力学自然上涨」的间接链（§4.4）。
9. **确定性归属**：本卷全部累积更新（`Cov`/`Bias`/痕迹/`Susp`/阶段转移/重置）是**零 RNG 世界侧簿记**；与本卷相关的随机性只有两处——03 卷决策抽取（唯一新增 RNG 消耗点，归属 03 卷声明）与既有失控骰/暴露骰位置（22-02 §4.4，本卷只消费其结果）。功能关闭 → 全步骤跳过 → parity 逐位不变（22-00 裁决 3/11 口径）。

**统一符号**（不得另起，22-00 §2）：`r` 风险度、`Θ` 自保（隐藏量）、`E` 执行强度、`b_s` 1 号 N=20 分箱后验、`φ` 伪装强度（22-02 §4）、`G` 认知梯度、`R_op` 本地 IT 操作资源、`L` 1 号问责量、`A(t)` 1 号注意力预算；22-02 §2 观测量 (a)–(g)。本卷新增量一律带下标：`Cov_c`/`Bias_c`（逐通道）、`Susp_s`（逐堡）。

### 1.2 盲区厚度 `Cov_c(t)`

**递推**（月度，世界侧簿记，零 RNG；形式刻意仿 22-01 §3.2 候选 A 的加性结构）：

```text
Δcov_c(t) = min( Σ_{当月作用于 c 的手段} u_m · Δcov_base,m ,  δ_cap )     // 同月多手段叠加上限
若 t < ChannelResetMonth_c + T_guard：Δcov_c(t) ×= (1 − q_guard)          // 拆穿后守卫期（§4.5）
Cov_c(t+1) = clamp01( Cov_c(t) + Δcov_c(t) − Cov_c(t)/τ_cov )
```

**参数**（均 `TODO(balance)`）：

| 参数 | 推荐初值 | 理由 |
| --- | --- | --- |
| `τ_cov` 衰减时间常数 | **30 月** | 硬要求：**短于** Θ 的 `τ_decay=48` 月——「盲区比戒心更容易被翻新磨掉」：人员轮换带走操作习惯、设备到寿更换、Order 重定义口径，都会磨掉旧盲区；而戒心是对施压经历的记忆，翻新磨不掉。半衰期 ≈21 月 |
| `δ_cov` 单次手段月度增量基准 | **0.02**（强度 1） | 01/02 卷各手段按 0.005–0.03 量级带声明；单次手段收益必须极小（§2.3 M0） |
| `δ_cap` 单通道单月增量上限 | **0.03** | 边际递减：同月多手段堆同一通道不爆炸，防「一月速成盲区」 |
| `T_guard` 拆穿后守卫期 | **18 月** | 被拆穿通道刚换过口径/设备/核查方式，重建盲区慢且被盯着（§4.5） |
| `q_guard` 守卫期增量折减 | **0.5** | 与上配套 |

**平衡厚度推导**：

- **持续经营**（每月恒定增量 Δ）：令净增为 0，`Cov_eq = min(1, Δ·τ_cov)`。取 Δ=0.02、τ=30 → `Cov_eq = 0.6`。趋近过程 `Cov(t) = 0.6·(1 − (1−1/30)^t)`：t=12 → ≈0.20，t=24 → ≈0.33，t=36 → ≈0.42，t=48 → ≈0.48，t=60 → ≈0.52。**厚到足以锁定后验的盲区（§2 定量）需要 30–40 月以上的持续经营**——这正是「单次收益极小、累积几十个月才构成盲区」的形式化。
- **放任衰减**（Δ=0）：`Cov(t) = Cov_0·(1−1/30)^t ≈ Cov_0·e^{−t/30}`。从 0.5 起：21 月 → 0.25，45 月 → 0.11。停手不立刻暴露（存量还在掩护），但盲区以月可见的速度变薄。
- **离散翻新冲击**（设备更换令、Order 口径重定义等内容事件）：表达为对 `Cov_c` 的一次性侵蚀增量，走既有内容事件效果通道（`silo_metric_delta` 对 `SafeguardRisk` 叠加的同款先例，22-00 §5-1）；本卷只声明接口，不发明事件。

### 1.3 被经营偏置 `Bias_c(t)`

22-02 §5.2 已论证：伪装扭曲是**系统性偏置**而非零均值噪声，`N→∞` 时后验收敛到错的箱；该卷未给这个世界侧偏置的动态来源。本卷补上：**偏置是盲区厚度的函数**——通道上的盲区越厚，经该通道上报的观测被过滤得越狠。

```text
Bias_c(t) = b̄_c · Cov_c(t)^γ_b          // γ_b = 1.0（线性起点，TODO(balance)，留 sim 调曲率）
```

| 参数 | 推荐初值 | 理由 |
| --- | --- | --- |
| `b̄_c` 单通道偏置上限 | **0.10** | 2–3 个通道叠加到同一观测量 ≈ 0.2–0.25，对齐 22-02 §5.0 的伪装偏置上限 `b_max≈0.2` 量级；单通道封顶防独大 |
| `B_max` 单观测量总结构偏置上限 | **0.25** | 多通道叠加截断，量级与 22-02 `b_max` 一致 |

**注入位置与方向**：观测产生（22-01 §2.2 步骤 4.65，世界侧）处，观测量 `k` 受其通道集 `C(k)`（§1.1 映射）的结构偏置，总偏置 `B_k = min(Σ_{c∈C(k)} w_{k,c}·Bias_c, B_max)`，**方向恒定向合规/安定一侧**（与 22-01 §5.2 伪装偏移 `−d_k` 同号）：

```text
y = clamp01( Θ' − B_k − (当月伪装 ? d_k : 0) + σ_k·η )
```

**为什么不是零均值噪声**（世界观论证）：

1. **单向过滤**：盲区手段只藏坏消息、从不造坏消息，只压坏消息、从不压好消息——扭曲的期望带符号，符号由本地执行链的利益结构（让上面看不到偏离）决定，不由物理偶然决定。设备漂移、人员更替带来的噪声是双向的，会被平均掉；经营性过滤不会。
2. **存量不随人员平均**：经营成果沉淀在口径、排班表、维护规程与回执格式里。搭建者调走，继任者继承的是**已经偏了的流程**——偏置跨人员存续，22-02 §4.5 所说的「φ 是共享隐变量、同月各通道同步失真」在这里有了跨月的存量对应物。
3. **与 φ 的分工**：`φ` 是当月主动伪装的**流量**（动机×能力，随 Θ、G、R_op 起伏，22-02 §4.1–4.3）；`Bias_c` 是累积进管线的**存量**——低 `φ` 月份（主任没在演戏）偏置照样生效。两者叠加，不互相替代。

### 1.4 痕迹账本（拆穿的原料）

每次手段使用在世界侧留下可追溯痕迹。**这是事实层**：1 号侧永远不能直读账本，只能通过稽查抽样（22-02 §3.1 的 `n` 抽样）与统计形状（§3.1 检测量）间接捕捉。

```text
TraceEntry { Year, Month int      // 发生月
             Channel string       // 六通道
             Kind string          // 痕迹类型（见下表）
             Magnitude float64    // 痕迹量级 ∝ 手段力度 u
             Seq int }            // 堡内单调序号（排序键）
```

| 通道 | 典型 `Kind` | 统计形状破绽（供 §3.1 检测量） |
| --- | --- | --- |
| `equipment` | `repair_slip`（维修单）、`calibration`（校准记录） | 故障间隔过于均匀（CV→0）、总在同类时段 |
| `schedule` | `roster_change`（排班变更） | 关键岗位长期固定同一批人、调整总赶在稽查前 |
| `reports` | `standard_change`（口径变更） | 变更总在上报期限前、缺项恰好避开抽验范围 |
| `ledger` | `receipt_shape`（回执统计形状） | 完成率方差过小（过于稳定）、时间戳集中在月末 |
| `census` | `census_diff`（底册与汇总差） | 同一缺口连续多期出现、口径变更未报备 |
| `timing` | `submit_time`（上报时点） | 坏消息与上级关注节奏高度负相关 |

**保留与衰减**：保留期 `T_retain = 36` 月 `TODO(balance)`（纸面档案归档量级，也是统计形状检测的窗口长度）；到期条目按月确定性移除。痕迹在保留期内**不衰减**——事实就是事实；会衰减的只是它对检测量的贡献（窗口滑出）。账本按月 `(年, 月, 通道, Seq)` 升序维护，零 RNG。

## 2. 1 号估计如何逐渐失真（不是一次性错）

### 2.1 偏置进入似然的位置：1 号模型之外的存量

22-01 §5.4 的似然含伪装边缘化：`L_i = (1−π̂(θ_i))·φ(y; θ_i, σ_eff) + π̂(θ_i)·φ(y; θ_i − d_k, σ_eff)`。1 号的 `π̂(θ)` 模型的是**主任当月粉饰**（流量，偏移 `d_k`），边缘化至多吸收 `d_k` 量级的偏移。**经营性盲区偏置 `B_k` 在 1 号的模型之外**——它不知道盲区经营这种玩法存在（这正是本系列的玩法增量），于是 `B_k` 中超出 `d_k` 吸收能力的部分把后验众数系统性拉低 ≈`B_k`：

- 结构偏置 `B_k` 与当月伪装偏移同向叠加，1 号的边缘化只能解释掉 `d_k` 份额，残差份额被当作「该堡本来就很平静」的证据。
- 这是「1 号会被骗」的精确机制：不是某条观测造假成功，而是**似然函数本身缺了一项**。

### 2.2 ε 地板防锁死，但防不住长期偏

22-01 §5.1 的先验带均匀地板 `ε=0.05`：所有箱严格为正，高斯似然全域支撑，任何箱永不归零锁死——「延迟、带噪、被伪装的信号始终有机会翻转任何先验判断」。本卷必须说明：**即使有地板，偏置仍让估计长期偏而不归零**。

定量（用 22 系列起点参数做示例推导，参数均 `TODO(balance)`；`σ_eff` 按 22-01 §5.3 延迟膨胀后 ≈0.11–0.18，取 0.14）：

- 被经营通道的观测 `y ≈ Θ_true − B + σ·η`。真值箱 `θ_t` 与错误箱 `θ_w = θ_t − B` 之间的单月对数似然比 ≈ `B²/(2σ_eff²)`。
- `B = 0.10`（≈2 箱宽）：≈0.26 nat/月 → 约 9 个月该通道观测把错误箱推到 10:1；`B = 0.15`（≈3 箱宽）：≈0.57 nat/月 → 约 4 个月。
- ε 地板的作用边界：它保证真值箱概率**永不归零**（单条强反证观测的贝叶斯因子有限但非零，恢复在原理上可能），**不保证真值箱能赢**——只要每月进入管线的观测仍被同向偏置过滤，似然比就持续朝错误箱累积；地板只把「锁死」推迟为「长期偏置」。
- 归零的唯一途径是**未被经营的观测**：Protocol 真值审判（制度读真值）、爆发期强观测（难以伪装）、稽查抽到未过滤的原始记录——这正是 §3 拆穿机制的三类来源。**地板保证门没焊死；拆穿机制负责有人去推门。**

### 2.4 与 22 系列的两处闭环

1. **对 22-02 §5.2 的闭环**：该卷论证「偏置不随平均消失」时，偏置是 φ 的静态函数；本卷给出其世界侧动态——偏置随 `Cov_c` 以月计生长、随停手以 `τ_cov` 计衰减、随拆穿清零。「试不出来」因此不只是伪装技巧问题，而是存量积累问题。
2. **对 22-03 §2.4 `N_stall` 的闭环**：信息停滞（连探后验不动）的机制解释在此——不是没有信号，是信号管道被结构性偏置接管；`N_stall` 的处方（旁证）是否有效，取决于旁证通道是否也被经营（邻堡传闻经 22-02 §3.4 低到达率通道，本身可被 `timing`/`reports` 间接污染）。

## 3. 拆穿机制（能用上很久）

**设计目标**：盲区要能用上很久——拆穿必须慢、必须权重式、必须多源汇拢；任何单一破绽（哪怕一次 Protocol 穿帮）都不直接触发拆穿。

### 3.1 怀疑的来源：检测量与判据形状

四类来源，每类给检测量（连续量，∈[0,1]）与判据形状（权重式，无硬门槛）。检测量全部由世界侧事实（真值、痕迹账本、1 号自己的信念与读回）确定性计算，零 RNG；权重 `w_*` 在 §3.2 的 `ΔSusp` 合成处统一施加。

**来源一 · 跨通道不一致 `e_cross`**：

- **普查口径 vs 物资消耗**：普查报告人口/物资与世界侧消耗真值反推的隐含量之差。消耗真值不可被报表经营（真值锚定通道），是最硬的一对。`Mismatch = |隐含量 − 报告量|/σ_pair`（`σ_pair` 为正常口径差预期，`TODO(balance)`）。
- **回执完成率 vs 稽查抽验**：(c) 自报完成率与 (a) 稽查抽出的实际完成之差（22-02 §3.1/§3.3 的残差）。
- **设备故障的统计形状**：维修单间隔的变异系数 `CV = σ_interval/μ_interval`——真实故障近似泊松聚簇（CV≈1），经营出来的「故障」间隔均匀（CV→0）、且集中在同类时段（众数时段占比超基线）。`e_eq = clamp01((CV_0 − CV)/CV_0) + 时段集中度项`，`CV_0≈0.8` `TODO(balance)`。
- 判据形状：`e_cross = clamp01( Σ_{通道对} w_pair · clamp01((Mismatch − m_0)/m_1) )`（`w_pair` 按通道对重要性分配，`TODO(balance)`；总证据截断在 1）。**关键性质**：两个被同源经营的通道配对时，偏置在差值中互相抵消，`Mismatch→0`——这就是「报表圆普查」为什么能解除怀疑机制；拆穿只能来自未被经营的锚定通道或偏置失配。

**来源二 · Protocol 真值审判穿帮 `e_proto`**：

- review 到点**读真实结果**（[protocol.go](../../internal/engine/protocol.go) L389-410「到 review 日读取真实结果，不看 IT 是否努力」；`order.json` O-01 读 rebellion、O-02 读 cohesion）——纸面瞒不住制度（22-00 裁决 4）。
- 穿帮 = **对照**：review 判出目标越界（`DeviationUnmet` 记录、`FailedReviews` 递增）而该堡纸面剪影仍在低箱（`Θ̂ < 0.30`，读 1 号自己的信念合法，非读心）。对照度 `= (1 − Θ̂)`：1 号越信它合规，穿帮越刺眼。
- 经营能做什么：`timing`/`census` 通道的盲区可以**延迟**穿帮时机（把坏消息压过 review 窗口、让真值在 review 日恰好落在界内）——但 22-00 裁决 4：伪装可**延迟**真值审判的触发时机，**不能消除「未达成」的事实**。未达成持续存在，review 每 3 月读一次真值，延迟只是把穿帮推迟到下一个窗口。
- 判据形状：`e_proto = 1[review 越界] · (1 − Θ̂)`（权重 `w_proto` 在 §3.2 合成处施加）；介入链升级到 `correction` 及以上且对照成立时，另计一次性强证据增量（§3.4 坐实条件）。

**来源三 · 爆发期强观测残差 `e_burst`**：

- 反应链期间难以伪装（22-03 §6.1「爆发即强观测」）：通牒响应、整肃执行中的真实姿态会露出来。
- 检测量：爆发响应实际值与「按当前 `b_s` 预期」的残差（预期用 1 号自己的信念与内部模型计算，合法）——一个「合规剪影」堡在通牒下表现出组织化的拖延或对抗，残差即证据。`e_burst = clamp01(|残差|/σ_burst)`，`σ_burst` `TODO(balance)`。
- 爆发观测本身按 22-03 §6.2-5 作为高质量观测入后验（归属观测管线），本检测量只负责怀疑侧记账。

**来源四 · 痕迹统计形状 `e_trace`**（来源一的补充，单列因其只依赖账本）：稽查抽样（22-02 §3.1 抽样强度 `n`）读到痕迹账本时，§1.4 表中的形状破绽转化为证据：`e_trace = clamp01(形状破绽合成)`（权重 `w_trace` 在 §3.2 合成处施加）。稽查强度 `n` 越大，抽到形状破绽的概率越高——怀疑与探索投入挂钩。

### 3.2 怀疑计数器 `Susp_s(t)`

```text
ΔSusp(t) = w_cross·e_cross + w_proto·e_proto + w_burst·e_burst + w_trace·e_trace   // 各证据 ∈[0,1]
Susp_s(t+1) = clamp( Susp_s(t) + ΔSusp(t) − Susp_s(t)/τ_susp , 0, 1 )
```

| 参数 | 推荐初值 | 理由 |
| --- | --- | --- |
| `τ_susp` 衰减时间常数 | **18 月** | 长期无破绽时回落（半衰 ≈12.5 月）；比单月证据持久，比盲区累积（τ_cov=30）短——怀疑比盲区更容易被时间冲淡，符合「用得好就能用上很久」 |
| `w_cross / w_proto / w_burst / w_trace` | **0.10 / 0.20 / 0.15 / 0.08** | 制度化穿帮最重（Order 自己的审判），跨通道不一致是基本盘，痕迹形状最弱（间接证据）；均 `TODO(balance)` |
| 单源证据上限 | 每次 `e ≤ 1` → 单源单月最大增量 ≈ `w_proto = 0.20`；介入链升级的一次性强证据增量 0.35（§3.4） | **单次破绽几乎不动它**：即使最强的单一事件，从零起也只够到起疑线之下 |

**量级校验**（从零到触发需数十月计）：持续的小不一致（`e_cross≈0.2`/月）→ ΔSusp≈0.02/月，平衡点 `Susp_eq = ΔSusp·τ_susp ≈ 0.36`，趋近时间常数 18 月——维持数十年才勉强爬到查证线附近；期间任何一次穿帮叠加才会实质推进。`TODO(balance)`，sim 校准。

### 3.3 权重式耦合：怀疑不是阈值开关

`Susp_s` **不直接触发任何处置**，它抬高的是 1 号在 22-03 探索层对该堡的投入权重（对接 22-03 §2.2/§7.1，只读接口，不写 `b_s`、不直接改 `r`）：

```text
不确定性膨胀：U_s' = U_s + u_susp · Susp_s          // 探索层读合并后的不确定性
审计间隔压缩：T_audit'(s) = max( T_audit_min, T_audit · (1 − q_audit · Susp_s) )
冷却压缩：    Susp_s ≥ θ_doubt 视为持续「外部触发」源（22-03 §2.2：可压缩冷却至
              C_probe_emergency，不可取消）
注意力权重：  该堡交叉验证/稽查的注意力配给 ×(1 + w_A · Susp_s)，A(t) 总量不变
```

| 参数 | 推荐初值 | 理由 |
| --- | --- | --- |
| `u_susp` | **0.5**（箱宽尺度） | `Susp=1` 时不确定性抬高半箱量级，足以推动探索而不越俎代庖 |
| `q_audit` / `T_audit_min` | **0.6 / 6 月** | 满怀疑时审计间隔压到下限 6 月，不压到 0（稽查本身有成本，22-02 §3.1） |
| `w_A` | **1.0** | 满怀疑时注意力配给翻倍 |

### 3.4 分阶段拆穿：起疑 → 查证 → 坐实

阶段是 `Susp` 与证据窗口的**形状判据**（连续量的累积结果），不是单一事件的开关。转移确定性判定，零 RNG。

**阶段一 · 起疑（`doubt`）**

- 进入形状：`Susp_s ≥ θ_doubt`（推荐 **0.20** `TODO(balance)`）。
- 行为：1 号开始对该堡交叉验证（§3.3 耦合生效）；玩家可见事实见 §5。
- 退出形状：`Susp_s < 0.12`（滞回退出线，防抖，`TODO(balance)`）→ 回到无阶段；或升级。

**阶段二 · 查证（`verify`）**

- 进入形状：`Susp_s ≥ θ_verify`（推荐 **0.40**）——需累积或多源证据；**最强单一证据（介入链穿帮增量 0.35）从零起也够不到查证线**，只能推进到起疑。
- 行为：针对性稽查/复核（22-02 §3.1 的主动观测，成本与自我侵蚀照付）；本地进入**迎检状态**。
- **迎检对拆穿概率的影响**：本地 IT 得知被查（稽查抵达是世界侧事实），临时收紧伪装并清理痕迹：
  - 证据产出抑制：稽查灵敏度 `se' = se·(1 − q_recv)`，`q_recv ≈ 0.4` `TODO(balance)`——等价于 22-02 §4 的 φ 临时增量 `Δφ_recv ≈ 0.2`（持续 = 稽查窗口 1–2 月；该增量的 φ 模型归并属实现轨对 22-02 §4 的扩展，本卷只给量与持续期）；
  - 但**骤变本身是新证据**：手段骤停、痕迹频率断崖（「维修单突然不来了」）记为 `Kind="abrupt_change"` 痕迹，供 `e_trace` 读取——迎检压低旧证据的产出，同时生产新证据，不是完美防御；
  - 迎检状态对 03 卷决策模型可见（被查期间手段权重下调是 03 卷的事）。
- 持续期：`T_verify_min = 3` 月（稽查往返 + 交叉核对，对齐 22-02 (a) 的 `δ_a=2` 结算节奏）；`T_verify_max = 12` 月内无新证据 → 回落起疑。均 `TODO(balance)`。

**阶段三 · 坐实（`confirmed`）**

- 进入形状（两条，均权重/累积式）：
  1. **多源汇拢**：`Susp_s ≥ θ_confirm`（推荐 **0.75**，`TODO(balance)`）**且**窗口 `W_confirm = 6` 月（`TODO(balance)`）内存在 **≥2 个独立来源类别**的证据（四类来源按类别计独立，同源重复不计）——「多条独立证据汇拢」；
  2. **制度化穿帮**：Protocol 介入链升至 `correction`（[protocol.go](../../internal/engine/protocol.go) L41-45：`warning → correction → override → assessment`）及以上，且当时该堡纸面剪影仍在低箱（`Θ̂ < 0.30`）。**注意这不是开关**：该条件兑现为一次性强证据增量 `ΔSusp = 0.35` 进入计数器——从查证期（≥0.40）推过 0.75 坐实；从起疑期只推高怀疑；从零起连查证都够不到。制度事实仍要走累积。
- 持续期：`T_confirmed = 4` 月（`TODO(balance)`；后果展开期：强观测注入、稽查展开、通道重置，§4）；结束后阶段回落 `doubt`（怀疑不会一笔勾销，`Susp` 保留），`StrictUntil` 生效（§4.2）。

**为什么能用上很久**（数值汇总）：单手段单月偏置 0.002（不可见）→ 单通道成形需 12+ 月 → 跨通道掩护 18–30 月 → 后验锁定 30–48 月；而拆穿侧：最强单证据 0.20–0.35 < 查证线 0.40 < 坐实线 0.75，且坐实要求窗口内双独立来源。**两侧都是数十月尺度的慢过程**，这是本卷的核心平衡形状。

## 4. 拆穿后果（逐条走既有通道，不新造惩罚机制）

### 4.1 信任崩塌 = 强观测注入（裁决 9）

22-00 裁决 9：`b_s` 的唯一写者是观测管线（4.65 产生 → 2b 信念更新）。**拆穿不得直接改写 `b_s`**——坐实事件作为**一条高质量负向观测**进入管线在途队列，与常规观测同格式、同抽干顺序：

```text
y_expose = clamp01( Θ + σ_expose·η )        // 世界侧产生：稽查实证/Protocol 偏离记录
                                            // 绕过被经营通道，不含 Bias、不含伪装偏移
似然参数：σ_expose = 0.05（远小于例行 σ_k=0.10–0.18：实证读数）
         π̂_expose = π̂ × 0.25（稽查实证难以再粉饰，伪装吸收大幅下调）
延迟 δ = 2 月（TODO(balance)，对齐 22-02 (a) 稽查报告回传节奏）
```

效果：后验向真值大幅回摆，但**幅度受贝叶斯约束**——被错误信念锁了几十个月的堡，一条强观测能把后验拉回数个箱，未必一次到底（深度锁死的信念修复需要后续多轮未污染观测）。信任崩塌是快的，信任重建是慢的。均 `TODO(balance)`。

### 4.2 更严监控（经 22-03 探索层，不直接写决策规则）

坐实写入 `StrictUntil = 当月 + T_strict`（推荐 **24 月** `TODO(balance)`），探索层读取：

- 该堡审计间隔 `T_audit` 减半（与 §3.3 的 `Susp` 压缩叠乘，下限 `T_audit_min` 不变）；
- 不确定性基线一次性注入 `U_s += 0.3`（箱宽尺度，`TODO(balance)`）——「被骗过」的堡不再享受低不确定性；
- 探索优先级经 §3.3 注意力权重表达（**不改 SiloID 升序的结算顺序**，确定性纪律）。

`r` 的后续变化是决策层读更新后 `b_s` 的**既有**行为（22-01 §6.3 argmax + 22-03 探索建议），本卷不新增任何指派规则。

### 4.3 惩罚（经既有 Protocol 介入链 / 反应链口径）

- **Protocol 介入链**：拆穿查出的偏离表达为既有偏离类型（`DeviationUnmet`/`DeviationLapse`）的记录与 `J` 重算，按既有阈值推进 `warning → correction → override → assessment`（[protocol.go](../../internal/engine/protocol.go) L421-474）——拆穿**喂的是证据，不是新罚则**；
- **反应链**：触发语义完全不变（`OrderPressure ≥ 0.45` 且宣传等级 ≥2，[world.go](../../internal/service/world.go) L428-445；`network_jammed` 守卫）。拆穿不进入触发判定（22-00 裁决 1）；其间接路径是：坐实后的高压姿态推高部门恐慌 → `OrderPressure = 0.6×叛乱 + 0.4×平均恐慌` 的恐慌分量有机上升（22-03 §6.3 方案 A 的既有公式内路径）；
- **不发明新惩罚**：无新结局键、无新事件链；玩家可见的处置呈现复用既有通道（§5）。

### 4.4 自保进一步上升：只经 `r`，不加新写入口

22-01 §3.1 裁决形式：`Θ_{t+1} = clamp01(Θ + growth(r) − decay(Θ, r))`，**growth 只由 `r` 驱动**。本卷遵守：拆穿事件**不写任何 Θ 增量**。间接链完整写出：

```text
坐实 → 强观测入管线（§4.1）→ b_s 后验上移（Θ̂ 升高、U_s 升高）
     → 既有决策规则响应（22-01 §6.3 argmax / 22-03 探索建议 / 安全停探）→ r 变化
     → Θ 按 growth(r)/decay 既有动力学自然上涨或回落
```

**为什么不直接加 Θ 增量**：

1. **裁决约束**：Θ 增长只由 `r` 驱动是 22-01 §3.1 裁决形式，加新写入口即违反；
2. **单一驱动不变量**：`r` 是 Θ 的唯一控制变量，保证「施压→离心、减压→回落」的回路可分析、可平衡；多写入口会破坏 22-00 §3 定稿时间常数的全部推导；
3. **可恢复性语义**：Θ 的语义是「对指令附带风险的自保姿态」（22-04 §1.3），风险退则自保松——若拆穿写入一次性 Θ 增量，该增量没有对应的衰减路径（不存在「安抚被拆穿」的操作），成为永久疤痕，与 Θ 的可恢复性矛盾；
4. **叙事一致**：底下人怕的不是「被拆穿」这个抽象事件，是拆穿之后**真正变苛刻的指令**——风险本身。
5. 跨卷登记：22-03 §6.3 的 `ΔΘ_burst`（爆发反喂）是爆发场景的外推增量，其归属以主线裁决为准；**无论该项是否成立，本卷的拆穿链不引入任何新 Θ 写入口**，不依赖该项。

### 4.5 拆穿后的盲区状态：重置与连带

**被拆穿通道**（坐实时执行）：

```text
Cov_c := 0；Bias_c := 0；ChannelResetMonth_c := 当月
该通道痕迹账本条目移除（被查抄/调走）
守卫期：T_guard = 18 月内该通道 Δcov ×= (1 − q_guard)（§1.2）
```

理由：上面换了口径、换了设备、换了核查方式——被经营安排被物理拆除；且该通道在守卫期内被盯着，重建更慢、更易再露。守卫期同时给观测侧：该通道观测 `σ_k ×= 0.75`（更严核查 = 噪声更小，与 §4.2 一致；`TODO(balance)`）。

**其余通道是否连带清洗——设计选择：坐实时部分连带，不全清**：

- 坐实（尤其多源汇拢路径）意味着 Order 启动全面复核：未直接涉证通道 `Cov_c ×= (1 − spillover)`，`spillover = 0.5` `TODO(balance)`——全面复核会顺手换掉一批口径与人员，但未涉证通道的旧安排不会全被识别；
- 理由：(i) 世界侧真实——普查穿帮不必然导致回执格式立刻更换，但经手人会紧张、部分安排悄悄停摆（体现为衰减加速与手段骤停痕迹）；(ii) 玩法——保留多通道分散经营的部分残值，避免「一次拆穿、全堡清零」的悬崖式惩罚，让经营方有「止损后重建」的决策空间，也让 1 号的后续监控投入（§4.2）有持续对象。
- 仅起疑/查证阶段被证伪（查无实据）：**不重置**，`Susp` 按 τ_susp 自然回落——查无实据本身是盲区经营的有效掩护成果，符合「能用上很久」。

## 5. 玩家可读呈现

**纪律**（22-04 §3.d 口径）：只展示已发生的具体事实；不点名、不概率、不弹窗；玩家可见文本主体是 **Order/专线/稽查组**，不以「1 号」为主语；事实经既有渠道（指令、专线、稽查组到访、部门文书）呈现。事件 ID 为内容立项建议，本轮不写事件文件（22-00 §5-6 口径）。

1. 「这个月的普查表多了一栏交叉核对：口粮领取编号要与人口册逐条对应。」

**查证阶段**（针对性稽查——玩家看到的是检查变严）：

4. 「稽查组这次没有提前通知。」

**坐实阶段**（后果展开——玩家看到的是制度落地）：

7. 「Order 的纠正通知里列着三项未达标，每一项后面都注着：与呈报不符。」

**演出约束**：以上事实只描述 Order 系统侧的**行为变化**，不出现「对面起疑了/被骗了」之类的全知视角表述；玩家从「查得变细、查得变突然」里自己品出味道。邻堡视角走传闻通道（`perception.go` 口径，22-04 §3.a）：「经线路杂音听到：某堡的稽查组住了一个月没走。」
