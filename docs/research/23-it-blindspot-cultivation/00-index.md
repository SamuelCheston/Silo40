# 23-00 · 底下 IT 盲区经营：总览、共享契约与主线裁决

> 本文档由 AI 维护（project-source）。本系列只写设计与规格，不改代码、配置、事件或数值；实现归实现轨（「自保与风险度指派的本体」由并行轨实现，本系列不碰其代码）。
>
> 系列定位：[22 号系列](../22-silo1-blackbox-learning/00-index.md)解决了「1 号如何估计看不见的自保量 `Θ`」；本系列补另一半——**底下 IT 如何主动经营 1 号的观测盲区**，而不是被动等 1 号来测。监控设备轮流「故障」、敏感活动排进盲区时段、报表数字被「合理地」裁剪：单次看都是无害的偶发事故，攒上几十次才看得出是一个人在给自己造盲区；等 1 号意识到被骗，已经过去很久。
>
> 与 22 系列裁决 13 的关系：22-00 裁决 13（反应快、暴露慢）把不可探性的主防线从时间常数转移到**观测伪装**——抬头后的第一反应是阳奉阴违，对 1 号基本不可见（22-02 §5.2「测到的是服从，不是自保」）。本系列正是这条主防线的**组织化机制**：`Θ` 是快起快落的姿态量（情绪/姿态层），盲区是慢建慢磨的制度化存量（流程/口径层）——1 号测到的服从，是这里经营出来的。

## 3. 权威状态模型与存档契约

**状态模型以 04 卷为权威**：逐通道 `Cov_c` 递推（加性增量 − `Cov_c/τ_cov`）、`Bias_c` 派生、痕迹账本、`Susp` 与阶段机，全部是**零 RNG 世界侧簿记**。01/02 卷声明手段的月度增量与痕迹模板，03 卷抽取「手段 + 力度」，04 卷消费并累积，05 卷把累积状态确定性映射进 22 观测管线。

**统一存档聚合**（合并 03 §5.5 与 04 §1.5，`serializer:json`，与 `NegotiationState`/`Silo1BlackBoxState` 同模式）：

```text
Silo.BlindSpot (BlindSpotState)
├── Initialized        bool      零值 false → 功能未启用 = 旧档语义逐位不变
├── Disposition        string    性情 χ_s（首次启用派生并持久化；重算必同值）
├── ActiveMethod       string    本月生效手段类 ID（"" = idle）
├── ActiveIntensity    int       本月力度 ℓ（0–3）
├── Coverage           [6]float64  逐通道 Cov_c（固定顺序 equipment/schedule/
│                                  reports/ledger/census/timing）；零值 = 无盲区
├── Suspicion          float64   怀疑计数器 Susp ∈ [0,1]
├── Stage              string    ""/doubt/verify/confirmed
├── StageMonths        int       当前阶段已持续月数
├── Traces             []TraceEntry   痕迹账本（保留期内，升序）
├── Evidence           []EvidenceEntry 近期证据（环形上限 24）
├── ChannelResetMonth  [6]int    逐通道最近重置月
├── StrictUntil        int       更严监控截止月
└── Log                []BlindSpotLogEntry  IT 伪装决策日志（环形上限 24）
```

`Bias_c` 不存档（由 `Cov_c` 确定性派生）。**零值语义**：全字段零值 = 功能未启用 = 注入恒等映射 = 旧档行为逐位不变。**版本号不定死**：实现轨与并行轨协调取号（22-00 裁决 11 同口径），升级器遵守备份 + 单事务 + 回读校验三件套。

## 5. 与实现轨的接口契约

1. **挂载点**（既有步骤不重编号）：

4.55 Θ/E 结算（22 系列，零 RNG）
4.6  RunITAuthorityMonthly（现状 argmax，逐位不变）

2. **RNG 纪律**：唯一新增消耗点是 4.62（动手/手段/力度三级抽取，堡按 SiloID 升序、堡内顺序写死）；性情派生是纯哈希不耗 RNG；累积/拆穿/注入全部零 RNG。功能关闭 → 4.62 跳过、注入恒等 → 零新消耗、parity 逐位不变；功能开启 → 4.62 新消耗位点按 knowledge/08 §5 登记重建基线（与 22-00 裁决 3 的一次性重建合并）。
3. **真值/信念隔离**：`Cov_c`/`Bias_c`/`Susp`/痕迹账本全是世界侧真值，1 号决策层永不读取（ADR-0015/0016）；1 号侧唯一可得路径是被污染的观测管线输出与拆穿强观测（管线内观测）。04 卷 `e_proto` 读 `Θ̂`（1 号自己的信念）属合法自查，不构成读心。
4. **Θ 零新写入口**：本系列不写 `Θ`、不写 `E`、不写 `b_s`、不进反应链触发判定（22-00 裁决 1）；全部效果经观测管线污染 → 信念失真 → 既有决策链间接表达。
5. **Protocol 边界**：注入只作用于黑箱观测管线，不作用于 Protocol review 真值读取；纸面手段可延迟真值审判触发时机、不能消除未达成事实（22-00 裁决 4；02 卷 §8 边界表）。
6. **缺口依赖**：本系列不新增机制缺口，只消费 22-02 §6 既有缺口——G1 稽查（拆穿的查证手段）、G2 举报管道、G3 例行指令账本（= ledger 通道载体）、G5 人口报告通道（= census 通道载体）、G10 表面服从脉冲为强依赖；G6 放弃项不复活；G7 落地前 M5 退化占位。本系列新增的唯一缺口是 01 卷 G-01（监控设备无实体），处置见裁决 22。

## 7. 玩家可读性（系列统一口径）

玩家应感觉到「底下有人在动手脚」与「1 号正被骗着」，全部经日常小动作与数据异样透出，不弹窗宣告（22-04 §3 纪律）：

1. **经营侧可见事实**（01 §5 / 02 §10）：维修单、排班表、口径变更、空洞回执、普查册缺口——主体是 Order 系统侧的文书与行为，不以「1 号」为主语。
2. **被骗侧可见异样**（22-04 §3.b 口径延伸）：报表过于干净、稽查结论与实况脱节、评级与实际脱节、反应慢半拍——只陈述已发生事实，推理留给玩家。
3. **拆穿侧可见事实**（04 §5）：起疑（文书变细）→ 查证（检查变严、变突然）→ 坐实（制度落地），按阶段分组的事实式文案。
4. 禁止项从 22-04 §3.d：不点名结局、不给概率、不展示 `Θ`/`b`/盲区状态真值、不教程弹窗、不以「1 号」为主语。
