## 2. 权重因子总表与详述

### 2.1 权重形式与候选集

对候选 `c`（手段类或「不动手」），未归一权重为**基础权重 × 连乘处境因子**：

```text
W_c = B_c · f_mot(c) · f_risk(c) · f_attn(c) · f_situ(c) · f_disp(c) · f_G(c) · f_inertia(c)
W_c ← max(W_c, ε_w)                    // 裁量地板：任何候选永不归零
```

- 因子取**乘法**而非加法：任一处境维度极端恶劣时整体倾向骤降但保持非零，归因时每个因子可独立读出。
- 权重计算全程**零 RNG**（纯确定性浮点）；随机只出现在 §3 的三次抽取。
- 候选集 `C` = 01/02 卷谱系表声明的全部手段类（**候选集以 01/02 卷谱系表为准**）+ 「本月不动手」`idle`。每个手段类在谱系表中声明：`ID`、所属通道（六通道之一）、类标签（惯性类/针对性类，见 §2.8；可选附加「表面合规」标签，见 §2.5）、基础权重 `B_c`、基础成本、基础收益、基础拆穿率 `u_c ∈ [0,1]`、扭曲的观测量（[22-02 §2](../22-silo1-blackbox-learning/02-observations-and-noise.md) 的 (a)–(g)）。同一通道声明多个手段类时，它们各自独立入候选集参与同一次抽取；本卷抽取粒度为「手段类」，通道内细节归 01/02 卷。
- 候选遍历序固定：**谱系表 ID 升序**（`idle` 恒排最后）——与「同分按 ID 升序」「只有严格更高分才替换」同口径【现状纪律，knowledge/08 §2】。

### 2.3 自保动机 `f_mot`：Θ 的函数，中段最强、两端受抑

动机核心沿用 [22-02 §4.1](../22-silo1-blackbox-learning/02-observations-and-noise.md) 的 `M(Θ) = 4·Θ·(1−Θ)`（峰值在 `Θ=0.5`，`M=1`）；本卷在其上补**两端的权重形状**【提案】：

```text
S_low(Θ)  = clamp01(Θ / θ_ramp)                       // 低段斜坡：B2 以下动机未充分成形
S_high(Θ) = 1 − clamp01((Θ − θ_fade) / (1 − θ_fade))  // 高段衰减：转向摊牌筹备，伪装退居次位
f_mot(c)  = ε_mot + M(Θ) · S_low(Θ) · S_high(Θ)       // 手段类候选
f_mot(idle) = 1 + (1 − M(Θ) · S_low(Θ) · S_high(Θ))   // 不动手：动机越低越倾向不动手
```

| 参数 | 初值 | 理由 |
| --- | --- | --- |
| `θ_ramp` | `0.30` `TODO(balance)` | 与 B2（阳奉阴违）下界对齐（[22-03 §2.1](../22-silo1-blackbox-learning/03-exploration-and-cost.md) 语义档）：`Θ<0.30` 时动机线性未饱和——低 Θ 堡真照办、无可伪装，伪装权重随之压低，但**不为零**（`ε_mot` 保底） |
| `θ_fade` | `0.70` `TODO(balance)` | 与 B4（抗命）下界对齐：`Θ>0.70` 后堡的精力转向摊牌筹备（16/20 号筹备线），伪装权重线性衰减；`M(0.9)=0.36` 的残余动机仍保留一部分——蓄谋期需要表面平静（22-02 §4.1 设计选择 1/2/3），衰减而非截断 |
| `ε_mot` | `0.02` `TODO(balance)` | 动机地板：任何 Θ 下伪装候选保留最小动机分量 |

两端形状读数示例（相对峰值）：`Θ=0.05` → `M·S_low·S_high ≈ 0.032`（峰值的 3%，「几乎不伪装」）；`Θ=0.5` → `1.0`（峰值）；`Θ=0.9` → `≈0.12`（峰值的 12%，「转向摊牌准备而非伪装」）。**注意**：这里 `0.30/0.70` 是权重形状的斜坡锚点，不是行动门槛——任何 Θ 下伪装与不动手的权重都严格为正。

世界观措辞：`Θ` 是**主任对 Order 系统的自保姿态**（[22-00 §2](../22-silo1-blackbox-learning/00-index.md) 命名裁决）；本因子描述的是主任给自己留后路的动机强弱，不涉及对 1 号的认知。

### 2.4 被查风险 `f_risk`：本地感知到的监督强度

输入只用**已发生事实**，不得读 1 号内部状态（`b_s`、`L`、`A(t)` 真值一律禁用）【裁决】：

- **公开到达的 `r` 档位**：`r` 指派是公开到达的指令，功能开启时经既有 `SafeguardRisk` 字段落地（[22-00 §5.1](../22-silo1-blackbox-learning/00-index.md)）——本地读到的就是 Order 风险评级本身，属世界事实。取本月生效值 `r_eff`（= 上月指派、本月生效，[22-01 §2.2](../22-silo1-blackbox-learning/01-dynamics-and-pseudocode.md) 指派月索引口径）。
- **近期稽查/核查事实**：`I_recent(t)` = 近 `K_win` 个月内已发生的稽查/核查类事实计数（稽查组到访、专项核查指令到达、报告频次被加密、交叉验证要求——对应 [22-03 §2.3](../22-silo1-blackbox-learning/03-exploration-and-cost.md) R2+ 档位的可观测姿态）。计数器的维护归 04 卷（§6.2），本卷只读。

```text
P_s(t) = w_r · r_eff(t) + w_i · clamp01(I_recent(t) / I_sat)      // 感知监督强度 ∈ [0, 1.2]
f_risk(c) = 1 + a_need · P_s − a_danger · P_s · u_c               // 手段类候选
f_risk(idle) ≡ 1
```

| 参数 | 初值 | 理由 |
| --- | --- | --- |
| `w_r` / `w_i` | `0.6` / `0.6` `TODO(balance)` | 评级与事实各占一半：评级是常态压力，事实是近期烈度；`P_s` 上界 1.2 容许「评级高 + 事实饱和」叠加 |
| `K_win` | `6 月` `TODO(balance)` | 稽查事实的记忆窗口：与 Θ 动力学的月级时间常数同量级，太短则监督感知抖动，太长则失去对近期稽查的反应 |
| `I_sat` | `3 次` `TODO(balance)` | 窗口内 3 次稽查类事实即感知饱和——再密的稽查在主任眼中已是「全面盯防」，边际感受不增 |
| `a_need` | `0.6` `TODO(balance)` | 监督越紧 → 报告面越需要打理 → 全体伪装候选权重抬升（动机侧） |
| `a_danger` | `1.2` `TODO(balance)` | 监督越紧 → 高拆穿率手段越危险 → 按 `u_c` 差异化压制（手段侧）。`a_danger > a_need`：净效果是**紧监督下向低拆穿率通道迁移**而非停手——例：`P_s=1, u_c=0.1` → 因子 1.48；`u_c=0.8` → 因子 0.64 |

`f_risk` 可为负值输入压到很低（`P_s=1.2, u_c=1` → `1+0.72−1.44=0.28`），但经 §2.1 地板后仍严格为正——**再严的监控也不禁止任何手段，只改变倾向**。

### 2.5 上级注意力投影 `f_attn`：1 号注意力的可观测投影

1 号的注意力预算 `A(t)` 是其内部量，**不得直读**【裁决】；本因子只用注意力在本堡的**可观测投影**（世界事实）：

- **专线流量比**：`traffic(t) = 近 3 月月均到达指令/核查请求数 ÷ 近 12 月基线均值`。流量是物理事实（指令到达就有记录），无需知道流量背后是谁的决策。计数器维护归 04 卷/观测管线（§6.2），本卷只读。
- **通牒事实**：近 `K_ult` 月内本堡收到过通牒（跨堡信号，[world.go](../../../internal/service/world.go) L428-445、`silo1_ultimatum_cross.js` 口径【现状】）→ 注意力投影的极端形态。

```text
Δ_traffic(t) = clamp(traffic(t) − 1, −0.5, 1.5) + 1[近 K_ult 月有通牒] · Δ_ult
f_attn(c) = exp(−ζ · Δ_traffic · u_c)                    // 手段类候选
f_attn(idle) = 1 + 0.15 · clamp(Δ_traffic, 0, 1.5)       // 注意力上抬时略偏向静默
```

（`idle` 的静默斜率 `0.15` 为 `TODO(balance)` 初值：注意力上抬时「不动手」的抬升幅度远小于对手段的压制幅度。）

另设**表面合规类例外**：谱系表可声明某手段类为「表面合规」标签（通牒后短期做样子，[22-02 §3.5](../22-silo1-blackbox-learning/02-observations-and-noise.md) 表面服从脉冲的手段侧对应物）；此类候选在通牒窗口内额外乘 `b_show = 1.5` `TODO(balance)`——通牒刚过，「表演服从」的期望收益最高。

| 参数 | 初值 | 理由 |
| --- | --- | --- |
| `ζ` | `1.0` `TODO(balance)` | 注意力弹性：`Δ_traffic=1`（流量翻倍）时 `u_c=0.5` 的手段权重乘 ≈0.61；低拆穿率手段（`u_c=0.1`）仅乘 ≈0.90——注意力上抬主要压制高风险动作 |
| `K_ult` | `3 月` `TODO(balance)` | 通牒的记忆窗口：通牒后 2–3 月是表演服从与复查的高峰期（对齐 22-02 §3.5 脉冲持续 1–2 月的量级并略放宽） |
| `Δ_ult` | `1.0` `TODO(balance)` | 通牒等价于流量翻倍的注意力冲击 |
| 流量下限截断 `−0.5` | — | 流量骤降（注意力移向别处）是**机会窗口**：高拆穿率手段权重回升，但截断防止「对面一安静就肆无忌惮」的极端化；截断值本身 `TODO(balance)` |

### 2.6 当前处境 `f_situ`：R_op 预算、W 成本曲线、部门恐慌

```text
cost_c      = ItCostCurve(BaseCost_c, W)                          // 既有成本曲线【现状，it_authority.go】
f_afford(c) = clamp01((R_op − cost_c)/R_reserve + 0.2 · R_op/cost_c)^0.5
f_panic(c)  = 1 + k_panic · panic̄ · (0.5 − u_c)
f_situ(c)   = f_afford(c) · f_panic(c)
f_situ(idle) = 1 + 0.1 · panic̄                                    // idle 免费，恐慌时静默略升
```

- **`R_op` 可负担性**：成本走既有 `ItCostCurve(base, W) = ceil(base·(1+3·(1−W/100)²))`【现状】——**威势 `W` 通过成本曲线进入权重**：`W` 低 → 同样手段更贵 → 权重更低，不需要单独的 `W` 因子。`f_afford` 是**软坡不是预算闸**：`R_op < cost_c` 时权重急剧下降但严格为正（§2.1 地板兜底）——与现状「`cost > budget` 直接剔除候选」的硬过滤不同【提案，执行侧的预算衔接见 §3.1-4】。式中余量项系数 `0.2` 与开方指数 `0.5` 为 `TODO(balance)` 初值：余量项让「付得起但伤筋动骨」与「付得起且宽裕」区分开；开方使负担感在接近付不起时陡升、宽裕区钝化。
- **部门恐慌**：`panic̄` = 堡内部门恐慌均值（`OrderPressure` 的恐慌分量同源【现状，content_events.go】）。恐慌期人人盯梢，高拆穿率手段更危险、低拆穿率手段（压数字、稳报告）反而顺手。

| 参数 | 初值 | 理由 |
| --- | --- | --- |
| `R_reserve` | `40` `TODO(balance)` | 负担余量标尺：付出成本后仍余 40（≈ 5 个月净收入量级）时负担感消失；`R_op` 初始 60、+8/月、上限 100【现状，it_authority.go】 |

### 2.7 长官性情 `f_disp`：逐堡确定性系数（种子派生）

每堡一个固有倾向 `χ_s`，**开局由种子派生、不耗运行时 RNG**【裁决】：

```text
h  := SplitMix64(World.Seed ^ (uint64(SiloID) · 0x9E3779B97F4A7C15))
u  := float64(h) / 2^64 ∈ [0,1)
χ_s := 谨慎 (u < 1/3) | 投机 (1/3 ≤ u < 2/3) | 守拙 (2/3 ≤ u)
```

- `SplitMix64` 取标准 finalizer（或任何等价的确定性整数哈希）；**纯函数派生，不创建任何随机源**。等价实现先例：驻地编号的 `rand.New(rand.NewSource(seed ^ 0x40a17))` 刻意独立源（[knowledge/08 §1](../../../knowledge/08-determinism-known-issues.md)）【现状】——若实现轨采用派生 source 方案，同样不消耗 gameplay RNG。
- 派生时机：功能首次启用时计算一次并写入存档；之后从 `(World.Seed, SiloID)` 重算必得同值（双保险）。同种子同堡序 → 同性情轨迹（复现契约，knowledge/08 §2）。
- 三型乘子【提案，全部 `TODO(balance)`】：

| 候选特征 | 谨慎 | 投机 | 守拙 |
| --- | --- | --- | --- |
| 低拆穿率手段（`u_c ≤ 0.3`） | ×1.10 | ×1.05 | ×1.00 |
| 高拆穿率手段（`u_c > 0.3`） | ×0.60 | ×1.15 | ×0.80 |
| timing 通道（时机类，投机者所长） | ×1.00 | ×1.30 | ×1.00 |
| 惯性类手段（对「流程」演戏） | ×1.00 | ×1.00 | ×1.30 |
| 针对性类手段 | ×1.00 | ×1.05 | ×0.80 |
| `idle` | ×1.40 | ×0.85 | ×1.20 |

一个候选可同时命中多行（如 timing 通道的低拆穿率手段），命中行的乘子**连乘**——各行是性情对不同候选特征的独立倾向，连乘后仍受 §2.1 地板保护，不产生禁止项。

理由：谨慎型主任宁可少做、做就做安全的；投机型主任敢抓窗口、敢上高风险手段；守拙型主任惯于按流程演戏（惯性官僚伪装的主力），对需要揣摩观察者的针对性伪装不在行。三型只是**乘子差异**，不产生任何禁止项。

### 2.8 认知梯度 `f_G`：惯性伪装与针对性伪装的分层

按 [22-02 §4.2](../22-silo1-blackbox-learning/02-observations-and-noise.md) 的认知分层（`G<0.10` 不知道上层控制方存在 → 只有惯性官僚伪装；`0.10–0.35` 察觉隐藏编写者；`≥0.35` 针对性伪装解锁；`≥0.65` 高精度伪装），本卷把「解锁」实现为**连续斜坡而非硬指示函数**【提案】：

```text
μ(G)：锚点线性插值
  (0.00, 0.15) → (0.30, 0.15) → (0.40, 1.00) → (0.65, 1.25) → (1.00, 1.25)
f_G(c) = 1          若 c 为惯性类（对「流程」演戏，不需要知道流程背后是谁）
f_G(c) = μ(G)       若 c 为针对性类
f_G(idle) ≡ 1
```

| 锚点 | 初值 | 理由 |
| --- | --- | --- |
| `G ≤ 0.30` 平台 `0.15` | `TODO(balance)` | 针对性伪装在认知解锁前只剩残余概率（例行公事里顺手夹带的程度）——对齐「`G<0.35` 时只有惯性官僚伪装（基线权重）」【裁决】，但以平台值 0.15 而非 0 表达，保非零裁量 |

| `G ≥ 0.65` 平台 `1.25` | `TODO(balance)` | 高精度伪装（知道哪些指标被读）使针对性手段更「值」，小幅加成；不继续放大以免高 G 堡变成完美伪装机器 |

**与 22-02 §4.3 能力式的关系**：22-02 的 `C(G,R_op) = 1[G≥0.35]·clamp(R_op/R_opMax,0,1)^0.5` 是**伪装能力上限**（决定伪装能扭曲多少），本因子是**决策倾向**（决定想不想伪装）；能力上限在 §3.2 的力度抽取中再次进入（能力不足时高力度的权重被压低而非禁止）。

## 3. 抽取机制与伪代码

### 3.1 与现状 RunITAuthorityMonthly 的关系与顺序

**现状**【it_authority.go】：`RunITAuthorityMonthly`（RunLocalPhase 步骤 4.6）对 `ItActionCatalog` 做**确定性 argmax**——`utility>0` 最高分、同分按 action ID 升序（L220-248）；随机只出现在执行期的失控骰与暴露骰（L320-331）。该回合管的是**本地治理**：维护忠诚、反击玩家威胁、Protocol 处置。

**本卷提案**：伪装经营决策是**另一个决策层**，挂在 argmax 之后、22 系列观测产生之前，新步骤 **4.62**：

```text
4 AdvanceAuthorityMonthly → 4.5 AdvanceProtocolMonthly
→ 4.55 Θ 结算（22 系列，零 RNG）
→ 4.6  RunITAuthorityMonthly（现状 argmax，逐位不变）
→ 4.62 IT 伪装决策抽取（本卷，门控 RNG，1–3 次）
→ 4.65 观测产生（22 系列，门控 RNG；读本月 ActiveDisguise 施加扭曲）
→ 4.7 DecayProfessionAlertness → 5 RunNpcTurn → 6 指标 → 7 胜负
```

顺序理由：

1. **预算竞争**：argmax 先花 `R_op`（本地治理），本卷抽取看余额（伪装经营）——「伪装与本地自保竞争同一预算」（[22-02 §4.3](../22-silo1-blackbox-learning/02-observations-and-noise.md)）由顺序支出天然实现：1 号持续施压会迫使本地 IT 在「伪装给上面看」与「镇压/自保」之间做真实取舍。
2. **信息顺序**：本月伪装部署必须先于观测产生定下，4.65 才知道该扭曲哪些信号（§6.4 φ 握手）。
3. **语义分离**：argmax 的目标是「怎么治理本堡」（对玩家与内部部门），本卷抽取的目标是「怎么对 Order 呈现」（对上报面）；候选集不相交、选择规则不同（确定性效用 vs 带权重随机）。
4. **取代声明**：[22-02 §4.4](../22-silo1-blackbox-learning/02-observations-and-noise.md)「伪装动作作为新候选类进入 `ItActionCatalog` 的 utility 选择……决策本身无随机」在**伪装手段选择**上由本卷取代——`TODO(adjudication)`：跨系列取代需主线确认；22-02 §4.1–4.3 的动机/能力公式保留，降为本卷因子输入（`f_mot` 的 `M(Θ)`、`f_G`/§3.2 的能力上限）。22-02 §4.4 关于抽样位置（本地相、Protocol 结算之后、SiloID 升序）与确定性纪律的部分继续有效。
5. **预算衔接**【提案】：现状 argmax 用「`cost > budget` 剔除候选」的硬过滤；本卷按非零裁量纪律**不剔除**——若抽中的手段类成本超出余额，执行侧按力度自动降档结算（`ℓ` 降到负担得起的最高档，`R_op` 扣到 0），而非作废重抽。降档规则的成本/效果结算归 01/02/04 卷，本卷只声明抽取侧语义：抽取永远有效，负担只影响力度。

### 3.2 三级抽取

每堡每月按固定顺序做至多三次抽取（等价的单次联合抽取方案见注）：

1. **是否动手**：`idle` 权重 `W_idle` vs 全体手段类权重和 `Σ W_c`。抽中 `idle` → 本月结束（只耗 1 次 RNG）。
2. **选哪个手段类**：在手段类候选上按权重抽取（谱系表 ID 升序累减）。
3. **用多大力度**：`ℓ ∈ {1 轻, 2 标准, 3 重}`，权重：

```text
cap_s = clamp01((G − 0.25)/0.15) · clamp01(R_op/100)^0.5     // 22-02 §4.3 能力上限的软化版
b_χ   = 0.1(谨慎) | 0.6(投机) | 0.3(守拙)
w_1 = 0.45 + 0.25·1[χ=谨慎] + 0.30·P_s
w_2 = 0.40
w_3 = (0.15 + 0.20·b_χ + 0.10·clamp01((R_op − cost_c·1.6)/R_reserve)) · (0.4 + 0.6·cap_s)
w_i ← max(w_i, ε_ℓ)
```

力度公式中的全部系数为 `TODO(balance)` 初值：`cap_s` 解锁斜坡锚点 `0.25 → 0.40`（中心压在 22-02 §4.2 的 `G=0.35` 解锁线）、`b_χ = {0.1, 0.6, 0.3}`、谨慎加成 `0.25`、`P_s` 系数 `0.30`、胆量系数 `0.20`、余量系数 `0.10`、重动作成本乘子 `1.6`（= `m_cost(3)`）、能力基底/权重 `0.4 / 0.6`。理由速记：轻动作是常态（`w_1` 基底最大）、重动作稀有且需胆量 + 余量 + 能力三者支持；各系数量级与 §2.10 参数汇总一致。

形状说明：紧监督与谨慎性情偏向轻动作（`w_1` 抬升）；重动作（`w_3`）需要胆量（性情）、余量（`R_op`）与能力（`cap_s`）三者支持——**能力不足不禁止重动作，只压低其权重**（`G=0.2` 时 `cap_s=0`，`w_3` 仍有 `0.4` 的乘子基底）。力度决定结算乘子 `m_cost/m_u/m_eff`（§2.10），消费归 01/02/04 卷。

> 注（等价方案）：单次在 `{idle} ∪ C` 上联合抽取再抽力度，与本方案联合分布完全相同（`P(idle)` 与 `P(c)` 的边际一致）。采用三级是因为：`idle` 月省两次 RNG、日志叙事自然（先决「动不动手」再决「怎么动」）。

### 3.4 复杂度

每堡每月：因子与权重计算 `O(|C|)`（`|C|` = 谱系表候选数，固定常数）；抽取 `O(|C|)` 累减；力度 `O(1)`。全游戏 **`O(S·|C|)`**，每月 ≤ `3S` 次 `DrawFloat64`——相对既有结算量可忽略。

### 3.5 确定性清单

1. **单一引擎 RNG 流**：只用 `DrawFloat64`（[rng.go](../../../internal/engine/rng.go)【现状】）；不新增私有随机源；性情派生是纯哈希，不耗任何 RNG。
2. **固定顺序**：堡按 SiloID 升序（既有纪律）；堡内固定为「动手抽取 → 手段抽取（谱系表 ID 升序累减）→ 力度抽取（ℓ 升序区间）」。
3. **门控**：功能关闭 → 4.62 整体跳过 → 零新消耗 → 与既有 parity 基线逐位一致（谈判层先例，[knowledge/08 §2](../../../knowledge/08-determinism-known-issues.md)）；功能开启 → 新增消耗位点，v8 parity 基线按 knowledge/08 §5 重建（登记，实现轨职责）。
4. **浮点纪律**：权重连乘按因子固定次序（§2.2 总表序）、候选按谱系表 ID 升序累加，无 map 序浮点累加。
5. **零月路径**不进入 RunLocalPhase（[22-01 §10.8](../22-silo1-blackbox-learning/01-dynamics-and-pseudocode.md) 同口径），本层天然不结算、不消耗。

## 4. RNG 消耗规范

| 步骤 | RNG 消耗 | 次数（每堡每月） | 顺序 |
| --- | --- | ---: | --- |
| 功能关闭 | 0 | 0 | 4.62 整体跳过 |
| 因子与权重计算 | **0** | 0 | 纯确定性（零 RNG） |
| 性情派生 | **0** | 0（仅首次启用时纯哈希派生） | 不耗运行时 RNG |
| 动手/不动手抽取 | `DrawFloat64` ×1 | 1 | 4.62 第一抽 |
| 手段类抽取 | `DrawFloat64` ×1 | 0–1（仅动手时） | 4.62 第二抽 |
| 力度抽取 | `DrawFloat64` ×1 | 0–1（仅动手时） | 4.62 第三抽 |

功能开启时，本地相内堡内 RNG 消耗点的完整序列（固定写死）：

```text
4.6  失控骰 / 暴露骰（现状，仅在执行动作时）
4.62 动手抽取 →（动手时）手段抽取 → 力度抽取（本卷）
4.65 逐信号伪装判定 + 噪声取样（22 系列，信号类型升序）
```

消耗次数依赖抽取结果（1 或 3），但给定（代码、种子、操作序列）完全确定——与谈判层「仅当信道畅通时消耗 RNG；固定取样顺序」同先例（[knowledge/08 §2](../../../knowledge/08-determinism-known-issues.md)）。

## 5. 决策日志格式

### 5.1 定位：世界侧审计日志（博弈两侧的底牌之一）

- 结构先例：`NegotiationLogEntry`——归一化权重 + 因子摘要、环形上限 `NegotiationLogCap = 24`、随存档持久化、可复盘【现状，models.go L635-693】。
- **与两份既有日志的关系**：谈判日志的决策方（市长/叛乱方/IT）是玩家可见的本地行动者，日志可上前端【现状】；[22-04 §2.1](../22-silo1-blackbox-learning/04-naming-log-and-readability.md) 的 1 号信念日志是 1 号侧底牌，只供审计；**本日志是 IT 侧底牌**——伪装决策的原始记录同样**不进玩家界面、不进玩家可见文本**，只供调试端点与回放。两份日志（1 号信念 / IT 伪装）分别是博弈两侧的底牌，定位对齐又互不可见：审计时可以并排复盘「1 号在猜什么」与「底下在演什么」。
- 日志记录的**行为后果**（报表被裁剪、档案被修补、核查被拖延）会经日常小动作被玩家看见——呈现归 01/02 各手段卷与 04 卷（及 05 卷的汇总，若其职责轨为呈现）；本卷只声明接口：日志条目的 `chosen/ℓ` 是「决策」与「呈现」之间的唯一桥梁（只陈述已发生事实、不解释原因，呈现纪律从 22-04 §3.b）。

### 5.2 字段清单

| 字段 | 含义 |
| --- | --- |
| 年/月 | 决策发生的月份 |
| 堡 | SiloID（日志按堡分环，每堡环形上限 24） |
| 性情 | `χ_s`（谨慎/投机/守拙，种子派生，归因上下文） |
| 各因子读数 | `Θ`、`M·S_low·S_high`、`G`、`r_eff`、`I_recent`、`P_s`、`traffic`、通牒事实、`R_op`、`cost_c`、`W`、`panic̄`、惯性标志 |
| 权重构成（可归因） | 全体候选的**归一化权重**（`round3`，谈判层同口径）+ 选中候选的**逐因子乘子分解** |
| 选中手段与力度 | `chosen`（手段类 ID 或 `idle`）+ `ℓ`（0/1/2/3） |
| 理由一句话 | 主导因子归因模板生成（§5.3），世界观措辞合规 |

### 5.3 理由句：主导因子归因（确定性模板）

取选中候选的因子乘子中 `|ln f|` 最大者为主导因子（`idle` 同理），映射到固定短语表；次主导因子可追加一个从句。短语表主语恒为「主任」，对象恒为 Order 系统侧的事物（风险评级、核查节奏、专线、报表面），**永不提及 1 号、信念、估计**【裁决，世界观措辞纪律】：

| 主导因子 | 短语模板（示例） |
| --- | --- |
| `f_risk`（监督紧） | 「Order 的核查节奏明显加密」 |
| `f_risk`（监督松） | 「Order 的评级久未变动，风头宽松」 |
| `f_attn`（流量升） | 「专线流量这个月翻了一番，风声紧」 |
| `f_attn`（流量降） | 「专线安静了下来，是个窗口」 |
| `f_mot` | 「风险评级压了数月，得让报表面干净些」 |
| `f_situ`（缺资源） | 「手头紧，只做得起轻动作」 |
| `f_disp` | 「主任性子谨慎，挑了最稳的一条」 |
| `f_G`（低认知） | 「按老流程走，把数字做平」 |
| `f_inertia` | 「上月的路子还在半途」 |
| `idle` 选中 | 「这个月没有动手的必要」/「风头正紧，先不动」 |

### 5.4 完整示例条目（中文）

```text
123 年 2 月 · 17 号堡 · IT 伪装决策
性情：谨慎（种子派生）
因子读数：Θ=0.42（动机 0.97，中段峰形）；G=0.52（针对性已解锁，μ=1.12）；
    r_eff=0.55（关注档），近 6 月稽查事实 2 次 → 监督强度 P_s=0.73；
    专线流量比 1.15（近 3 月无通牒）；R_op=54/100，W=68，部门恐慌均值 0.31；
    上月部署：reports_trim（惯性延续）
权重构成（归一化）：不动手 0.201 | reports_trim 0.259 | equipment_mute 0.178 |
    ledger_patch 0.130 | schedule_slip 0.095 | census_pad 0.078 | timing_hold 0.058
    （选中候选乘子分解：B=1.00 × 动机 0.99 × 认知 1.12 × 风险 1.22 × 注意力 0.96
      × 处境 1.05 × 性情 1.10 × 惯性 1.30 = 1.95，未归一）
选中：reports_trim（reports 通道 · 针对性类）· 标准力度（2）
理由：主任因为上月的报表裁剪还在半途、Order 的核查请求连续两月上抬，
    决定继续「裁剪报表」，按标准力度做。
```

（示例候选 ID 与谱系参数为演示用，**候选集以 01/02 卷谱系表为准**。）

### 5.5 存档字段提案（只写规格，不写代码）

新增堡聚合字段 `Silo.BlindSpot`（`BlindSpotState`，`serializer:json`，与 `NegotiationState`/`Silo1BlackBoxState` 同模式【现状/22-01 §8】）：

```text
BlindSpotState
├── Initialized        bool      零值 false → 功能未启用 = 旧档语义
├── Disposition        string    性情 χ_s（首次启用派生并持久化；重算必同值）
├── ActiveMethod       string    本月生效手段类 ID（"" = idle）
├── ActiveIntensity    int       本月力度 ℓ（0–3）
└── Log                []BlindSpotLogEntry   环形上限 24（NegotiationLogEntry 模式）
```

- **零值语义**：所有新字段零值写入 → 功能未启用 → 旧档行为逐位不变（与 22-01 §8 同口径）。`I_recent`、`traffic` 等事实计数器**不是本卷字段**，其维护归 04 卷累积状态（§6.2）。
- **存档版本号**：本规格不定死版本号，实现轨与并行轨协调取号（[22-00 裁决 11](../22-silo1-blackbox-learning/00-index.md) 同裁决）；升级器遵守备份 + 单事务 + 回读校验三件套。

## 6. 与 01/02/04/05 卷及既有系统的接口

### 6.1 对 01/02 卷（手段谱系）

- **本卷消费**：候选集声明——每个手段类在谱系表声明 `{ID, 通道 ∈ {equipment, schedule, reports, ledger, census, timing}, 类标签（惯性/针对性/表面合规）, 基础权重 B_c, 基础成本, 基础收益, 基础拆穿率 u_c, 扭曲的观测量（22-02 §2 (a)–(g) 声明）}`。本卷权重公式只依赖 `B_c`、`u_c`、类标签、通道四项；其余字段由 04 卷结算消费。
- **本卷输出**：每堡每月的 `(chosen, ℓ)` 与归一化权重快照（日志内）。
- 六通道固定为本系列共享通道集；谱系表在通道内声明多少个手段类，候选集就有多少个候选，本卷抽取机制不变。

### 6.2 对 04 卷（累积状态与回流）

- **正向**：`(chosen, ℓ)` → 04 卷盲区厚度月度增量 `ΔB_s(t)`。本卷声明增量方向：`ΔB ∝ 手段基础收益 × m_eff(ℓ) × (0.5 + 0.5·cap_s)`（能力封顶：认知与资源不足的堡，同样力度做不出同样厚的伪装；能力项系数 `0.5/0.5` 为 `TODO(balance)` 初值——能力归零时伪装仍有一半的「蛮干」效果，不归零）；形式化（含未动手月的自然衰减、拆穿判定）归 04 卷。
- **回流路径声明**（拆穿后的处境变化 → 下月权重输入；**形式化归 04 卷**，本卷只声明输入接口）：
  1. 拆穿事实 → `I_recent` 计数 +1（更严监控：稽查/核查事实增加）→ 下月 `f_risk` 的 `P_s` 抬升 → 高拆穿率手段权重下降；
  2. 拆穿事实 → `R_op` 惩罚性削减（信任崩塌的资源后果）→ 下月 `f_situ` 负担能力下降 → 全体主动手段权重下降；
  3. 拆穿事实 → `Θ` 动力学冲击（暴露冲击喂养自保姿态）——本卷**不写 `Θ`**，该路径经 04 卷/22 系列的世界侧接口进入（[22-01 §3](../22-silo1-blackbox-learning/01-dynamics-and-pseudocode.md) 动力学），再于次月经 `f_mot` 影响本卷权重；
  4. 连续未被拆穿 → 盲区厚度累积（04 卷）→ 1 号侧信念漂移是 22 系列职责，本卷不读其结果。
- **本卷保证**：所有回流量都以「已发生事实输入」（计数器、字段读数）进入本卷权重，任何时刻不读 1 号内部状态（`b_s`、`L`、`A(t)` 真值）。

### 6.3 对 05 卷

05 卷职责轨以主线系列分工为准（`TODO(adjudication)`：本卷按系列索引/总览卷对待，类比 [22-00](../22-silo1-blackbox-learning/00-index.md)）。本卷向 05 卷交付：
