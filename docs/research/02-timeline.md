# Silo 时间线研究

> 用途：history 类事件、“大革命/重置/陷落”节点、500 年倒计时叙事的依据。
> 口径：小说纪年保留公元年份；改编侧只保留阶段结构与相对先后，不写具体纪年、人名与集数，避免两套时间轴混用。

### 1.2 关键跨度（游戏叙事可直接引用）

- 封堡 → 正篇：**293 年**（2052→2345）。
- Silo 18 重置 → 正篇：**133 年**（2212→2345）——所以大革命只剩传说。
- Solo 独居：**34 年**（2312→2345）。
- 创始计划总长：约 **500 年**（对应 Silo40 的 500 年倒计时）。
- Donald 从设计地堡到炸毁 Silo 1：近 **300 年**。

## 2. 改编侧纪年（抽象概述）

改编侧使用另一套纪年，并把大量前史人物与事件重写。为避免两套纪年混用，本节只保留阶段结构，不写具体年份、人名与集数；可复用价值在于“阶段如何衔接”，不在于复述剧情。

### 2.1 大革命前后

- 大革命被写成一次本地 IT 主管主导的自我清洗：焚书、清空服务器、向供水投药，并把官方叙事嫁祸给叛军；主事者身败名裂，后代被罚做苦役。
- 此后形成“每年纪念平叛胜利”的公共仪式：漂浮灯、楼梯滑梯、市长演说，以及被篡改的历史重演。
- 常态下叛乱约每 20 年一次，皆由“对上一次叛乱的记忆”点燃。

### 2.2 正篇前夜

- 一名治安官因妻子之死要求出去，清洁死亡。
- 市长与副手下行招募机械师，归途被毒杀；IT 主管依公约代理市长。
- 机械师拒洁、翻山抵达邻堡，遇见邻堡唯一成年幸存者。
- 机械部门起义被镇压，IT 主管承认杀害机械师；系统分析师接任 IT 主管。
- 指挥堡内部发现“只留一堡”的终局文件，开始干预本地政治。

### 2.3 正篇之后

- 机械师任市长，启动掘进机横向挖向邻堡。
- 指挥堡内乱，无人机发现毒区之外有绿地。
- 邻堡暴乱，被纳米虫终止；约 200 人经隧道逃入另一堡，隧道被封死。
- 指挥堡被引爆，幸存者走出毒尘带，抵达 Seed。

### 2.4 建堡前史线

- 改编侧把建堡前史改写为一条“灾难—建堡—记忆实验”的调查线：灾难记忆被技术抹除，建堡计划被包装成公共工程，记忆修复与身份错认成为长期隐患。
- 可复用机制：**灾难记忆的官方改写**、**公共工程掩护**、**记忆修复导致身份错认**；不保留具体人物与机构名称。
