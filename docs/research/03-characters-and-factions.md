# Silo 人物与派系研究

> 用途：NPC 设计、faction（政治阵营）与部门行动（profession actions）的设定依据。
> 口径：小说人物保留原名与功能；改编侧只保留“功能位”与派系动力，不写具体人名、组织名与剧情桥段。

## 1. 部门权力图谱

### 1.1 小说侧（原著明确）

```text
Silo 1: Shepherd（Donald / Thurman）
   └─ 隐秘线路（只有各地堡 IT 主管知道）
Silo 18 表面秩序: Mayor（Jahns）→ Sheriff（Holston→Juliette）
Silo 18 真实权力: IT 主管 Bernard（依 Pact 在市长死后自动接任代理市长）
Down Deep: Mechanical（Knox / Walker / Shirly）— 掌握“东西怎么转”，被系统性蒙蔽
```

- IT 与 Mechanical 的对立是小说主轴：“IT 知道什么是真的并隐藏它；Mechanical 知道东西实际怎么转、停不下手去测试。Juliette 的胜利是机械师的胜利。”【原著明确】
- 部门间消息传递靠 Porters（楼梯人力运输），有自己的亚文化，传消息比 IT 希望的快。【原著明确】

### 1.2 改编侧（功能位抽象）

```text
明面: Mayor（可被代理、可被架空）
      ├─ Sheriff Department（执法与治安）
      └─ Judicial（法官、武装执法、违禁品没收、矿役判决）
暗面: IT（档案、监控、隐藏指令通道、供水投药权）
底层: Mechanical + Supply + Medical + Mines + Farms
```

- **双执法机构制衡**：Sheriff 与 Judicial 并存，Judicial 实际更强；司法系统掌握违禁品、监控与刑罚入口。
- **隐蔽监控**：全堡隐藏摄像头的物理入口藏在清洁用品间暗门之后，由清洁工家族世代看守；监控权可以独立于正式警权运作。
- **IT 的双重身份**：表面是技术部门，实际同时掌握档案、监控、外部指令与供水投药权。
- 以上只保留机制位，不绑定具体人名或剧情。【改编侧抽象】

## 3. 改编侧人物功能位（抽象）

改编侧大量重命名、合并或扩写人物。对游戏有用的不是具体姓名，而是**功能位**：

| 功能位 | 机制作用 | 可复用点 |
| --- | --- | --- |
| 明面市长 | 提供正式合法性；可被代理、架空或立为傀儡 | 继承危机、合法性来源、派系拉拢 |
| 治安官 | 执法入口；可被上层安插、胁迫或倒戈 | 调查线、证人保护、执法资源 |
| 司法主管 | 法官与武装执法的交汇点；掌握违禁品与刑罚 | 弹劾、没收、矿役、监控授权 |
| IT 主管 | 档案、监控、外部指令与供水投药权的交汇点 | 幕后威势、信息垄断、继承斗争 |
| 隐蔽监控负责人 | 独立于正式警权的监控网络 | 监视、眼线、信息不对称 |
| 武装执法头目 | 平乱、抓捕、灭口 | 镇压、暴力升级、体制内倒戈 |
| 机械师/工程师 | 设施实际运转的掌握者 | 维修权、反制垄断、隧道与掘进机 |
| 记忆保存者 | 旧世界记忆的活载体 | history burden、记忆碎片、镇压与觉醒 |
| 矿层主管 | 资源与刑罚劳动的交叉点 | 矿役、违禁品流通、底层动员 |
| 供应主管 | 配给与库存的交叉点 | 断供、囤积、黑市、派系交易 |

这些功能位可以任意映射到不同名字的 NPC，而不改变机制。【改编侧抽象】

## 4. 暗线组织与隐藏机制（抽象）

| 组织/机制 | 性质 | 手段 | 机制价值 |
| --- | --- | --- | --- |
| **记忆保存网络** | 民间记忆保存者 | 以违禁遗物保存旧世界记忆；被投药、绝育式镇压 | 活的 history burden 载体；镇压越狠，觉醒越强 |
| **隐蔽监控单元** | IT 暗面监控员 | 全堡隐藏摄像头；监控室藏在清洁间暗门后 | 信息不对称、眼线、反侦察 |
| **武装执法单元** | Judicial 武装力量 | 平乱、抓捕、灭口 | 镇压工具、体制内暴力 |
| **隐藏指令通道** | 本地 IT 的“指令之声” | 任命、应急指令、评估堡存活概率 | 不可见权威、祛魅节点、终局反抗前提 |
| **上级处置文件** | 载有终止机制的上级文件 | 规定终止条件与执行方式 | 终局级威胁、信息碎片目标 |
| **叛乱后治理机构** | 叛乱后的新治理安排 | 主导派系立傀儡市长 | 政权更迭、合法性重建 |
| **堡外边缘群体** | 堡外或边缘群体 | 绑架、走私、情报交易 | 外部变量、跨堡行动 |
| **建堡计划** | 建堡前史侧的公共工程 | 与灾难记忆、记忆实验交织 | 前史调查线、阴谋揭示 |

以上全部为功能抽象，不使用具体组织名、人名或专有名词。【改编侧抽象】

## 5. 派系动力学速记（可直接映射游戏 faction）

1. **蒙蔽的秩序派**（IT/Judicial 上层）：合法性来自“外面有毒”信条与公约；手段=监控、投药、嫁祸；弱点=依赖隐藏指令通道、内部分裂。
2. **技术真相派**（Mechanical 与旧硬盘发现者）：合法性来自“东西真的在转”；手段=维修权、胶带、广播；弱点=分散、无武装。
3. **记忆保存派**（民间记忆网络与旧史持有者）：不夺权，只保存“历史包袱”——对应游戏的 history burden 机制。
4. **体制内良心派**（司法、IT、机械部门中的倒戈者）：在体制内转向，是政权更迭的铰链。
5. **外部变量**（指挥堡、跨堡特工、建堡前史阴谋线）：随时可以把堡内博弈升级为存亡级事件（终止机制）。
