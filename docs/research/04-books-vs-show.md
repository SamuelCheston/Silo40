# 原著与改编的机制差异研究

> 用途：避免在文案中混用两套设定；识别改编侧可借鉴的机制增量，以及原著中尚未被改编的素材。
> 口径：只比较结构与机制，不复述具体剧情；改编侧的人名、组织名、集数与纪年一律不写入，统一用功能位描述。

## 1. 结构层差异

| 维度 | 原著 | 改编侧 | 机制影响 |
| --- | --- | --- | --- |
| 叙事切分 | Wool（现在时）→ Shift（前传，三段）→ Dust（终局） | 正篇 + 前史线 + 终局，按季推进 | 原著更适合“历史包袱”式时间轴；改编侧更适合“调查线”式悬念 |
| 纪年 | 公元 2049–2550 | 自有一套“大革命后”纪年 + 前史线 | 两套纪年不可混用；游戏采用原著锚点 |
| 主角视角 | 双主角：机械师与建堡者，读者比角色先知道真相 | 单主角：机械师线为主，建堡者线改为调查线并后置 | 双主角适合“真相已知、角色未知”的叙事；单主角适合“逐层揭露” |
| 真相节奏 | 建堡者线早早揭示终局 | 终局信息被拆成多季的调查节点 | 游戏可借用“碎片式揭露”，但不必复制季播结构 |

## 2. 人物功能的改写

改编侧大量重命名、合并或扩写人物。对机制设计有意义的是“功能位如何变化”，不是姓名本身：

| 原著功能位 | 改编侧处理 | 机制影响 |
| --- | --- | --- |
| 建堡前史主角：建筑师/众议员，轮班后化名 | 改为工程兵出身的政客，保留化名与身份错认 | “建造者被自己的机器困住”这一母题保留，但前史调查线更适合游戏碎片 |
| 主角配偶：被分离的妻子 | 改为独立调查者，主动追查真相 | 配偶从“被寻找的对象”变成“并行的调查者”，增加双线叙事 |
| 项目主脑：男性参议员 | 改为女性参议员，保留女儿作为幕僚 | 权力家庭结构保留，性别与职位可替换 |
| 飞行员妹妹：无人机飞行员 | 提前到前史线，并加入记忆抹除 | “记忆不可靠”成为前史线的核心机制 |
| 项目心理学家：设计轮班心理架构后自杀 | 改为记忆科学医生 | 从“设计者被计划压垮”改为“记忆技术的发明者与使用者” |
| 无对应人物 | 新增资本资助者 | 原著把末日阴谋写成国家行为；改编侧加入资本维度 |
| 无对应人物 | 新增神秘特工 | 为调查线提供跨季钩子 |

**结论**：人物姓名与关系可以整体替换，但以下功能位必须保留——**建堡者、项目主脑、记忆技术专家、机械师主角、IT 主管、司法执法者、记忆保存者**。游戏 NPC 设计应绑定功能位，而不是绑定某一版人名。

## 3. 同类剧情节点的处理差异

下表只比较“同一功能节点在两套叙事中的处理方式”，不写具体人名与集数：

| 功能节点 | 原著处理 | 改编侧处理 | 机制差异 |
| --- | --- | --- | --- |
| 市长之死 | IT 主管在副手水壶下毒，市长误饮 | 司法系统的打手行凶，IT 主管是幕后结构 | 从“个人谋杀”变为“体制暴力”，继承危机的合法性更脆弱 |
| 副手之死 | 被伪装成自杀 | 同被司法打手杀害 | 执法系统内部的灭口更直接 |
| 机械师之死 | 早死的机械师，作为起义前史 | 主角的恋人/修理店极客，為免酷刑自尽 | 从“背景事件”变为“主角动机”，情感杠杆更强 |
| 绿景广播 | 无对应桥段 | 叛乱方劫持全堡屏幕播放绿景，目击者被投药抹忆 | 增加“真相传播 vs 记忆管制”的竞速机制 |
| 大革命真相 | 由指挥堡主导的重置：移除免疫者、投药、清档 | 由本地 IT 主管主动焚书、投药、清档，并嫁祸叛军 | 从“外部处置”变为“本地自保”，主事者动机更复杂 |
| 起义领袖 | 免疫失忆药的老教师 + 运输工 | 无对应人物；记忆保存线改为民间网络与地下日记 | 从“个人领袖”变为“网络与文本”，更适合碎片系统 |
| IT 主管结局 | 被揭穿后送外，死于气闸火焰 | 重伤 → 伪造死亡 → 藏匿 → 公开自首、无防护服清洁赴死 | 从“被处决”变为“自我献祭”，可复用为“反派公开赴死”事件 |
| 主角返堡后 | 洗冤、当选市长，立即挖隧道 | 被投药失忆、立为傀儡市长，后恢复记忆 | 增加“记忆被夺走”的中间段，适合做政治悬疑 |
| 系统分析师命运 | 死于邻堡被终止 | 存活，并执行邻堡方向任务 | 改编侧保留续作空间；游戏可按需选择 |
| 邻堡陷落方式 | 叛乱、指挥堡开气闸关堡、少年躲进服务器暗堡 | 拒洁点燃叛乱、炸泵淹堡、杀 IT 主管、冲出气闸后被无人机与毒剂杀死 | 从“关堡”变为“突围后被外部清除”，外部威胁更可见 |
| 跨堡通讯 | 经邻堡设备联络各堡 | 同构，并加入无线电密语与躲避监听 | 通讯成为可被监听、可被伪造的机制 |

## 4. 机制层差异

| 机制 | 原著 | 改编侧抽象 | 机制差异 |
| --- | --- | --- | --- |
| 指挥之声 | 指挥堡真人指挥链（Shepherd）；但各堡 IT 以为自己在与一套系统打交道，背后是人只有极少数才参悟 | 本地 IT 密室中的“指令之声”，最终被证明是人在说话 | 从“制度性指挥”变为“不可见权威的祛魅” |
| 应急手册 | 指挥堡内部的处置手册 | 各堡 IT 主管可读的应急手册 + 上级处置文件 | 信息资产从一层变为两层，玩家可争夺副本 |
| 失忆药 | 指挥堡轮班药物 + 重置投药 | 可局部投药，也可经供水系统全堡投药 | 供水系统成为可被争夺、可被污染的机制节点 |
| 终止机制 | 远程释放“毒气”（纳米虫） | 分层输送管网：指挥堡 → 枢纽 → 各堡，泵入毒剂；关键管段可被封死 | 从“不可见的远程手段”变为“可被工程反制的实体网络” |
| 清洁服致死 | 劣质热封胶带 + 气闸纳米虫腐蚀 | 劣质热封胶带同构；气闸火焰消毒 | 供应链与维修权成为暗权的一部分 |
| 500 年终局 | E-Day 2550：算法选一堡，其余终止 | 尚未揭示，但“算法选人”的方向已被引入 | 终局可以后置，但“唯一胜出者”的机制可提前埋线 |
| Seed | 明确存在，掘进机全部指向它 | 尚未命名 | 逃生设施与掘进机网络可独立复用 |
| Silo 40 | 2212 率 11 堡断联，被物理摧毁；幸存者流散 | 截至现有改编内容未提及 | 这是本项目最安全、最有价值的原创空间 |

## 5. 改编侧可借鉴的机制增量

以下只保留机制，不保留名称、人物与情节：

- **年度纪念仪式**：以庆典重演被篡改的历史；短期提升凝聚力，长期可被真相派渗透。
- **违禁遗物制度**：旧世界物品分级、登记、没收与矿役刑罚；可承载信息碎片与黑市交易。
- **长期地下生活综合征**：环境性疾病、官方宣传与执法豁免；可作为恐慌与合法性的交叉杠杆。
- **民间记忆保存网络**：以实物与口述保存旧世界记忆；被镇压越狠，觉醒时爆发越强。
- **隐蔽监控与清洁间暗门**：监控权独立于正式警权；可作为反侦察与眼线机制。
- **加密档案 + 解码书组合**：真相以碎片形式跨世代接力；适合游戏的碎片收集链。
- **地下日记/一手史料**：记录镇压规模与死者数字；可作为 history burden 的硬证据。
- **叛乱后治理机构**：政变后的新治理安排与傀儡市长；适合政权更迭剧本。
- **建堡前史调查线**：灾难记忆被抹除、公共工程掩护、记忆修复导致身份错认。
- **分层输送管网与枢纽拓扑**：终止机制可被工程反制，但只能封住对应渠道。

## 6. 尚未改编的原著素材

以下为小说《Dust》内容、改编侧尚未呈现，**可优先做进游戏**（后续改编播出后需复核）：

1. 掘进机横向挖通两堡隧道；隧道是“招致毁灭的行为”这一主题。
2. Silo 18 被 Thurman 以纳米虫终止；约 200 人经隧道逃入 Silo 17；Shirly 封隧道断后。
3. Donald/Charlotte 的无人机发现毒区之外有绿地（“世界没有被毁灭，只是被围了一圈”）。
4. Donald 与 Juliette 隔着无线电互相试探（“两个主角以声音相遇”）。
5. Silo 1 内战：Anna 尸体被发现 → Thurman 复醒夺权 → Donald 越狱失败 → Darcy 牺牲 → Donald 引爆 Silo 1。
6. 每台掘进机都指向 Seed；幸存者徒步穿越毒尘带，发现世界已自愈，抵达 Seed。
7. 小说终局基调：“Donald 没有挑选更好的赢家，而是移除了唯一有权挑选的权威。”
