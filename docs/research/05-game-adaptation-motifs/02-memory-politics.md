## 2. 大革命与记忆政治（history burden 轴核心事件源）

### 2.1 自我污名化重置【改编侧抽象】

- 桥段：IT 主管为阻止上级清洗，主动焚书、清空服务器、向供水投记忆药，再把一切嫁祸给叛军；自己身败名裂，后代被罚做苦役。
- 机制内核：“拯救者被写成罪人”——官方叙事与真实历史的永久背离；被抹掉的历史成为 history burden。
- 映射：`histories` 事件模板：叛乱临界时，IT 特工可发动“自我污名化重置”：叛乱清零、信息碎片清空、但埋下 N 年后觉醒的定时事件（对应 `history_burden_awakened`）。

### 2.2 加密档案与解码钥匙【改编侧抽象】

- 桥段：真相被写成加密档案，解码需要特定一本书的指定页；百年后由法官→IT→矿役犯逐手破译。
- 机制内核：真相以碎片形式跨世代接力（对应游戏的“信息碎片”系统）。
- 映射：`histories` 收集链：存储介质（碎片 A）+ 特定书籍（碎片 B）+ 解码者（技术角色）= 解锁“多堡网络与终止机制”情报，开放新的结局路线。

### 2.3 年度纪念仪式【改编侧抽象】

- 桥段：每年庆祝“平叛胜利”：漂浮灯、楼梯滑梯、市长演说；官方戏剧重演被篡改的历史。
- 机制内核：仪式化记忆——合法性维护工具，但也是真相派的渗透窗口。
- 映射：周期性 `rules` 事件：凝聚力小幅恢复；若 history burden 高，则有概率在庆典中触发“记忆闪回”（觉醒事件）。

### 2.4 记忆保存网络与地下日记【改编侧抽象】

- 桥段：民间网络以儿童旅行指南等遗物保存旧世界记忆，被投药与绝育式镇压；运输工的日记记载了镇压规模与死亡人数。
- 机制内核：记忆保存者=活的 history burden 载体；被镇压越狠，觉醒时爆发越强。
- 映射：`special` 事件：发现记忆保存节点→选择镇压（合法性+ / 未来叛乱风险+）或默许（信息碎片+ / 秩序派不满+）。
