# Silo 世界观设定研究

> 用途：Silo40 楼层职能、资源系统、禁忌规则、外部环境事件的设定依据。
> 口径：本文把外部作品中的具体人物、组织与情节改写为中性机制描述；只保留可复用的设定结构与数值关系，不指认具体作品、角色或改编段落。
> 可信度标记：【原著明确】/【改编侧抽象】/【存疑】，出处随条标注。

## 1. 地堡（Silo）总体结构

### 1.1 规模与形制

| 设定项 | 内容 | 可信度 |
| --- | --- | --- |
| 楼层数 | 144 层，单一中央螺旋楼梯贯穿顶底 | 【原著明确】 |
| 人口 | 约 10,000 人；不同叙事版本会给出更精确的统计口径 | 【原著明确】+【改编侧抽象】 |
| 禁电梯 | 公约严禁机械化垂直运输（电梯、滑轮），层间移动只能步行 | 【原著明确】+【改编侧抽象】 |
| 放大镜禁令 | 超过一定倍率的放大镜被限制，防止居民观察过细之物 | 【改编侧抽象】 |
| 地堡数量 | 50 座人口地堡 + 1 座指挥堡；另有第 51 个目的地“Seed” | 【原著明确】 |
| 布局 | 各地堡相距仅数百米，成片分布于一片废墟城市郊外数英里处 | 【原著明确】 |
| 建造年代 | 2049 年完成设计，2052 年封堡 | 【原著明确】 |

### 1.2 楼层职能分布（抽象分区）

不同叙事版本给出的楼层锚点略有差异，但垂直分区稳定：

| 区带 | 典型职能 | 机制作用 |
| --- | --- | --- |
| 顶层 | 食堂与外景大屏、治安官办公室、关押“想出去者”的拘留区、通往地表的气闸 | 信息展示、执法入口、清洁仪式的舞台 |
| 上层 | Judicial 办公室、管理层公寓、IT 办公室 | 正式权力与隐蔽权力重叠区 |
| 上层隐蔽区 | 监控室藏于清洁用品间暗门之后 | 全堡摄像头的物理入口 |
| 中层 | 医疗中心、分段医院、农场与磨坊 | 人口健康、食物生产与配给 |
| 下层 | 矿层入口、副治安官驻点 | 资源开采、刑罚劳动、基层执法 |
| 底层 | 机械区、发电机房、地下水泵 | 能源、水、空气与结构维护 |
| 底层之下 | 封闭 cavern 与掘进机 | 终局逃生设施与禁忌知识 |

小说侧的对应关系是：IT 位于地堡上部、掌握服务器与真相；Mechanical 位于 Down Deep（最底层），负责发电机、泵与空气；市长与副手可以徒步下行约 100 层到 Down Deep 面试机械师。【原著明确】

### 1.3 Cavern 与掘进机

- 地堡最底部、约 30 英尺厚混凝土板之下，有一个横跨整个堡体周长、高数层的圆柱形 cavern，内有建造地堡时使用的巨型掘进机，底部有浅水层与一条通往巨大金属门的隧道。【改编侧抽象】
- 小说对应物：每座地堡底部都埋着一台隧道掘进机，全部指向同一方向——指向 Seed；机械师出身的市长可以启动本堡掘进机横向挖向邻堡。【原著明确】

## 2. 部门与分工

### 2.1 小说侧部门【原著明确】

| 部门 | 职能与位置 | 机制作用 |
| --- | --- | --- |
| IT | 地堡上部；服务器、监控、与指挥堡的隐秘线路；唯一知道指挥堡存在的部门 | 信息垄断、暗权、跨堡通信 |
| Mechanical | Down Deep；发电机、泵、空气系统；“知道东西怎么转，忍不住去测试” | 底层技术能力、设施维护、反制垄断 |
| Supply | 中段；物资配给与库存 | 资源调度、配给政治 |
| Sheriff / Mayor / Judicial | 治安与行政；Mayor 为民选最高文职，Sheriff 执法 | 正式合法性、执法与继承规则 |
| Farming（Farms） | 中段农场层 | 食物生产与饥荒风险 |
| Porters | 楼梯人力运输工，有亚文化与消息传递网络 | 信息扩散、跨层物流 |

### 2.2 改编侧部门扩展（抽象）

改编侧在小说部门之外补充了若干职能，可抽象为：

- **矿层**：资源开采与刑罚劳动合一；违禁品持有者可被判矿役。
- **农场层**：食物生产、殡葬与配给冲突的物理舞台。
- **隐蔽监控单元**：隶属 IT 的暗面职能，负责全堡隐藏摄像头与监控室。
- **武装执法单元**：Judicial 下属的武装力量，承担平乱、抓捕与灭口。
- **运输工网络**：楼梯运输工的调度站与口传网络，是跨层消息的天然通道。

这些职能只提供机制位，不绑定具体人名或剧情。【改编侧抽象】

### 2.3 权力链（两种抽象模型）

**小说模型**【原著明确】：

```text
指挥堡（Shepherd）
   └─ 隐秘线路（只有各地堡 IT 主管知道）
各地堡表面秩序：Mayor → Sheriff
各地堡真实权力：IT 主管（可在市长死后依公约代理）
底层：Mechanical（掌握设施实际运转，被系统性蒙蔽）
```

**改编模型**【改编侧抽象】：

```text
隐藏指令通道（声音或文本，来源不可见）
   └─ 本地 IT 主管
        ├─ 市长继承与任免
        ├─ 档案与监控
        └─ 供水投药权
表面行政：Mayor / Sheriff / Judicial
底层：Mechanical / Supply / Medical / Mines / Farms
```

两种模型的共同机制是：**正式权力与信息权力分离**；IT 是唯一同时接触外部指令与本地档案的部门；底层技术部门掌握设施的实际运转，但被排除在真相之外。

## 3. 资源循环与能源

| 设定项 | 内容 | 可信度 |
| --- | --- | --- |
| 电力 | 每座地堡由底层的发电机供电，高压蒸汽驱动，蒸汽来源为地热；IT 办公室可独立供电并直连指挥堡 | 【原著明确】+【改编侧抽象】 |
| 食物 | 农场层农耕 + 磨坊；内战中断供可以饿死下层，但叛军也可能夺取农场层反制 | 【改编侧抽象】+【原著明确】 |
| 水 | 地下水系统；底层水泵可被炸毁导致淹堡；记忆药物可经供水系统全堡投放 | 【原著明确】+【改编侧抽象】 |
| 回收 | 多个回收站；死者遗物统一回收，“每个身体都是资源” | 【原著明确】+【改编侧抽象】 |
| 医疗 | 分段医院、长期护理病房；可承担生育、创伤与流行病管理 | 【改编侧抽象】 |
| 矿 | 矿层产出矿物，也是刑罚地；严重时可向矿层投放毒饵 | 【改编侧抽象】 |

## 4. 外部世界（Outside）

### 4.1 表象与真相

| 层 | 居民所见 | 真相 | 机制作用 |
| --- | --- | --- | --- |
| 食堂大屏 | 灰色荒原、一座山丘、一棵枯树，散落着历代清洁者的尸体 | 摄像头镜头被刻意保持肮脏以强化绝望感；画面本身基本真实 | 日常恐惧的视觉来源 |
| 清洁者头盔 | 绿意盎然、生机勃勃的世界 | 面罩是高分辨率显示屏，播放合成绿景；有时限与范围限制 | 处刑即宣传 |
| 空气 | “外面剧毒，必死” | 局部为真：致命区环绕地堡群，是人为布设的纳米机器或毒尘；致命区之外世界已恢复 | 终局反转的物理基础 |

### 4.2 清洁（Cleaning）机制

- **核心律法**：任何人公开表达“想出去”，就必须被送出去清洁外部传感器，且不可撤销（可申请一次听证）。这是公约的第一规则。【原著明确】+【改编侧抽象】
- **防护服是处刑工具**：IT 用劣质热封胶带暗中让所有防护服必然失效；清洁者出舱后必死，以“验证”外面有毒。机械师若换上优质胶带，清洁者就可能存活。【原著明确】
- **气闸手段**：气闸喷出的“惰性气体”可以是纳米虫云，专门腐蚀劣质胶带并杀死舱内人；气闸消毒火焰也可作为处刑手段。【原著明确】+【改编侧抽象】
- **拒洁先例**：清洁者拒绝清洁、走出摄像头视野，会让全堡目击“他没死”，瞬间击穿信条；这一先例可以点燃邻堡叛乱。【原著明确】+【改编侧抽象】

## 5. 遗留科技与禁令

### 5.1 公约与处置手册

- **公开公约**：规定堡内生活的基本规则，包括出去请求不可撤销、禁电梯/滑轮、限制高倍放大镜、法官弹劾条件、生育与家庭条款等。多数居民只一知半解。【原著明确】+【改编侧抽象】
- **处置手册**：指挥堡内部运行的应急程序手册，规定叛乱、失联、清洁失败等情境的处置梯度；不覆盖所有未知条件。【原著明确】
- **隐藏终局文件**：与公开公约同名但内容不同的终极计划，规定数百年后只保留一座地堡并终止其余（含指挥堡）。【原著明确】
- **改编侧扩展**：本地 IT 主管可读的应急手册、上级处置文件与隐藏指令通道，构成“公开规则—内部手册—终极文件”三层信息资产。【改编侧抽象】

### 5.2 Relic（遗物）制度【改编侧抽象】

- 定义：大革命前的一切物品均为违禁遗物，持有违法，可判矿役；少数物品（如手表）可登记合法化。
- 常见类型：存储介质、个人随身物品、日用品与包装、影像设备、旧世界地理与生活读物、旧版书籍。
- 分级与刑罚：存在颜色或等级分级的违禁品清单；矿役是常见刑罚。
- 小说对应：硬盘是最高违禁品，持有即重罪；“想出去”与硬盘共同构成两条主线禁忌。【原著明确】

### 5.3 记忆药物（遗忘机制）【原著明确】+【改编侧抽象】

| 机制 | 内容 |
| --- | --- |
| 指挥堡轮班药物 | 值班员服用钝化记忆与情感的药物；重置时全堡投药抹忆 |
| 供水投药 | 记忆药物可经供水系统全堡投放，抹去数周至数年记忆 |
| 免疫个体 | 少数人对药物天然免疫，成为历史记忆的活载体 |
| 极端后果 | 大规模抹忆可导致自杀、儿童被遗忘而饿死等次生灾难 |

### 5.4 长期地下生活综合征【改编侧抽象】

- 症状梯度：不自主抽搐 → 四肢震颤 → 疼痛痉挛 → 平衡失调 → 认知衰退 → 神经系统停摆。
- 官方叙事：把病症解释为外部环境或生活方式问题，并用宣传标语维持秩序。
- 病因假说：血液病、维生素缺乏，或长期地下生活导致的自然反应。
- 制度接口：患者可获得执法豁免或特殊岗位安排，成为可被政治利用的群体。

## 6. 地堡网络与处置机制

### 6.1 指挥堡与指挥体系

- 小说：指挥堡是隐藏的指挥中心，无家庭、无世代；男性每约 6 个月轮班（冷冻往返），女性原则上全程冷冻；以处置手册管理各地堡，以隐藏终局文件规定约 500 年后的唯一胜出者；E-Day 定于 2550 年。【原著明确】
- 改编：指挥堡为指挥中心，建堡前史人物冷冻驻守；通过隐藏指令通道指挥各堡 IT 主管；可监控、干预、终止。【改编侧抽象】
- 共同机制：指挥堡掌握跨堡通信、档案与终止渠道；本地 IT 是唯一接口；普通居民不知道其他地堡存在。

### 6.2 Reset（重置）与终止机制

| 机制 | 小说 | 改编侧抽象 |
| --- | --- | --- |
| 触发 | 叛乱被 IT 压制但失控风险高 | 叛乱威胁打开气闸或接触他堡 |
| 手段 | 减口 + 全堡投药抹忆 + 清空服务器 | 焚书、清服务器、供水投药，并把官方叙事嫁祸给叛军 |
| 终极手段 | 远程释放致命“毒气”（实为纳米虫群）终止全堡 | 通过分层输送管网向失守地堡泵入毒剂；关键管段可被工程手段封死 |
| 反制 | 干扰终止信号可使远程终止失效，但可能招致物理摧毁 | 封堵本地管段只能保住对应渠道，不免疫其他渠道 |

- **Silo 40 事件（小说）**：2212 年，Silo 40 率领 11 座地堡切断与指挥堡的联络并干扰终止信号；指挥堡被迫物理摧毁，Donald 下令轰炸 Silo 40。作者确认 Silo 40 已毁灭、部分幸存者流入其他地堡。【原著明确】
- **改编侧结局状态**：曾出现“仅剩少数地堡活跃”的结局描述，但具体名单属单一来源，且与地堡总数存在矛盾，不纳入机制基线。【存疑】
- **分组结构**：改编侧的输送管网采用“指挥堡 → 分层枢纽 → 各堡”的拓扑；分组数量与总堡数存在口径冲突，落地时以项目配置为准。【存疑】

## 7. Seed（终局目的地）

- Seed 是致命区之外的独立设施，储备食物、工具、植物种源与重建材料，是“唯一胜出地堡”的目的地；所有地堡的掘进机都指向它。【原著明确】
- 改编侧尚未命名该设施，但“掘进机指向外部目的地”的机制可以独立复用。【改编侧抽象】
