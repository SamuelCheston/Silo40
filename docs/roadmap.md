### 逃出群体与《越岭》逃离模型

**状态：Layer 0/1/2 已实装（16 分册分层），余一项收尾。** 已落地：顶层立场（市长/IT 三档，带权随机决策，地堡种子复现）、准备账本（防护服/补给/材料/预案功能位覆盖/演练/照护/生产起点/接应档位/暴露，划拨即扣减）、《越岭》事件链四节点（意愿→路线→开窗→离开，见 [36](story/endings/36-rebellion-nodes.md)/[37](story/endings/37-rebellion-event-spec.md) 分册）、出发结算级联（容量 D→存活率 S→维存 M→追踪 T→逃出人数，立场只塑形输入，阻挠自然结算为人数 0），以及 Layer 2 的堡外段：堡外月度维持（补给/防护服/路线三侧面各自结算，覆没写明冻死/耗尽/被困）、追踪四档（没人注意/已被察觉/咬住痕迹/正在追捕，由筹备暴露＋出发清点＋safeguard 风险＋1 号注意力定档，改变选择空间而非必然失败）、群体质量（老人/伤者/工匠/领头人组合事实，进 P2 作玩家贡献项，资格仍只读群体存续）。仲裁仍只读 `EscapedGroup`，不读立场与账本（ADR-0008）。剩余：

- 追踪的反制入口（"反制藏进日常小动作"批次）——**逃跑筹备侧已落地**：审计没收已移除（反向梯度），改为组织怀疑度驱动的 IT 响应层（镇压/蒙住 1 号/不作为的带权随机三选一，后果只抬成本与风险，见 [ADR-0014](../knowledge/adr/0014-countermeasures-cost-suspicion-org-only.md)）；**死亡线的远程终止渠道已绑定**：值夜检修动作 `TERMINATION_CHANNEL_JAM` → `termination_channel_disrupted` 写 `network_jammed`，`termination_release` 读该守卫（只免疫远程渠道，物理投送照旧）；**本地整肃已接后果与反制**：执行节点按名册是否被动过分档削人口/记忆，复核夜调换名册动作 `PURGE_ROSTER_TAMPER` → `silo1_purge_softened` 取轻档；信息流通侧（T1 指标恶化、T2-2 信道审计、T3 个体档）仍按 [20-world-countermeasures-design.md](research/20-world-countermeasures-design.md) §7 测试账与重调判据同批落地（长期约束见 [ADR-0012](../knowledge/adr/0012-world-countermeasures-read-public-facts-only.md)）。

**移除登记（设计者裁决）**：原待做两项——「逃出群体与原驻地的后续关系（回传、沉默或原驻地毁灭后的独立存续）」与「散逃者尾声」——已移除，不再排期。理由：**逃出发生时原堡已被摧毁，不存在可延续的后续关系；没赶上队伍的人必死，没有尾声可写。** 口径落点见 [16 §3.2 裁决 3](research/16-preparation-outcome-design.md)、[36 §5／§8](story/endings/36-rebellion-nodes.md)、[37 §3](story/endings/37-rebellion-event-spec.md) 与《越岭》结算叙事。

### 《共证》外溢准备工作

**状态：未实装（用户裁决：本轮不做）。** 裁决口径：**外溢不进胜负判定——外溢为零同样可以判胜，外溢数量只影响结算分数**（仲裁已按此实现：出站信号到达的不同地堡数只进《共证》加权，不进资格）。外溢准备工作与逃离模型同样复杂，需要单独设计：

- 受限渠道的选择与建立（专线、跨堡信号、实体交接各自的因果与风险）——**建立侧已随《越岭》Layer 1 落地**（`SpilloverPrep.Channels` 账本＋三种信道接触卡），投递侧仍缺；
- 外部接收方的独立核验与再复制结算（跨堡编排、接收堡模拟状态与"独立复制一代"的判定）；
- 外溢暴露与宿主风险的结算（异常流量、可操作观察与处置升级）。

设计完成前，《共证》资格只读本地活链与跨部门公共事实；外溢相关节点只以注释预留。准备侧（受限信道、包裹质量与暴露代价如何换算为外溢触达与接收）的机制设计已完成，见 [16-preparation-outcome-design.md](research/16-preparation-outcome-design.md)；外溢维持既有裁决口径，只影响结算分数，不进资格。

**状态：设计完成，尚未实现。** 公式、原著边界、验收与 `TODO(balance)` 目标见 [10-it-control-credibility.md](research/10-it-control-credibility.md)。

6. **玩家拆台路线**：接调查、执行失败、核验、公开发布和 IT 反击，按首档 4–5 次有效操作、pact 累计 8–10 次的 `TODO(balance)` 目标校准。

### LLM 上下文档位可调

**状态：待做，尚未实现。**

允许用户调整喂给模型的上下文档位，与已有的 LLM 参与度档位正交：参与度决定“什么时候问”，上下文档位决定“问的时候给多少料”。

| 档位 | 上下文内容 |
| --- | --- |
| 极简 | 仅当前 NPC、候选动作、输出契约 |
| 标准 | 在极简基础上，加地堡大局指标、相关派系人物、近期事件摘要 |
| 丰富 | 在标准基础上，再加本堡主线经过 |
| 世界观 | 在丰富基础上，再带 silo 设定、其他地堡关系、长期剧情线 |

档位之外保留独立开关或配置项：个人记忆、条文法规、事件摘要条数、是否携带其他地堡情报。

动机：预算紧张的用户可压到很小的上下文，预算宽裕的用户可放开上下文，在成本与决策信息丰富度之间自行取舍。
