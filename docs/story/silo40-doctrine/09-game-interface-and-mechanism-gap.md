# Silo 40 的两份教义文件（二创设定） · 与游戏的接口与机制缺口

> 拆分自 [Silo 40 的两份教义文件（二创设定）](../silo40-doctrine.md)；目录、章节映射与出处见该索引。

## 5. 与游戏的接口（只描述映射）

【项目原创】

| the Errand 的部件 | 游戏侧对应物 | 映射方式 |
| --- | --- | --- |
| 五个阶段 | `ProgressStage`：`arrival` / `first_signal` / `archive_awakened`（阶段四、五不新增 stage） | 阶段一≈`arrival`、阶段二≈`first_signal`、阶段三≈`archive_awakened`；阶段四、五靠指标与关系条件继续解锁 |
| 节点触发 | `events/action_gates.json` 的条件集：`event_completed` / `stage_at_least` / `metric` / `relation` | 每个节点的"触发条件"只使用这四类条件能表达的量，不引入新条件类型 |
| 完成判据 | 现有可观测状态（事件完成、指标、关系、阶段） | 只声明"什么算做到"，**不绑定、不排序具体行动**；行动集由玩家自行选择 |
| 底线 | 叙事约束 | 不进入 gates；违反只影响叙事与结局解释 |
| 任务失效 | 叙事条件 | 不新增结局类型；TIME 等既有结局不变 |
| 阶段推进 | `stages[].when` 的 `event_completed` 条件 | 现有三条 stage 规则保持不变；the Errand 不新增 stage |

【项目原创】三条使用原则：
- 文件是**叙事层的国策树**，不是操作手册；节点编号、条款号都不进入代码。
- 文件不指定、不排序具体行动；行动是否可见、可用，仍由现有 gates 决定。
- 不新增行动、阶段或结局类型；失败与超时只写"会发生什么"。

## 6. 机制缺口（只列缺口，不改代码）

【项目原创】以下缺口按"叙事已成立、机制接不住"列出；每条只说明缺什么，不提出实现要求。

1. **条款冲突没有优先级表达**：`unlock`/`available` 只能表达条件，不能表达"命 > 他人 > 秘密 > 真相"的裁决顺序。
2. **"审查收紧"没有环境状态**：生育审查变严、失踪增加、口径统一等只能写成事件文案，没有可驱动多事件的指标。
3. **"睡了多少年"没有认知状态**：时间是全局 `CurrentYear`，特工"不知道年份、只能问三件事"的认知差无法表达。
4. **"目标堡不存在"没有判定**：驻地随机分配，没有目标台账，无法校验"目标已注销"并转投下一座。
5. **"任务失效"没有合法出口**：结局类型里没有"主动隐退、以本地身份活下去"，TIME 不是放弃，the Errand 的失效条款在机制上无处落地。
6. **文件与证据不是可持有对象**：`known_fragments` 只是计数，不能表达"持有 the Errand""证据已保全/已销毁""证人仍在"。
7. **失忆者/清档者没有人物状态**：无法标记"档案被清、无法核对来历"的 NPC，§3.5 的自我处置只能靠文案。
8. **见证人没有生命周期**：节点 18"保护证人"没有可追踪的实体，证人的存活、失联、死亡无法进入判定。
