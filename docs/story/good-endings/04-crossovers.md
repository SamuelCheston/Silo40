# 三线交叉与互相拆台

> [返回总索引](../silo40-good-endings.md) · [通用前提](./00-common.md) · [《共证》](./01-information.md) · [《越岭》](./02-rebellion.md) · [《无人裁决》](./03-time.md)

## 1. 重算后的总关系

【裁决更新】《共证》资格改为本地活链＋跨部门公共事实，外溢只作评分项（本轮未实装）。这使三条线的距离再次变化：

- **它与《无人裁决》最接近。** 两者都需要活着、藏得住、保持开放的宿主直到结算，都不能靠一次公开煽动跳过长期维持。区别在于《无人裁决》必须把开放思潮保持到覆灭结算的快照时刻，而《共证》必须让活链与公共事实立住。
- **它与《越岭》的张力仍在。** 传播链需要活着的复制者、日常岗位和开放人口，撤离却会带走其中相当一部分人。逃出者可以带走档案，但那是《越岭》的幸存事实，不自动算作《共证》的外溢评分。
- **三线仍只选一个主结局。** 同一事实可以同时改变另外两条线的资格与支撑，不能只给路线分加减分而不解释人口、证据、宿主和时间发生了什么。

## 2. 六个方向的直接帮助与拆台

| 路线的举动 | 对另一条路线的帮助 | 对另一条路线的拆台 |
| --- | --- | --- |
| **《共证》隐匿培养传播链** | 反制与核验方法可帮助《越岭》保护撤离者；长期保宿主、保开放、保基础设施与《无人裁决》高度同向 | 若玩家选择公开化提速，可能在结算前暴露宿主、招来处置，使《无人裁决》失去存续驻地；若为保宿主而限制人员离开，《越岭》会失去窗口 |
| **《共证》要求活着的开放宿主** | 留住的工程、医疗、 Supply 与开放 Cohort 可维持有序撤离，也能形成《无人裁决》所需人口与公共表达 | 核心复制者、证人与开放人口一旦被《越岭》优先送走，链会停止本地复制；宿主若在结算前被毁，《共证》与《无人裁决》同时失去前提 |
| **《越岭》组织实际离开** | 先遣往返可提供独立外部观察；逃出者带走的档案可成为未来轮次外溢评分的载体 | 工程骨干、证人和开放 Cohort 离开会掏空《共证》的活着宿主与《无人裁决》的人口思潮；公开出走还可能破坏《共证》的隐匿 |
| **《越岭》提高公开反抗** | 可迫使 IT 暴露法警调度、制造执行失败，为《共证》提供责任链，也可为两条长期路线缩短旧秩序控制时间 | 没有路径与组织的高叛乱会毁档、伤人、破坏资源与结构，使《共证》失去复制材料与宿主、《无人裁决》失去可存续驻地；公开动荡还会破坏隐匿 |
| **《无人裁决》维持低暴露、开放与存续** | 为《共证》提供最佳孵化环境：活着的宿主、持续记录、开放 Cohort 和基础设施；也可为有序撤离保留条件 | 为等到覆灭结算而压低一切风险动作，可能让《共证》的活链建设停在浅层、《越岭》的窗口关闭 |
| **《无人裁决》等待覆灭结算** | 结算后外部介入能力消失，尚未完成的传播与撤离叙事进入结局画面 | 结算瞬间定格快照：等待期间宿主被毁则《无人裁决》失去驻地；结算后不留内容窗口，不存在"覆灭后再补"的可能 |

## 3. 四个共享的三角冲突

### A. 同一份传播单元：继续复制、交给逃出者，还是留作长期来源

一份包含事实、核验、反制、隐匿和再传递方法的传播单元，可以同时：

- 作为《共证》本地活链的能力载体（未来轮次若外溢，也是评分的载体）；
- 作为《越岭》证明路线、保护撤离者与建立接应点的行动材料；
- 作为《无人裁决》维持长期求证、但不立即公开的来源。

过早对外发送（未来轮次）会暴露宿主；把唯一完整单元随逃出者带走会让原驻地失去复制能力；长期扣留又可能让接收窗口关闭。复制文本可以缓解材料唯一性，却不能复制不在场的人、岗位与独立观察。

### B. 同一批开放人口：复制者、逃出者，还是覆灭前本地主流

开放 Cohort 是最愿意独立核验、参加撤离和质疑旧秩序的人。《共证》需要他们活着并在日常岗位中复制，《越岭》需要他们成为实际逃出者，《无人裁决》需要他们留在驻地构成覆灭前人口与公共表达。

让他们优先离开，逃出群体更有机会延续，却会同时削弱原宿主传播链与本地开放资格；把他们全部留下，可能保住《共证》或《无人裁决》，却让撤离失去组织者与目标人群。

《无人裁决》读取的是 **覆灭结算前夕的驻地思潮**，不能拿已经离开的开放群体替驻地补票；《共证》读取的是本地活链与跨部门公共事实，逃出者带走的材料归《越岭》的幸存事实，不自动算作《共证》的外溢评分。

### C. 同一次暴露：外溢证据、撤离窗口，还是提前毁灭

IT 被迫直接调度 Judicial 时，可能留下《共证》最需要的暗权证据；同一调度也可能封住《越岭》的出口，或清除《共证》与《无人裁决》共同依赖的开放节点。未来轮次若进行跨堡外溢，还会增加 Silo 1 的异常观察，使"再发送一份"和"再藏一个月"成为互相冲突的需要。

玩家可以诱导危机，却不能只领取证据而不承担处置后果。反制也必须分渠道：终止信号受干扰不等于物理轰炸失效，宿主藏过毒气不等于获得全面免疫。

### D. 同一个终局时钟：本地活链、实际逃离，还是原驻地活到结算

- 对《共证》，最重要的是本地活链与跨部门公共事实成立，且宿主活到覆灭结算、未被格式化。
- 对《无人裁决》，原驻地必须活到覆灭结算，且覆灭前夕开放快照合格。
- 对《越岭》，实际离开与独立群体存续是硬事实；原驻地是否毁灭、覆灭结算是否到来都只作尾声或窗口。
- 若《共证》的宿主也活到覆灭结算，且覆灭前思潮合格，两条路线可同时进入候选；若宿主在结算前被毁，《无人裁决》与《共证》同时失去驻地前提。

## 4. 一个三线相撞的预期终局局面

在某局后段，可以同时出现以下状态：

1. 驻地内传播链已经能自我复制，但公共事实还差最后几个部门的独立核验，宿主必须继续隐匿活着；
2. 先遣队已确认接应点，最后几批撤离者等待通过，工程骨干和开放 Cohort 同时是撤离组织与传播链的核心；
3. Silo 1 明显衰弱，驻地即将举行决定封闭或开放的公开质询，而玩家的高风险动作已经引起注意。

玩家最后的关系与行动能力只够重点支撑一件事：

- **留下核心节点并完成最后的公共事实核验**：可能形成《共证》，但会错过撤离窗口；宿主若随后在结算前被毁，《无人裁决》失格。
- **护送核心节点与最后几批人离开**：可能形成《越岭》，逃出者带走的档案归其幸存事实；驻地开放人口进一步下降，《共证》活链与《无人裁决》快照都被削弱。
- **暂停撤离与公开动作，保住公开质询和原驻地**：可能守住《无人裁决》的覆灭前快照，也可能让《共证》的活链停在浅层、永远失去撤离路线。

如果此前实际成果已经使多条路线同时合格，则按结局体系进入统一加权；同分时《共证》优先于《越岭》，《越岭》优先于《无人裁决》。其他成果保留为事实性尾声，不能让一次终局同时显示三个主胜利。

## 5. 容易混淆的候选边界

| 实际结果 | 可以支持什么 | 不能额外冒充什么 |
| --- | --- | --- |
| 本地活链成立、公共事实跨部门可复核、宿主活到结算 | 《共证》（外溢为零不影响资格，只影响分数） | 不能因外溢为零而降格为《公议》 |
| 本地公开事实稳定，但活链未成立（只会背诵玩家版本） | 公开约章等本地成果；《公议》方向 | 不能直接判《共证》 |
| 逃出群体活着并保存档案 | 《越岭》 | 带走的档案不自动算《共证》的外溢评分 |
| 宿主在结算前暴露并被毁 | 按实际结果进入《遗忘》《寂堡》等 | 不能用"已经发出很多材料"追授《共证》 |
| 本地活链成立，宿主也活到覆灭结算且快照合格 | 《共证》《无人裁决》共同进入候选 | 不能显示两个主结局 |
