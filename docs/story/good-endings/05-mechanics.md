# 机制接口：stage、行动门控、派系部门与思潮

> [返回总索引](../silo40-good-endings.md) · [通用前提](./00-common.md) · [《共证》](./01-information.md) · [三线交叉](./04-crossovers.md)

## 1. 剧情台阶不是新增 stage

当前阶段链只有：

```text
arrival
  → first_signal
  → archive_awakened
```

- 成功 Gather Info 才进入 `first_signal`。
- 成功 Share Info 才进入 `archive_awakened`。
- 此后不新增剧情 stage，继续由关系、威望、宣传、部门状态、事件完成情况和跨堡行动门控承接。

| 现有状态 | 《共证》 | 《越岭》 | 《无人裁决》 |
| --- | --- | --- | --- |
| `arrival` | 落脚，辨认第一位能继续核验与复制的本地接收者 | 落脚，区分离开意愿、夺权欲望与恐慌 | 落脚，评估是否值得长期维持而非立即公开 |
| `first_signal` | 建立跨部门来源，同时确定宿主隐匿和日常掩护方式 | 建立工程、供给、医疗关系，开始路线调查 | 建立低暴露关系，让开放问题进入普通 Cohort |
| `archive_awakened` | 接收者开始独立核验，事实、方法与隐匿交接进入复制链 | 路线事实可以分享，撤离主张进入公开组织 | 材料离手但发布节奏受控，公共讨论获得持续来源 |
| 后续无新 stage | 保住宿主与开放人口，完成外部独立下一代复制；宿主随后毁灭也不使链消失 | 先遣确认、分批公开反抗、实际离开与群体存续 | 维持存续与开放，经历覆灭前夕抉择，等待权威覆灭事实 |

任何“进入下一阶段”的叙事，都必须对应成功行动或明确事件结果；不能用月份经过替代。外部接收方的独立复制同样必须由实际交接、观察和后续事件确认，不能只改一条结局文案。

## 2. 现有行动门控在剧情中的功能

| 现有内容 | 当前门控要点 | 剧情中的正确用法 |
| --- | --- | --- |
| Gather Info | 开局可用 | 获得本地观察，不直接获得全堡确信，也不让普通居民凭空获得外堡知识 |
| Share Info | `first_signal`；至少一个已知碎片 | 让材料进入部门与人物网络；成功后才推进 `archive_awakened`；《共证》还须继续形成方法与外部复制 |
| Build Connection | `first_signal` | 建立核验、复制、撤离或长期公共讨论所需的部门关系与日常掩护 |
| Conduct Propaganda | Mayor 关系达到既有解锁条件，且已到 `first_signal` | 扩大公开主张；不能替代独立证据、组织能力、开放人口或隐匿存活，也不是《共证》的默认最优解 |
| Incite Rebellion | 政治威望与 Mayor 关系达到既有门控 | 形成公开动荡；只有转化为实际逃离才支持《越岭》，并可能破坏《共证》的宿主隐匿 |
| Publicize Faction | `archive_awakened` 与既有威望门控，且仍受派系代表条件约束 | 让公开派系承担政治表达；不是任何一条好结局的必备按钮，公开化还会提高《共证》的暴露风险 |
| STATION_INTEL／SILO1_INTEL | `first_signal` | 确认本地或 Silo 1 的实际状态，避免把传闻当权威事实 |
| STATION_INFILTRATE | `archive_awakened` 与 Mechanical 关系门控 | 可制造本地合法性、凝聚力与部门紧张后果，不能被写成无代价“开门”或隐匿 |
| STATION_DECEIVE／SILO1_DECEIVE | `archive_awakened` 与宣传门控 | 提高目标叛乱、恐慌与亲外；同时必须承认 Exposure、反间谍和驻地后果，不能直接填写完整复合思潮 |
| STATION_TRADE | Supply 关系门控与 `first_signal` | 消耗驻地 Supplies，换取合法性、凝聚力与玩家威望，可服务宿主长期存续，但不自动产生开放思潮 |

本文不新增行动，也不要求玩家按固定次序使用它们。某些剧情事实若当前机制尚不能表达，应作为内容落地前的资格缺口处理，不能用文案假装已经结算。

## 3. 部门与派系不能写成固定战队

- **Mayor／Police**：可成为秩序、公开调查、宿主日常掩护或撤离组织的合作方；Mayor 个人正统性高不等于已经知道 IT 暗权，更不等于知道 Silo 1、Silo 40 或其他地堡。Judicial 也不会因 Mayor 高正统性自动转向。
- **Judicial**：既能执行 IT 调度，也可能在低 `W` 后附着 Mayor 或公开约章；其当前附着必须影响公开核验、证物、宿主隐匿与封路剧情。
- **IT**：始终按隐蔽权力与 Protocol 行动，不能被写成公开的叛乱友军。IT 主任层是驻地中可能接触上层控制网与 40 号材料的受限知情层，但其内部人员可以掌握多少仍由实际权限与碎片决定；个人泄漏或忠诚变化不会自动生成公开反 Silo 1 组织。
- **Mechanical／Mines**：提供物理记录、工程能力、反制验证与撤离可行性，不垄断反制、传播或逃离资格；其他部门也可能按实际能力参与。
- **Supply／Agricultural／Medical**：既保存物流、生产与诊疗证据，也决定复制者、撤离者和长期宿主能否活着，而不是让口号自行维持。
- **派系**：由 Cohort 聚类与持久身份产生。影响力、凝聚力、公开状态、Stance、Memory、Demands 与人物野心决定其能做什么，不能预设“开放派必然善良、忠诚派必然愚蠢”，也不能把公开派系人数直接当成《共证》的外部复制结果。
- **具名人物**：提供不可替代的推动、背叛、核验、交接或转向，但一个高影响力开放人物不能代替人口思潮，也不能独自创造传播链或幸存群体。
- **临时协作**：反制、复制和撤离项目是能力网络，不是新增“反抗者阵营”或第五类结局主体；参与、贡献、实际保护与知情程度分别成立。

## 4. 思潮判定的叙事纪律

1. 《共证》要求求证在复制链中具有实质地位，并要求宿主承认外部经验的正当性；单纯知道暗权事实、闭守群体要求追责或只听玩家背诵结论都不够。行动隐匿不等于秘守价值观，但“外向＋秘守”的外部崇拜不能替代独立核验，也不能充当《无人裁决》的合格开放联盟。
2. 《越岭》通常需要开放立场，但“想出去”不等于能组织离开，更不等于离开后能活。
3. 《无人裁决》的开放资格以 Cohort 人口加权为基础，以公开派系和具名人物为政治表达；不能只读部门派生值或一个代表人物。
4. 当前合格方向是亲外成为主导或复合主导的一极；未来复合思潮必须明确包含承认外部、他堡经验或重新审视封闭秩序的正当理由。多轴设计启用后应读取轴谓词、位置与显著性，不能从复合族名或旧标签静默推出完整立场。
5. 纯种地堡思潮即使稳定、繁荣、凝聚力高，也不合格。
6. 覆灭后余波造成的新亲外、新恐慌和新叛乱，不得写入覆灭前夕快照。
7. 玩家行动创造受众经历，不直接填写答案。同一 Observation 对同一受众只结算一次；外向、求证、公议、协商和试验等方向必须由实际材料、结果与归因支持，不能靠“传播链已建立”一条文案一次性发齐。
