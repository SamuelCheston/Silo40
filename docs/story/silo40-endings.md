# Silo40 结局线：剧情台阶与事件链

> 日期：2026-11-14
> 性质：剧情与事件链设计，不包含代码、事件文件、配置或数值改动。
> 范围：玩家作为 Silo 40 外派特工进入的随机驻地（2–17 号）；Silo 18 正典人物、事件时序与独立结局不接入随机驻地收束。
> 本文件只作索引。各分册只讲一个主题，可独立阅读；交叉引用以相对链接为准。

## 裁决口径（本卷共同遵守）

1. **相对历**：开局为 Y0，不对齐原著绝对年份；2301→2345 只存在于前史。
2. **三个剧情锚点**：朱丽叶当上警长=中期事件，当选市长=末期事件，覆灭=结算事件。
3. **覆灭是结算动作**：窗口走完或结算条件满足即进仲裁；原固定年份覆灭信号降级为结算触发器，不再是剧情节点；**覆灭后不留内容窗口**。
4. **延迟链允许溢出**：自然触发或按年份强制推进；窗口内必发的特殊事件设兜底强制拉起。
5. **司法部只附着 IT 或约章**：市长只有影响力，不构成归属；《人治》以警察服从＋市长正统性为基础。
6. **《人治》的 Mayor 公开担当时刻允许重复**，不作一次性锁死。
7. **外溢不进胜负判定**：外溢为零同样判胜，数量只影响结算分数；外溢准备工作与逃离模型本轮不做，已登 [roadmap](../roadmap.md)，相关链条节点只预留注释。
