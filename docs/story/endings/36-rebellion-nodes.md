# 《越岭》事件链 · 完整节点设计

> [返回总索引](../silo40-endings.md) · [链骨架](./13-chain-rebellion.md) · [剧情台阶](../good-endings/02-rebellion.md) · [准备度换算设计](../../research/16-preparation-outcome-design.md)
> 性质：**内容节点设计文档**。沿用 [33《无人裁决》](./33-time-nodes.md)／[30《人治》](./30-personal-rule-nodes.md) 的格式与纪律：只写设计，数值一律 `TODO(balance)`，依赖未落地机制处只留注释。
> 口径（用户裁决，16 分册卷首与 §3.2 誊录）：**门是三档立场**——市长与 IT 各处于阻挠／不阻挠／配合；任一方阻挠 → 逃离不成立（人数自然为 0）；不阻挠 → 成立；配合 → 成立且成果加成。两人不必亲身离开，不阻挠就够。**立场是带权重的随机决策**，由既有状态塑形（正统性、叛乱、W、1 号状态、保障可信度），不是玩家按钮；随机源走地堡种子；磋商持续、立场可反复重估，最后一刻妥协也算。**结算只看逃出去了多少人**；立场不直接换算人数，经准备账本与四个成果侧面体现。**Layer 1 纪律**：账本存在但仲裁不读它——囤积准备不是假的胜利进度条。
> 本册与 [ADR-0008](../../../knowledge/adr/0008-escape-gate-to-outcome-layer.md) 对齐：立场不作显式判定闸、不作玩家按钮；阻挠经容量／存活率／追踪自然结算为人数 0；准备度只决定"成得多好"。

## 0. 全线总览

```text
意愿（departure_willingness：想走的人出现且可联络）
   ▼
路线（route_survey_offer → accept → route_survey_step → route_confirmed
      → advance_party_dispatch → advance_party_report：先遣往返确认通行）
   ▼                                    ‖ 并行：准备层（§4）
开窗（escape_window_open：有组织反抗打开撤离窗口；      防护服／划拨／预案／演练／
      无路径叛乱锁死本节点）＋R-D 抉择（有序／暴乱）      照护／生产起点／接应／信道
   ▼                                    ‖ 并行：立场生产层（§3）
离开（escape_departure_launch：终局立场重估 → 出发结算）  开窗重估／保障磋商／出发终估
   ▼
出发结算（容量 D → 存活率 S → 维存 M → 追踪 T → 逃出人数）
   ▼
仲裁读 EscapedGroup 存续 → REBELLION 候选（资格接口不变）
```

顺序：意愿 → 路线 → 开窗 → 离开。并行：准备层与立场生产层全程进行；《共证》《无人裁决》建设可同时进行（结算时同池竞争）。

## 1. 资格事实（现有代码口径，先看清再动笔）

- **资格**：仲裁只读 `station.EscapedGroup.SurvivingEscapeGroup()`（人口 > 0 且 `Surviving`）。本线一切节点不得另行授予资格；出发结算是资格事实的唯一生产者。
- **P0 例外不改**：原驻地毁灭／重置／崩坏时，存续群体不被追溯判死，只作惨胜尾声（既有分支）。
- **立场不是资格**：`top_stance:mayor`／`top_stance:it` 是内部状态，仲裁永不读取；它只塑形出发结算的输入。阻挠不需要额外判定宣布失败——容量、存活率、追踪把人数自然压到 0。
- **账本不是资格**：`EscapePrep`／`SpilloverPrep` 在出发结算之外没有任何结局消费方（Layer 1 纪律）。

| 节点 | 内容 |
| --- | --- |

| `route_confirmed` | special，ONCE：勘察步骤完成后路线事实成立，`rebellion +0.04`。这是"路线是事实，不是计划"的落点 |
| `advance_party_dispatch` | `PLAYER_EVENT`，ONCE：路线确认后解锁；`schedule_event(advance_party_report, 4)`（`TODO(balance)`） |
| `advance_party_report` | crisis，纯调度（`canTrigger: false`）：apply 守卫区分完好／受损——期间发生 `lower_deck_collapse` 则受损（档位停在 surveyed、恐慌上升）；完好则 `preparationStage("confirmed")`＋`rebellion +0.04` |

**路线事实与账本的分工**（16 §2.1）：路线本身用完成键表达（不新建）；接应档位（none/surveyed/confirmed/stocked）是账本侧镜像，由先遣链写入，供出发结算读取。受损分支不设独立字段：档位停在 surveyed，结算按"未确认路线强行出发"的地板值处理（16 §4.2）。

## 3. 立场生产层（Layer 0）

立场由带权重的随机决策产生，随机源走地堡种子（引擎单一 RNG 流，同种子复现）。权重读既有状态，不被状态锁死——不存在"叛乱 ≥ X → 必须妥协"的阈值。

| 生产者 | 时机 | 说明 |
| --- | --- | --- |
| 开窗事实 | `escape_window_open` 点火 | 首次重估：叛乱胜利拆掉阻挠的三根支柱（执法合法性失效、命令源枯竭、生存算计） |
| 保障磋商 | `escape_negotiation_guarantee`（开窗后解锁） | 赦免／职能保留承诺写入保障可信度（0-1 夹取），随即重估 |
| 谈判层 | `negotiation_open_channel` 起（叛乱 ≥ 0.30 解锁） | 完整谈判机制（21 设计卷）：市长三条路（镇压／谈判／妥协）与叛乱方接受、IT 反应全部是带权重的随机决策；信道畅通期间月度通气，试探／递条款是玩家的高强度回合；妥协成立抬高保障可信度并重估立场，叛乱方可选接管或不接管市长职位。只改变"谁在阻碍谁"，不发放胜利（ADR-0013） |
| 出发终估 | `escape_departure_launch` 效果首位 | 最后一刻妥协也算；重估在结算之前施加（效果顺序即时序） |

**权重输入**（各自 `TODO(balance)`）：市长侧读个人正统性（`MayorLegitimacy`，既有）、叛乱、保障可信度、1 号命令源；IT 侧读残余力量 `W`、叛乱、警察服从（执法支柱坍塌）、保障可信度（求生算计）、1 号命令源（专线静默／覆灭 → 瓦解）。重估不保证单调：W 残余时保留玉石俱焚回摆到阻挠的概率。

**读现任不读职位**（裁决 E）：立场挂在堡聚合上，读的是那一刻的现任立场；市长更替（《人治》继承链）不迁移立场状态，继任者按自身状态重估。

## 4. 准备层（Layer 1）：账本、成本与反制

账本是事实账本，不是成功率系数：每条记录有明确生产者，禁止月度被动积累与 AP 直接兑换。可数实物获取即付成本。

| 账本字段 | 生产者 | 成本 |
| --- | --- | --- |
| 可用防护服 `suits_functional` | `escape_prep_suit_repair`（暗中换胶带，可重复）；`escape_prep_suit_warehouse`（IT 配合时开库，可得性由立场塑形） | 暴露累积（喂出发追踪）；**囤积不被没收**（审计没收已移除，20 分册修订、ADR-0014：反制只抬成本与风险，不没收囤积、不困死玩家） |
| 便携补给 `supplies_packed` | `escape_prep_transfer_supplies`（Supply 关系门控） | **划拨即扣减**：堡内补给立即减少（喂大 `supplies_shortage`）；市长非配合时暗中划拨计暴露 |
| 装备材料 `materials_packed` | `escape_prep_transfer_materials` | 同上：挤压维修与生产 |
| 预案完备度 `plan_completeness` | 六个功能位对接（`escape_plan_{mechanical,mines,supply,medical,agricultural,order}`，各挂对应部门关系门控） | 暴露小量累积。**完备度 = 功能位覆盖率**（R-2 清单，等权基线 `TODO(balance)`），UI 可显示"还缺哪个位" |
| 演练水平 `drill_level` | `escape_drill`（可重复） | 可见性成本（暴露增量） |
| 照护能力 `care_ready` | `escape_prep_care`（Medical 门控） | 暴露小量累积 |
| 生产起点 `production_start` | `escape_prep_production`（Agricultural 门控＋封存材料达标，触发器读账本） | 材料门槛 |
| 接应档位 `reception_stage` | 先遣链（surveyed/confirmed）；`escape_reception_stocking`（confirmed 后向接应点划拨补给 → stocked） | 划拨即扣减 |
| 筹备暴露 `prep_exposure` | 上述各动作的副作用 | 喂大出发追踪与堡外追踪定档（囤积不喂组织怀疑度，ADR-0014） |
| 外溢信道 `spillover_prep.channels` | 三种信道各一张接触卡（IT 专线／跨堡信号／实体交接） | 建立即记暴露成本。**投递与独立接收已落地**（`spillover.go`） |

**立场塑形准备可得性**（16 §3.2 表）：阻挠下修服走黑市（高暴露）；不阻挠下暗中准备可行；配合下库开启（暴露成本消失）、正式调拨（不计暴露）。反制只抬成本与风险，不没收囤积（审计没收已移除，20 分册修订、ADR-0014）。塑形由动作的 `canTrigger`／`apply` 读 `ctx.top_stance` 实现——立场是成因，不是按钮。

## 5. 收口点与失败路径（每条都有下落）

| 情形 | 结算落点 | 依据 |
| --- | --- | --- |
| IT 阻挠下出发 | 人数 0，无群体；尝试键仍在，副作用（暴露、损耗）已记账 | 本册 §2 W-4；16 §3.2 |
| 市长阻挠下出发 | 动员坍塌＋追缉损耗，人数趋近 0；至多散逃者规模——逃出发生时原堡已被摧毁，没赶上队伍的人必死，**无散逃者尾声**（裁决已定，16 §3.2 裁决 3） | 同上 |
| 叛乱胜利但立场未转变、窗口先关闭（1 号打击先到） | 《寂堡》（终止／轰炸事实键，既有） | 16 §3.2 残余表 |
| IT 核心玉石俱焚（回摆阻挠） | 终止／重置／路线损毁 → 《寂堡》／《遗忘》／先遣受损分支（全部既有事实键） | 同上 |
| 叛乱被镇压 | 立场继续阻挠；按社会状态走《断层》／《深闭》／《遗忘》或继续模拟（既有行为） | 同上 |
| 路线未确认强行出发 | 存活率地板 → 近乎全损；群体不成立则无资格 | 16 §4.2 |
| 补给不足 | 落地即散（M1 失败 → 群体不存续）；堡外月度补给维持已落地（Layer 2，`escape_outside.go`） | 16 §4.1 |
| 组织缺位 | 走出去的是人群，不是群体（M4 失败 → 不存续；仍为出发时即时定性，延迟定性未实装） | 16 §4.1 |
| 暴露过高 | 追踪折减＋脆弱标记；追踪四档已落地（Layer 2，`escape_outside.go`） | 16 §3.3 |
| 撤离窗口关闭且成规模离开未成立 | 回退为外溢方向：未消费的进展改道流入外溢（《共证》分支已落地，见 37 分册）。**未消费进展的自动改道尚未实装；窗口关闭事实的生产属后话，本期只登记口径**（Witness 回退规则） | Witness §回退规则 |

## 6. 与其他线的关系

- **《共证》**：撤离组织者与核心复制者重叠时争夺同一批人（13 分册 §2 既有）；出发带走的人口直接减少宿主复制链。外溢是逃跑失败后的退路，不是并行的第二套准备（16 §3.5）。
- **《无人裁决》**：成规模离开成立时，"宿主活到结算"的留驻前提消失（Witness 互斥点二）；本线出发结算写 `EscapedGroup` 后，《无人裁决》的宿主类节点按实际宿主状态锁定。
- **《断层》**：全面暴乱开窗的结构与资源损耗进入断层口径（R-D 暴乱支）。
- **同池竞争**：《共证》《越岭》《无人裁决》候选在结算时同池竞争，同分按 P3 既定序（INFORMATION 先于 REBELLION 先于 TIME）。
