# 《人治》收束段与终局呈现设计

> [返回总索引](../silo40-endings.md) · [节点设计](./30-personal-rule-nodes.md) · [字段级规格](./31-personal-rule-event-spec.md)
> 性质：设计文档＋本批已落地的内容。沿用 [25《共证》](./25-information-endgame.md)／[28《公议》](./28-rule-of-law-endgame.md) 的格式与纪律。
> 口径：终局叙事按原书口径书写，功能位、无人名；资格全由引擎读事实（警察服从＋正统性＋W 退场＋司法部不在 IT 手里）；司法部永不归市长（[ADR-0005](../../../knowledge/adr/0005-judicial-not-mayors.md)）。

## 1. 收束段：S-3 点亮之后到终局判定

警察转向（S-3）点亮不是终点，而是进入**收束段**：秩序已经系于其人，剩下的是让它活过结算。

### 1.1 还需要什么条件

| 条件 | 读什么 | 现状 |
| --- | --- | --- |
| 宿主活到结算 | 驻地未被毁灭（无 DEATH 事实）、未被重置（无 `reset_completed`） | 既有仲裁口径，直接可用 |
| 持有者在任 | 引擎 `refreshMayorHolder`：现任具名 Mayor 存活 | 死亡/更替时引擎自动重算；无继承安排的后果见 30 号 §7 |
| 资格四条件持续成立 | `personalRuleEligible`：W ≤ 30、正统性 ≥ 0.35、服从 ≥ 0.60、Regime ≠ IT | 引擎每月读事实；W 回升或 Regime 回摆 IT 即失格 |

### 1.2 玩家此时能做什么

- **维持宿主**：资源、楼层、恐慌走既有职务与情境化动作；收束段不新增按钮。
- **重复担当**：`mayor_public_stand` 允许重复（裁决）——每次担当垫高正统性、压低叛乱与恐慌，抵御秩序回摆。人治不是一锤定音，是一连串担当时刻。
- **控制偏离**：不把叛乱推过 0.8（喂大侦察与整肃链）；清洗链是持有者与秩序的威胁。
- **继承抉择**：H-1 在首次担当后解锁——纯粹人治收束，或埋程序种子改道《公议》。

### 1.3 错失窗口会怎样

| 错失形态 | 结果 |
| --- | --- |
| 结算前宿主被毁／被重置 | 按《遗忘》《寂堡》等硬失败结算；P0 护栏先于历史加权 |
| W 回升、IT 重新接管 | 引擎事实：Regime 回摆 IT，资格失效；滑向《深闭》（既有仲裁口径） |
| 正统性跌回 0.35 下／服从跌回 0.60 下 | 资格失效；按实际状态滑向《深闭》或（争夺中）继续模拟 |
| 约章同时锁定 | 两收束同池；同分按既定序让《公议》（既有 P3 顺序） |

## 2. 终局叙事：落回现有判定输出

### 2.1 落点（不新造机制）

与《共证》《公议》同一链路（25 号文档 §2.2 已接通）：仲裁选中 `PERSONAL_RULE` 后把 `decision.Reason` 设为叙事文本＋秩序事实结算行（§3）；引擎写入 `VictoryStatus.Description`；前端无需改动。

### 2.2 《人治》终局文本（原书口径）

> 驻地秩序系于一位具备个人正统性的现任者。一次危机由他的个人判断收束：那道无人能解释来源的旧命令摆在桌上，他没有向居民解释全部，只以本地责任公开拒绝执行；法警没有去执行它——司法部没有站在 IT 一边，哪怕它也没有站到他一边。当夜驻地安静，居民安睡在他们并不完全理解的秩序里。这个秩序会随一个人老去，而居民此刻不需要知道更多：被保护的睡眠，与一个知道代价的守夜人。《人治》成立。

文本不出现任何人名；Mayor 拒绝的是"不合法的本地命令"，不是"来自 Silo 1 的命令"（设定自检：他自始至终不知道其他地堡存在）。诚实的限度写进叙事本身：秩序系于一人的寿命与判断，换来的是时间与活人，不是一个答案。

## 3. 秩序事实结算行

对应《公议》的证据底座行：《人治》的结算信息是**秩序立在什么事实上**。

- 仲裁在叙事后追加：`结算时：警察服从 x.xx，市长正统性 x.xx，幕后威势 W=xx.x，司法部<三态译名>——它永不归属市长，其立场也不是成立条件。`（三态译名：SWING=处于争夺态，PACT=附着约章；IT 态在结算时不可能出现——那是失格条件。）
- 约章并存时追加：`公开约章与人治并存：两种秩序同时成立，本次加权倾向人治一侧；同分时按既定序让《公议》。`
- 该行只报事实，不作胜负：资格只读引擎四条件（既有）。

## 4. 留存与再玩

### 4.1 结局之后玩家看到什么

1. **终局叙事**（§2.2）＋秩序事实结算行。
2. **决策面板**：候选分数、资格池与排除原因——与《公议》同池竞争时，两者的分差直接可见。
3. **链的痕迹**：本局点亮的节点与完成键（树呈现待 UI 批次）。

### 4.2 缺什么信息会让人想再开一局

- **继承的洞**：秩序与此人同寿——下一任是谁，本局不演。埋了程序种子的局会在《公议》线看到种子发芽的样子。
- **担当的另一种时机**：提前对抗（被折断的正统性）与等合法舞台是两条没同时走过的路。
- **中间地带**：18 < W ≤ 30 的驻地只有《人治》可成立；W 再低，约章线就开了另一扇门。
- **另一座驻地**：不同种子的派系凝聚力决定正统性的派生底座，担当的拉力因此不同。

### 4.3 明确不做

不做成就解锁项、不做跨局成长、不做结局图鉴收集——与《共证》《公议》同口径。
