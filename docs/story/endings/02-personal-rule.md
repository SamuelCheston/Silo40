# `PERSONAL_RULE`《人治》：制度不可得时，把驻地交给一个可信的人

> [返回总索引](../silo40-endings.md) · [通用前提与共同开局](../good-endings/00-common.md) · [《公议》](./01-rule-of-law.md) · [十线交叉](./08-cross-lines.md)

## 1. 路线命题：为什么选它是有理据的

【项目外推】《人治》回答的问题是：当约章缺乏社会支撑——公开证据单薄、Judicial 无人承接程序、派系碎裂——而替代方案是 IT 继续隐蔽统治或驻地滑向内耗时，**一个真有个人正统性的 Mayor 是唯一可用的收束**。

居民得到的是一个可接受的统治者，不是一个充分知情的社会。玩家选它的理据是真实的：

- 它不流血，保住驻地，用最小可用工具约束了暗权；
- 它不要求居民先拥有他们还没有的认知——正统性来自履历与担当，不来自真相；
- 在制度与认知都不成熟的驻地，这是**伤害最小、当下可兑现**的秩序。

它诚实地只是中性：the Witness 的完成判据没有满足——终止链仍在，真相未公开，秩序系于一人的寿命与判断。选《人治》的玩家接受这一点：他换来的是时间与活人，不是一个答案。

## 2. 剧情台阶

### P-1　起点处境：唯一可见的替代权力

共同开局之后，玩家评估制度路线：公开证据不足以支撑约章，或 Judicial 中没有能承接程序的人；同时 `W` 仍高，IT 的隐蔽调度照常。唯一可见的替代权力是 Mayor 的个人正统性。

但正统性不是知识：Mayor 不知道 IT 的暗权网络，更不知道 Silo 1。他能做对的事，却不知道自己对抗的是什么。

### P-2　转折一：分清正统性与职位

玩家调查的不是权力黑箱，而是**居民实际信任谁**：Mayor 过去危机中的记录、他的命令在职位之外是否被执行、他是否为驻地承担过个人代价。正统性是现任具名人物的个人属性，不能用地堡整体合法性替代。

**玩家抉择 P-A：把 Mayor 当障碍绕过，还是当部分盟友。**

- 绕过：他不知道真相，所以不可用；玩家转入纯秘密路线。代价是驻地永远没有一个能公开承接秩序的本地人。
- 当部分盟友：他不需要知道全部真相也能做对的事；玩家用本地层证据与关系支持他，同时对他保留跨堡层。

预期走向采用后者。保留不是欺骗：Mayor 有权知道他职责内的事实，没有义务替玩家背 Silo 1 的包袱。

### P-3　转折二：威势仍须先降

【机制对接】高正统性不能单独翻转 Judicial（[12 结局体系](../../research/12-ending-system-design.md) §8）。Judicial 要能迁移到 Mayor，IT 幕后威势 `W` 必须先低到允许迁移。

玩家因此仍须制造执行失败与 IT 直接调度的证据——但材料的去向是 Mayor 圈层，不是舆论，也不是约章力量。正式权力借此接管暗权留下的职能空缺。

**玩家抉择 P-B：把证据交给 Mayor，还是留作对双方的筹码。**

- 交给 Mayor：他可能善用，也可能压下去；且他从这一刻起成为 IT 的处置目标，玩家要替他准备承受。
- 留作筹码：玩家安全，但秩序建立在玩家个人操纵之上——这本身是一种更脆弱的人治，且把玩家变成驻地事实上的影子权威，违背 the Witness"不以任务之名重建旧权力"的判据。

预期走向采用前者。

### P-4　关键转折：Mayor 的公开担当时刻

必须有一幕：Mayor 以个人权威**公开**拒绝或改写一道隐蔽命令。他不需要知道命令的真正来源，只需要知道那不是合法的本地命令。玩家的作用是使这一幕可能且可见：证人在场、部门能确认、Judicial 能记录。

**玩家抉择 P-C：推 Mayor 提前对抗，还是等一个合法舞台。**

- 提前对抗：快，但 Mayor 可能在准备不足时被 IT 折断，正统性随之转移给恐惧。
- 等危机提供合法舞台：Mayor 的担当有真实场合，但危机本身可能先压垮驻地；等待期间玩家必须维持驻地的维存。

预期走向采用后者，且玩家须为危机的到来做维存准备，不能只等戏。

### P-5　玩家决断时刻：要不要补继承的洞

人治的已知弱点是现任者更替。玩家可以帮助建立最低限度的继承安排——但那已经是《公议》的起点。

**玩家抉择 P-D：接受纯粹人治，还是在人治里埋程序种子。**

- 接受纯粹人治：秩序与此人同寿；任务以局部成就收束，驻地得到它现在能承受的最好的统治者。
- 埋程序种子：结局可能漂移为《公议》，《人治》不再成立；玩家等于用这一局替下一局铺路。

两个方向都正当。这是本线必须由玩家决断的时刻，因为它决定本局收敛到哪一个结局。

## 3. 终局那一刻

一次危机由 Mayor 的个人判断收束。那道无人能解释来源的旧命令摆在桌上；Mayor 没有向居民解释全部，只以本地责任公开拒绝执行。Judicial 执行的是 Mayor 的话，不是 IT 的耳语。当夜驻地安静，居民安睡在他们并不完全理解的秩序里。

玩家知道两件事：这个秩序会随一个人老去；而居民此刻不需要知道更多。这就是《人治》的终局画面——**被保护的睡眠，与一个知道代价的守夜人**。

## 4. 资格对齐与失格边界

| 局面 | 判定 |
| --- | --- |
| 低 `W`＋Mayor 个人正统性＋Judicial 的 Mayor 附着，三者齐备 | 《人治》成立 |
| `W` 回升、IT 重新接管隐蔽调度 | 秩序回摆，按实际状态滑向《深闭》 |
| Mayor 死亡或更替且无继承安排 | 视后续状态进入《深闭》（旧秩序回填）或《断层》（各方争夺空缺） |
| Mayor 成为《越岭》的公开领头并随队离开 | 《人治》失去持有者，不再成立 |
| 约章锁定同时成立 | Judicial 附着互斥，以实际附着为准；极端情形两者都合格时，同分顺序 `RULE_OF_LAW` 先于 `PERSONAL_RULE` |

## 5. 机制接口

- `MayorOffice.HolderResidentID / Legitimacy`、Police 对 Mayor 的服从、Judicial 的 Mayor 附着、幕后威势 `W`。
- Mayor 现任者以具名人物身份参与贡献；其职位与正统性用于资格与解释，不新增"Mayor 阵营"主体。
- 玩家行动沿用既有门控：Gather／Share Info、Build Connection、STATION_INTEL；本线不新增行动、不新增 stage。

## 6. 设定自检

《人治》是纯本地收束，与"地堡之间互不往来"无冲突。关键纪律：Mayor 自始至终不需要知道其他地堡存在——他拒绝的是"不合法的本地命令"，不是"来自 Silo 1 的命令"。玩家对他的保留是任务边界，不是剧情漏洞。

## 7. 本线需要原创的部分

Mayor 的正式权力与个人威望有原著底座；《人治》的剧情台阶——正统性调查、制度不可得的判断、公开担当时刻、继承洞口的抉择，以及"被保护的睡眠"的终局画面——均为本项目原创。
