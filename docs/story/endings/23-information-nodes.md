                     ▼                        │

顺序：感染 → 复制 → 活链 → 公共事实。并行：隐匿簇全程并行；再流通自复制簇起并行。收敛点三处，见 §7。

## 1. 感染簇：真相第一次落地

感染不是"玩家知道真相"——特工醒来就记得任务。感染是**真相第一次以可核验的形态落到本地**：玩家取得本地材料，第一位接收者独立完成核验。

### I-1　真相材料获取

| 项 | 内容 |
| --- | --- |
| 触发条件 | 阶段 `arrival` 之后；任一基础职务行动产生观察（`observation:first_local` 迁移口径） |
| 地点与来源 | 按部门取材料，每处一种来源类型：**IT 档案**（维护调度记录、删除队列）、**Mechanical 维修日志**（换胶带记录、泵房工单）、**Supply 台账**（配额与请领单）、**Medical 记录**（镇静剂库存、巡诊记录）、**Judicial 案卷**（执法调度与补签）。来源类型是判据一"两类来源互证"的计量单位 |
| 前置 | 部门准入（职务或关系）；检测类别按信念层机制结算：矿工结构豁免（UNSAMPLED，不采样、无常规怀疑、仍计 AP），其余为 SAMPLED 类 |
| 消耗 | AP；检测类别的暴露风险（SAMPLED 类按因素公式） |
| 产出完成键 | 观察吸收按信念层机制结算（p_get 判定、B 递减更新、pi 贝叶斯移动，第三次趋近确定但永不为 1）；无独立完成键，计入碎片与信念层 |
| 玩家反馈 | 观察条目入档；材料标注来源类型与缺口（"这份能证明什么、还缺什么"） |
| 树上成就 | 不直接点亮节点——感染成就要求接收者独立核验（I-3） |

### I-2　首位接收者接触

| 项 | 内容 |
| --- | --- |
| 触发条件 | 玩家对某一具体对象执行 Share Info；信念地板 B ≥ 0.30（既有机制） |
| 前置 | `first_signal` 阶段；与接收者的关系达到可交谈程度 |
| 消耗 | AP；关系占用 |
| 产出完成键 | `player_action:action_share_info`（首次） |
| 玩家反馈 | **第一次接触真相的反馈不是相信，而是追问来源**：接收者问"这从哪里来、哪部分能查"。传播强度按 `B_player·transmit·receptivity` 被接收部门吸收；首次分享为独立吸收 |
| 树上成就 | 感染的前置（尚不点亮） |

### I-3　首位接收者独立核验（感染成就）

| 项 | 内容 |
| --- | --- |
| 触发条件 | 首次分享后，接收者所在部门信念层越过核验阈值 `TODO(校准)`，或接收者发起一次可观察的回查动作（调档、对账、实地查看） |
| 消耗 | 无直接消耗（接收者自发）；玩家可选择陪同（AP，降低失败率） |
| 产出完成键 | `special:first_receiver_verifies` |
| 玩家反馈 | 接收者指出一处玩家材料里的错误，或补上一条玩家没有的旁证——**只有独立核验过的人才会这样做** |
| 树上成就 | **感染**（一成就点两节点：同时推进主干 T2） |

## 2. 复制簇：真相在本地扩散

### R-1　二代传递

| 项 | 内容 |
| --- | --- |
| 触发条件 | 感染成就成立后，再次执行 Share Info（玩家驱动），或接收者自发转述 |
| 消耗 | 玩家驱动：AP；自发转述：无 AP，但**转述强度只有 0.25**（既有机制）——电话游戏会衰减，二代传递原则上应由玩家或强信念者重新分享，不能靠口口相传 |
| 产出完成键 | `special:replication_progress`（REPEATABLE，计数按质变档） |
| 玩家反馈 | 新接收部门/人物入档；显示该份事实的传播路径（谁从谁那里听到） |
| 树上成就 | **复制**（多成就节点：传递成功＋隐匿保持同时成立，见 §5） |

**扩散路径与阻碍**：

- 路径：沿部门关系网跳传。每一跳是一次分享，目标是**尚未持有该事实的部门**。
- 阻碍一·淡忘：**部门信念层按恒定淡忘系数衰减**（已实现，17 号经济文档 §3）；衰减使信念回落，传播路径上的远端节点先淡。抵衰减的唯一手段是再流通（§3 的 L-3）。
- 阻碍二·转述衰减：0.25 强度意味着三代以上的口口相传几乎不产生新核验者。
- 阻碍三·监视：信念进入 IT 忠诚度高的部门会抬升归因加权信念聚合——E 是高水位，抬上去就下不来（§5）。
- 阻碍四·处置：清洗链与整肃链可以直接删除持有者（§5 时点表）。

### R-2　跨部门跳传

| 项 | 内容 |
| --- | --- |
| 触发条件 | 对未持有该事实的部门执行分享并越过信念地板 |
| 消耗 | AP；跨部门关系（无关系部门需先 Build Network） |
| 产出完成键 | 公共事实登记的**部门覆盖** +1（登记按事实去重，重复公开只抬字段） |
| 玩家反馈 | 覆盖清单更新："这份事实现在存在于哪些部门" |
| 树上成就 | 复制的计数面（质变档由复制成就统一读取） |

## 3. 活链簇：链不再需要你

### L-1　独立接收者

**谁算独立接收者**（定义，非数值）：能独立说明证据来自哪里、哪些部分可核验、哪些仍有缺口；能在没有玩家持续授意的情况下保存、复述并继续核对；不承认 Silo 40 权威、不加入任何秘密组织，仍认为事实值得保存。三条全备才算。

**需要几个**：至少两名、且来源类型不同（对应判据一"两类来源互相印证"）。具体数量阈值 `TODO(校准)`。

**要不要独立核验**：要。只会复述结论、无法接触证据的听众不算独立接收者；可核验性比声量重要。

| 项 | 内容 |
| --- | --- |
| 触发条件 | 独立接收者计数达标（定义如上，数量 `TODO(校准)`） |
| 消耗 | 无直接消耗（由复制簇累积） |
| 产出完成键 | `special:independent_receivers_met` |
| 玩家反馈 | 接收者名录（功能位与来源类型，不显示为"进度条"，显示为人与部门） |
| 树上成就 | 活链的组成要件 |

### L-2　活链确认（终局成就之一）

| 项 | 内容 |
| --- | --- |
| 触发条件 | 独立接收者达标 ＋ 复制计数达质变档 ＋ 隐匿保持（§5 C-1 未破） |
| 消耗 | 无 |
| 产出完成键 | `special:living_chain_confirmed` |
| 玩家反馈 | 一段可观察的自运转迹象：接收者之间自行对账、自行纠错、自行安排下一轮核对，没有来找玩家 |
| 树上成就 | **活链**（感染＋复制＋隐匿三成就齐备） |

### L-3　再流通：维持公共事实（并行）

情报会淡忘：已分享的碎片随时间衰减，玩家推动流通才能抵住。

| 项 | 内容 |
| --- | --- |
| 触发条件 | 常驻条件节点：公共事实覆盖 ≥ 淡忘地板 `TODO(校准)`。覆盖跌破地板时节点熄灭，活链确认随之失效，直到重新流通拉回 |
| 手段 | 再分享（对淡忘边缘的部门重新 Share Info）、促使接收者再核验（提供新旁证）、公开场合再引用（登记覆盖抬字段） |
| 消耗 | AP；每次再流通有暴露增量（§5） |
| 产出完成键 | 无新键；维持的是登记覆盖与信念层状态 |
| 玩家反馈 | 淡忘预警：哪些部门的事实正在变淡（信念层回落可见）；再流通后回稳 |
| 树上成就 | 活链的持续要件（活链不是一次点亮永久有效，维持失败会熄灭） |

## 5. 隐匿簇（并行全程）

总原则：**E 是归因加权信念聚合的高水位——抬上去就下不来**。隐匿不是降低暴露，而是不让暴露抬头：控制信念传播的速度、去向与部门权重。

### C-1　暴露管理（常驻条件）

| 项 | 内容 |
| --- | --- |
| 条件 | E 低于注意力阈值 `TODO(校准)`。E 越过阈值不立即失败，但接入 1 号反应链（下） |
| 手段 | 优先向低权重与结构豁免部门传播（矿工 UNSAMPLED）；行动层保密、价值观层公开（compartmentalization）；控制单月分享次数 |
| 玩家反馈 | 压力指示：信念聚合的归因构成（哪个部门贡献了多少 E） |
| 树上成就 | 复制与活链的并行要件"隐匿保持" |

### C-2　反情报动作

| 项 | 内容 |
| --- | --- |
| 触发条件 | `archive_awakened` 阶段＋宣传门控（既有） |
| 手段 | STATION_DECEIVE／SILO1_DECEIVE：向指定链路投放伪造材料；代价是 Exposure 与反间谍后果 |
| 消耗 | AP；宣传门控；暴露增量 |
| 产出完成键 | 对应行动完成键（既有） |
| 玩家反馈 | 投放回执＋延迟可见的对方反应；**高水位不可逆**：反情报能误导方向，不能抹掉已经抬高的 E |
| 树上成就 | 无独立成就；服务 C-1 |

### C-3　与 1 号三条链的时点协调

既有反应链（相对历）：**通牒**（`silo1_ultimatum`，Y4M1）→ **侦察**（`strike_reconnaissance`，Y6M1 起、rebellion≥0.8 时校位）→ **投放**（`bombing_terminal`，侦察后 +3 月）；另有终止渠道测试（`termination_channel_test`，Y5 起）与本地整肃链（`silo1_purge_omen`，Y4M9 起、rebellion≥0.8 → 执行 +3，被曝光则停滞）。

隐匿簇的时点纪律：

| 时段 | 纪律 |
| --- | --- |
| Y0–Y4（通牒前） | 感染与复制的主窗口；高暴露动作（跨部门公开引用、欺骗投放）尽量在此完成 |
| Y4–Y6（通牒后、侦察前） | 收敛暴露：停止新增高权重部门传播；再流通只走淡忘边缘的低权重部门 |
| rebellion ≥ 0.8 | 侦察与整肃被喂大：《共证》线若不同时需要叛乱侧成果，应把叛乱压在阈值下——这是与《越岭》线的真实资源冲突 |
| 侦察→投放（+3 月） | 最后窗口：活链未确认则转入宿主存续抉择（I-G）；已确认则链不依赖宿主，按惨胜口径等待结算 |

## 6. 再传递／外溢簇（预留评分，本轮不实装）

**明确不参与胜负**：外溢为零同样判胜；外溢数量只影响结算分（仲裁按出站信号到达的不同地堡数计 Information 分）。

| 节点 | 内容 | 状态 |
| --- | --- | --- |
| 信道建立 | 三种受限信道各一条接触卡：IT 专线类（可靠度最高、暴露成本最高）、跨堡信号类（受邻接约束）、实体交接类（与逃跑耦合：逃出者携带材料首先归《越岭》幸存事实，计入外溢须有显式再传递交接，不自动双算） | 预留（16 分册 §2.3） |
| 包裹组装 | 五种能力完备度各一完成键：事实与来源／独立核验／反制方法／隐匿与交接／再传递 | 预留（16 分册 §2.3） |
| 投递与独立接收 | 逐信道确定性结算，成功追加出站信号日志；接收结算属外溢模型主体 | 预留（roadmap） |

## 7. 顺序、并行与互斥收口

- **顺序**：感染（I-1→I-2→I-3）→ 复制（R-1/R-2 循环）→ 活链（L-1→L-2）→ 公共事实（P-1）。
- **并行**：隐匿簇（C-1/C-2）全程并行；再流通（L-3）自复制簇起并行。
- **收口点一 · 公开化对隐匿**（线内互斥抉择）：公开化提速（大规模引用、宣传）可加速公共事实，但永久抬高 E；隐匿优先则慢。这是速率与安全的交换，一旦公开化造成的 E 越线不可回退。
- **收口点二 · 约章喂证**（转《公议》链）：把责任链材料喂给制度内渠道，同一份材料从此主要作为约章证据存在；不排斥活链，但玩家的剩余杠杆转向制度线。
- **收口点三 · 核心送走**（转《越岭》链）：核心复制者随撤离离开，活链的本地承接被掏空——已点亮的活链成就保留（事实发生过），但 L-3 维持与后续公共事实不再可达。
- **终局抉择 I-G**：扩大本地公开传播／提前送走核心节点／保持宿主隐匿到结算。预期走向第三种。
