# 《无人裁决》收束段与终局呈现设计

> [返回总索引](../silo40-endings.md) · [节点设计](./33-time-nodes.md) · [字段级规格](./34-time-event-spec.md)
> 性质：设计文档＋本批已落地的内容。沿用 [25《共证》](./25-information-endgame.md)／[28《公议》](./28-rule-of-law-endgame.md)／[32《人治》](./32-personal-rule-endgame.md) 的格式与纪律。
> 口径：覆灭是结算事件，覆灭后不留内容环节；终局画面是仲裁呈现给玩家的结算演出，不是覆灭之后还可玩的环节（机制底座 §3 时序纪律）。

## 1. 收束段：抉择卡点亮之后到覆灭结算

抉择时刻（T-1）点亮到覆灭结算之间是最后的收束段：快照尚未定格，一切都还来得及，也一切都来不及了。

### 1.1 还需要什么条件

| 条件 | 读什么 | 现状 |
| --- | --- | --- |
| 宿主活到结算 | 无 DEATH 事实、无 `reset_completed`、无 `fracture_confirmed` | 既有 P0 口径；致死来路见 33 号 §2 |
| 快照开放合格 | 覆灭落地瞬间的 cohort 人口加权思潮：亲外 > 0 且 ≥ 忠诚 | 引擎截取（`takePreFallIdeologySnapshot`），内容不重算 |
| 叛乱不越过 0.8 | 致死来路（终止自检、投送侦察）的喂大阈值 | 既有反应链口径 |

### 1.2 玩家此时能做什么

- **维持宿主**：资源、楼层、恐慌走既有职务与情境化动作；收束段不新增按钮。
- **守住开放**：恐慌会把 cohort 思潮漂向忠诚（既有漂移口径）——收束段的恐慌管理就是快照管理。
- **反制**：终止渠道反制按分渠道结算（干扰远程终止不免疫物理手段，见《寂堡》链）。
- **不做**：不在收束段发动高暴露动作；不借镇压点火。

### 1.3 错失窗口会怎样

| 错失形态 | 结果 |
| --- | --- |
| 结算前宿主被毁 | 按《遗忘》《寂堡》《断层》等 P0 口径结算；覆灭事实不追授 |
| 抉择卡未选 | 时刻卡有兜底强制拉起；玩家不选则快照按当时思潮定格——不选择也是一种答案（33 号 §3） |
| 熬到覆灭但快照纯种 | 《深闭》死后复制：覆灭使 `exclusionistEligible` 成立，按加权输出"秩序内化了它的主人"画面 |

## 2. 终局叙事：落回现有判定输出

### 2.1 落点（不新造机制）

与《共证》《公议》《人治》同一链路：仲裁选中 `TIME` 后把 `decision.Reason` 设为叙事文本＋覆灭后结算行（§3）；引擎写入 `VictoryStatus.Description`；前端无需改动。

### 2.2 《无人裁决》终局文本（原书口径）

> 按 Protocol 应当到来的复核没有到来，控制通道不再给出下一项处置。桌上的旧命令第一次没有后续签批，谁也不能再用下一道外部指令推迟选择。在覆灭之前就已存在的公开质询场所里，有人把那份旧命令放到桌上，问它今天是否仍然适用；没有人能从控制网另一端得到答案。争论没有立即停止，外面也没有因此变得安全——但讨论继续下去，不需要谁替全堡批准。你坐在其中，不是新裁决者。《无人裁决》成立：不是世界终于给出正确答案，而是唯一垄断裁决权的来源消失时，这里已经具备不被另一套封闭答案立即吞没的公共条件。

文本不出现任何人名；没有全堡围观爆炸的全知镜头——驻地最先感知到的是"应当到来的复核没有到来"（剧情台阶 03 §3 口径）。

## 3. 覆灭之后还剩什么（结算行）

和解感不来自胜利，来自具体的剩余物。仲裁在叙事末尾追加：

1. **快照事实**（硬条件可见）：`覆灭前夕快照：亲外 x.xx 对忠诚 x.xx（主导轴：亲外/忠诚），快照人口 N——硬条件在结算瞬间定格。`
2. **外面**：`本局共有 N 条信号送出驻地，到达 M 座他堡——残余应答不是建制恢复，也不许诺。`（N=0 时：`外面：本局没有信号送出驻地——外部保持沉默。`）复用《共证》的出站信号账本（`spilloverSignalCount`／`spilloverSiloCount`），但措辞不是外溢评分，是残余应答母题。
3. **驻地**：`驻地内仍有居民 N 人，从今天起，没有人再替他们签批。`

## 4. 留存与再玩

### 4.1 结局之后玩家看到什么

1. **终局叙事**（§2.2）＋三段结算行。
2. **决策面板**：候选分数、资格池与排除原因——快照失格时 TIME 的排除原因与《深闭》的入选同屏可见。
3. **链的痕迹**：本局点亮的节点与完成键（树呈现待 UI 批次）。

### 4.2 缺什么信息会让人想再开一局

- **残余应答的下落**：送出去的信号是否被接收、被谁接收，本局不揭晓（应答不等于建制恢复，也不许诺）。
- **另一种熬法**：这一局为保宿主放弃了外溢与撤离；另一局可能用同样的整局时长走《共证》或《越岭》——同一个终局时钟，三种花法。
- **快照的另一种形状**：忠诚动员那一支的结局画面（死后复制）只能重开一局去看。

### 4.3 明确不做

不做成就解锁项、不做跨局成长、不做结局图鉴收集——与其他线同口径。

## 5. 平衡台账（TODO(balance)）

**现状实测**（种子 3401–3409、Supply/Mines/Agricultural/Mechanical 职业）：真跑完当前固定覆灭锚点前的整局，全部以封闭快照结算（忠诚 ≈0.87–0.94，亲外 ≈0.25–0.37，人口损耗 ≈60–70%）。结构化原因：

| 项 | 现状 | 待校准方向 |
| --- | --- | --- |
| 恐慌→忠诚漂移 | `panic × 0.10 × deltaYears` 每月，恐慌难清零 | 漂移系数与恐慌衰减的相对强度 |
| 开放杠杆 | `MINES_TUNNEL_NETWORK` +0.03/次（AP 20）、`AGRICULTURAL_FIELD_GOSSIP` +0.03/部门（AP 10） | 杠杆强度与 AP 经济 |
| NPC 经济 | 能源/补给在多数种子下于 12–36 月内见底，单特工职务动作补不回来 | 资源消耗率与部门自产 |

接线已由测试锁定（时刻卡兜底必到、结算必消费快照、资格分支正确）；让开放快照在真跑中可达属数值批次，参照 17 号经济文档的处理方式。
