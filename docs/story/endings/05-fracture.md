# `FRACTURE`《断层》：反抗毁掉了它声称要拯救的东西

> [返回总索引](../silo40-endings.md) · [通用前提与共同开局](../good-endings/00-common.md) · [《遗忘》](./04-reset.md) · [《除名》](./06-agent-compromised.md) · [十线交叉](./08-cross-lines.md)

## 1. 路线命题：高叛乱与社会崩溃是两件事

【原著母题】原著存在叛乱最终导致地堡社会崩毁的案例。

【项目外推】《断层》是反抗或内耗使社会**失去维存能力**：不是所有人死亡（那是《寂堡》），而是驻地再也无法维持自己——基础设施不可恢复、部门互相为敌、资源被毁、组织碎裂，且不存在《越岭》所需的独立逃出群体。

本线的叙事纪律是结局体系反复强调的那条：**高叛乱本身不等于《断层》**。只有实际组织能力、基本资源或关键基础设施已经不可恢复地崩坏时才成立。剧情因此必须把"愤怒"与"维存崩溃"写成两个可以分离的过程——前者可以通向《越岭》，后者才是这里。

## 2. 四条滑入路径（都必须能真的发生）

1. **无组织的叛乱。** 玩家在没有路线与组织的情况下点火——起义毁掉的比它解放的多。（对应《越岭》抉择 R-A 的错误方向。）
2. **部门战争。** 玩家为取证与借力挑动派系互斗；冲突升级到玩家再也无法仲裁的程度。
3. **资源赌博。** 玩家为战术目标损耗维生基础——制造危机、过度透支交换；动荡叠加后驻地无法恢复。
4. **权力真空。** IT 暗权崩溃，但没有东西接住它；各方争夺战利品，而战利品里包括维生资源。

## 3. 剧情台阶

### C-1　起点处境：期待跑得比组织快

真实的怨气存在；玩家的早期成功让期待跑得比组织快。危险的第一个征兆不是暴力，而是**"人人开始自行其是"**——每个部门、每个派系都觉得自己有理由单独行动。

### C-2　第一道转折：第一次无人控制的破坏

一场楼层斗殴、一次被破坏的泵房、一个哄抢中的仓库。玩家的指纹可能在上面——宣传、煽动、派系操纵都会留下。

**玩家抉择 C-A：借乱局，还是止损。**

- 借乱局：IT 控制松动，证据窗口打开；但每一分破坏都会记在维存账上，且不会自动偿还。
- 止损：花威望与关系压住破坏。损失动能，换回看不见的好处——驻地还活着。

### C-3　升级阶梯：从"针对谁"到"互相针对"

冲突换质：部门停止共享，轮班断裂，关键岗位弃守。玩家必须看懂一件事——**驻地的维存是一张协作网，每撕掉一条网眼，都不会因为任何一方"胜利"而自动复原**。

### C-4　玩家决断时刻：维存基础还能修复时

**玩家抉择 C-B：牺牲任务动能换修复，还是继续加压。**

- 换修复：用剩余杠杆恢复轮班、调解部门。结局可能漂移为《人治》或《深闭》——秩序在旧旗下恢复，玩家等于亲手把驻地交还给他想改变的东西。
- 继续加压：赌旧秩序先于维存基础崩溃。赌对了且逃离路径打开，可能转入《越岭》；赌错，就是《断层》。

这是本线必须由玩家决断的时刻：它逼玩家在"任务的胜利"与"驻地的存活"之间报出真实优先级。

### C-5　不可逆点

关键基础设施被毁且不可修复，或一个部门永久脱离协作，或农业与医疗基础跌破维持人口的最低线。此后即使停战，维存也无法恢复——**驻地技术上还活着，已经失去了明天**。

## 4. 能不能中途爬出来

能，直到 C-5。但爬出来的代价是任务动能——这是《断层》最诚实的交易：救驻地的玩家可能必须接受驻地在旧旗下恢复。剧情不得写成玩家一段演说让众人和解；修复需要真实的资源、真实的调解、真实的轮班表。

## 5. 终局那一刻

不是战场，是战后。冰冷的楼层，修不好的泵，太少又太分裂的人口凑不齐下一班轮值。部门之间最后一次协作，是谈判谁吃饭。有人来问玩家接下来怎么办——那个曾经许诺改变的人没有答案。

最后一幕：驻地的灯一层一层熄灭。不是因为攻击，是因为没有人再在开关旁边。

## 6. 资格对齐与失格边界

| 局面 | 判定 |
| --- | --- |
| 高叛乱但社会仍能恢复 | 不提前终局；继续模拟 |
| 高叛乱＋维存不可逆崩溃＋无逃出群体 | 《断层》，P0.3 |
| 已无任何幸存群体 | 改判优先级更高的《寂堡》（P0.1 先于 P0.3） |
| 独立逃出群体已成立 | 断裂的原驻地只是《越岭》的背景 |
| 玩家宣传与操纵推高了崩溃 | 《断层》由真实社会状态成立，不是"负面宣传分"自动产生；但玩家的责任要写进剧情 |

## 7. 与其他九线的关系（详见[十线交叉](./08-cross-lines.md)）

《断层》是《越岭》没有逃离事实时的影子，是《共证》公开曝光引发无组织恐慌时的下坡，也是《寂堡》的前厅。它与其他失败结局的分界很硬：《遗忘》里社会被外力格式化，《断层》里社会被自己的手撕碎。

## 8. 机制接口

- `Rebellion / Cohesion / DeptTension`、资源、人口、楼层稳定度、派系低凝聚力与互相冲突的需求。
- 作为社会维存失败的硬护栏，不能被《共证》或《无人裁决》的高分覆盖。
- 本线不新增行动、不新增 stage。

## 9. 设定自检

纯内部过程，无跨堡要素，与"地堡之间互不往来"无冲突。若断层的诱因涉及玩家公开跨堡信息，恐慌按既有纪律书写：恐慌推向闭守与排外，不产生开放（[13 思潮轴设计](../../research/13-ideology-axes-design.md) §0.2），方向一致。

## 10. 本线需要原创的部分

叛乱致崩的母题来自原著；《断层》的四条滑入路径、"期待跑得比组织快"的起点、维存与动能的交易决断、"灯一层层熄灭"的终局画面，均为本项目原创。
