# 十线设定自检：与「地堡之间互不往来」的逐条核对

> [返回总索引](../silo40-endings.md) · [通用前提与共同开局](../good-endings/00-common.md) · [前史红线](../silo40-backstory/08-redlines.md)

## 1. 被核对的设定

核心设定（[通用前提](../good-endings/00-common.md) §2）：**普通居民不知道其他地堡是否存在**，没有 Silo 1 与跨堡控制网的公共概念。跨堡知识只能来自玩家、受限 IT 层级、Silo 1，或当局实际产生的 Observation 与权威事件。

认知基线按最新修订口径：各堡专线的另一头，在 IT 主任看来是**一套系统、一个声音**，不是"背后有活人在指挥的 1 号"；后者只有极少数主任终其一生才参悟出来。

本文对十条结局线逐条核对，冲突改写为规则，无法裁决的登记留白。

## 2. 逐线核对

| 结局 | 线内的跨堡要素 | 核对结论 |
| --- | --- | --- |
| 《共证》 | 外溢必须经受限渠道；外部接收方独立复制 | 好结局分册已自检：普通居民不能自由呼叫邻堡，Silo 18 不作公共电台。无冲突 |
| 《越岭》 | 接应点与外部事实 | 好结局分册已自检：路线与接应必须由当局事实支持，不写成自由接触他堡。无冲突 |
| 《无人裁决》 | Silo 1 覆灭的权威事实 | 覆灭只能经权威世界事实抵达，居民感知为"上面沉默了"，不是"1 号死了"。无冲突 |
| 《公议》 | 命令链追查可能触及专线 | 无冲突，但有边界，见 §3 |
| 《人治》 | 无 | 纯本地收束；Mayor 拒绝的是"不合法的本地命令"，从不需要知道专线那头是什么。无冲突 |
| 《深闭》 | 死后复制变体中"上面沉默了" | 覆灭事实只在受限层级流通，不得写成居民公开知晓。无冲突 |
| 《遗忘》 | 重置指令经专线下达 | 居民体验为本地灾变（投药、清洗、"事故"），从不知道来源；失忆只来自药物（红线 5）。无冲突 |
| 《断层》 | 若诱因为玩家公开跨堡信息 | 恐慌推向闭守与排外，不产生开放，方向与既有纪律一致。无冲突 |
| 《除名》 | 玩家清除的演出方式 | **发现冲突，已改写为演出约束**，见 §4 |
| 《寂堡》 | 终止经权威渠道到来 | 居民至终不知道原因；残余应答不写成组织延续。无冲突 |

## 3. 《公议》的边界：约章法庭能追到哪一层

约章锁定的资格可以只用本地层公开证据完成——命令无合法来源、调度绕过正式手续——这些不需要任何居民拥有跨堡概念。

但约章法庭一旦运转，迟早遇到"这条命令到底从哪里来"。追到专线层面时：

- 对 IT 主任而言，专线是"那套系统"；命令来自系统，在本地认知内可以成立，约章可以要求"系统命令也须有可复核的落地手续"——这仍在本地层；
- 若继续追问"系统背后是什么"，即进入《共证》领域：跨堡网络成为待证事实，承担《共证》的暴露风险与资格门槛。

规则：**《公议》的锁定不要求、也不允许把跨堡层写进公开约章文本**。约章管本地裁决程序；跨堡真相是另一条路线的事。

## 4. 《除名》的冲突与改写

冲突：最直观的《除名》演出——公开审讯"来自另一座地堡的特工"——会向全体居民暴露他堡存在，直接违反核心设定；且 Silo 1 的一贯政策是彻底保密，跨堡追查本身就是它最害怕的暴露（the Graft §4.1 修订口径：追查暴露的首要事实是"这么多堡的背后是同一个指挥来源"）。

改写为演出约束：**玩家的清除只能以本地名义包装**——来历存疑、刑事罪名、精神异常、无声失踪。本地 IT 即使追到档案接缝（本地 IT 级暴露），其追查在对外口径上也必须保持本地化；连点级暴露正常玩法不可达，不展开。

这条约束反而强化了结局的叙事：玩家以一个不属于他的名义被抹除，没有人会知道他真正是什么。

## 5. 其他设定项核对

| 设定项 | 核对结论 |
| --- | --- |
| 不增设第四条胜利路线 | 两条中性结局明确为非胜利收束；五条失败均为硬失败或封闭延续。合规 |
| 不新增 stage | 全部台阶承接 `arrival / first_signal / archive_awakened` 之后的既有状态，无新 stage。合规 |
| 不创造原书之外的人名 | 十条线全部以功能位写作。合规 |
| 纯种地堡绝对排除 TIME | 《深闭》死后复制滑入与《无人裁决》失格边界均遵守；覆灭前全面忠诚动员写成亲手关闭《无人裁决》之门。合规 |
| 硬失败优先级与逃出群体检查 | 《寂堡》《遗忘》《断层》的判定顺序与例外（独立逃出群体改判尾声）全部按 P0 书写。合规 |
| 空转月份不推进阶段 | 《深闭》惯性滑入写成证人老去与体制巩固（世界状态），不写成阶段自动推进；终局判定仍读事实轮廓。合规 |
| 阶段推进必须由玩家实际执行动作触发 | 各线台阶均以成功行动或明确事件结果推进，无月份蒙太奇。合规 |

## 6. 冲突与留白清单

**发现并已解决的冲突（1 项）：**

1. 《除名》公开审讯演出与"居民不知他堡存在"及 Silo 1 保密政策冲突——已改写为本地名义包装的演出约束（§4）。

**留白（不在本轮裁决）：**

1. 《公议》约章法庭追查专线背后的权限与风险——已划边界（§3），具体台阶属《共证》领域，本轮不展开。
2. 《人治》的继承安排——刻意留白：继承空洞是本结局的性质，补上即漂移为《公议》。
3. 《寂堡》的残余应答——母题可用但不许诺，不写成可达结局内容。
4. 《除名》连点级暴露——正常玩法不可达，不展开为剧情。
5. 一切量化门槛（"成规模"、`W` 阈值、怀疑封顶值）——按结局体系规定留待 sim，剧情文件不发明数值。
