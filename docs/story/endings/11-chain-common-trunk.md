# 结局事件链 · 共同开局主干

> [返回总索引](../silo40-endings.md) · [机制底座](./10-chain-foundation.md) · [通用前提与共同开局](../good-endings/00-common.md)

十条线共用同一条开局主干。主干全部由**既有门控与既有事件**构成，不新增节点；分岔从 `archive_awakened` 之后开始。

## 1. 主干节点

| 节点 | 机制载体 | 触发/推进条件 | 现状 |
| --- | --- | --- | --- |
| 落脚 | 阶段 `arrival` | 开局即是（相对历 Y0M1） | 既有 |
| 首份本地材料 | 任一基础职务行动，材料作为伴随 Observation | 职务主结果成功 | 既有 |
| 第一道裂缝 | 阶段 `first_signal` | 首份有效本地 Observation（`observation:first_local`，已迁移） | 既有 |
| 材料离手 | 阶段 `archive_awakened` | 完成一次 Share Info（`player_action:action_share_info`） | 既有 |
| 世界锚点一 | `archive_truth_broadcast`（histories） | Y0M1 | 既有 |
| 世界锚点二 | `neighbor_silo_silence` → `network_data_cache` | Y2M1；缓存节点经 `event_triggered` 跟随 | 既有 |
| 世界锚点三 | `silo1_ultimatum` → `ultimatum_aftermath`（+3 月） | Y4M1 | 既有 |
| 清洗拉锯 | `archive_purge_order` → `purge_backlash`（+4 月） | `history_burden ≥ 0.12` | 既有 |
| 结算触发器 | `silo1_destroyed_signal` | 覆灭锚点到达（Y8M1）或结算条件满足；置 `silo1_destroyed` flag 即进仲裁 | 既有；**降级为结算触发器，不再是剧情节点** |

锚点节奏由三个剧情锚点标定（用户裁决）：**朱丽叶当上警长是中期事件，当选市长是末期事件，覆灭是结算事件**。锚点取 18 号正典链进度；覆灭结算后不留内容环节，仲裁紧随结算。锚点不是窗口长度；游戏不设时长窗口，终局事件发生即结算（ADR-0018）。

## 2. 主干上的第一次分岔

`archive_awakened` 之后，玩家的第一批选择决定本局进入哪条线的节点群。分岔不靠新机制，靠**完成键**：

- 继续向可核验者分享 → 进入《共证》感染节点群或《公议》规则断点节点群；
- 与工程/供给/医疗建立路线关系 → 进入《越岭》路线调查节点群；
- 控制发布节奏、维持低暴露 → 进入《无人裁决》维持节点群；
- 向 Mayor 圈层喂证 → 进入《人治》节点群；
- 什么都不推进 → 世界锚点照常推进，《深闭》惯性节点开始计数。

同一条主干也可以被失败线拦断：`archive_purge_order` 链是《遗忘》缓慢绞杀路径的既有起点；`silo1_ultimatum` 链是《寂堡》终止征兆的既有起点；玩家行动的痕迹累积是《除名》的既有压力源（victory_check 怀疑封顶）。

## 4. 主干纪律

1. 空转月份不推进阶段：主干只认成功行动与明确事件结果。
2. 世界锚点不被玩家改写：`neighbor_silo_silence` 与覆灭结算是权威事实与结算动作，玩家行动只能改变驻地对这些事实的处置，不能提前或阻止它们。
3. 主干不产生新结局主体：锚点事件的效果全部落在既有持久杠杆上。
4. 覆灭后不留内容环节：结算触发器点火即进仲裁，主干上不得挂任何"覆灭之后"的内容节点。
