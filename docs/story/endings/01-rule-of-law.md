# `RULE_OF_LAW`《公议》：把裁决锁进可复核的规则

> [返回总索引](../silo40-endings.md) · [通用前提与共同开局](../good-endings/00-common.md) · [《人治》](./02-personal-rule.md) · [十线交叉](./08-cross-lines.md)

## 1. 路线命题：为什么选它是有理据的

【项目外推】《公议》回答的问题是：当全量公开真相代价过高、个人统治又太脆弱时，驻地能不能**先把"怎样裁决"锁住，而不必先解决"什么是真的"**。

它的成就是程序性的：裁决依据从 IT 的隐蔽命令与个人正统性，转向可公开复核的规则。它的限度也是程序性的：居民得到的是一套可以引用的规则，不是一套能够理解的真相。

玩家选它而非《共证》的理据是真实的：

- 公开约章锁定**不需要外溢**，不需要把宿主暴露给 Silo 1 的可操作观察；
- 它保护的是所有人，包括还不知道真相的人——任意权力被约束，不依赖居民先完成认知觉醒；
- 在认知条件不成熟（居民连跨堡问题都还没有）的驻地，这可能是**可成就的最大制度成果**。

它诚实地只是中性：the Witness 的完成判据没有满足——终止链没有被公开拆除，跨堡真相没有进入公共领域，约章管得住本地裁决，管不到控制网另一端。选《公议》的玩家接受这一点：局部成就也是成就，程序是真相到来之前唯一能先站住的东西。

## 2. 剧情台阶

### L-1　起点处境：两面墙

共同开局三台阶（落脚、第一道裂缝、材料离手）之后，玩家手里有本地证据，但看见两面墙：

1. 外溢条件不成熟——受限渠道没有可靠接收方，或宿主承受不起暴露；《共证》的门槛在可见的未来够不到。
2. Judicial 当前附着于 IT——玩家手里的材料在程序上属于"违禁品"，公开即被收缴。

问题从"让所有人知道"收窄为"先约束命令怎样被裁决"。这不是降格，而是换战场：约章路线不需要居民先相信跨堡真相，只需要足够多的人在意**命令有没有合法来源**。

### L-2　转折一：找规则断点，不找个人罪行

玩家的调查目标从暗权本身转向命令链断点：Judicial 的执法调度缺本地合法来源、事后补签倒填日期、IT 以非正式渠道调动物资与人员。这类断点的价值在于：**它们不需要跨堡知识就能核验**，任何在意程序的本地人都能查。

第一位接收者因此不是开放派系代表，而是一个还在意程序本身的 Judicial 人员——他未必怀疑体制，只是无法忍受手续不全的命令。

**玩家抉择 L-A：指向个人责任，还是指向规则漏洞。**

- 指向个人责任：容易动员，容易让某个 IT 执行人成为替罪者；但清洗个人不改变结构，且容易滑向《人治》的前奏（"换好人"逻辑）。
- 指向规则漏洞：更难传播，成果却是制度性的——问题被写成"什么样的命令不可执行"，而不是"谁该下台"。

预期走向采用后者。

### L-3　转折二：威势不降，约章无门

【机制对接】约章锁定的资格前提是 IT 幕后威势 `W` 已不足以封锁路线（见 [12 结局体系](../../research/12-ending-system-design.md) §4.1）。Judicial 不会在 IT 仍能随手调度法警的时候附着约章。

玩家必须让**执行失败**与 **IT 直接调度**成为关键联盟可核验的事实：Police 发现自己被当工具使用的那一次、Judicial 发现自己被绕过的那一份、Mayor 发现正式命令被架空的那一回。这一步与《共证》共用技术（证据线、责任链），但喂给制度内渠道，不做公共扩散。

**玩家抉择 L-B：材料喂给舆论，还是喂给制度。**

- 喂给舆论：快，但舆论不能完成锁定，且提前暴露意图，招来 Protocol 处置。
- 喂给 Judicial 与 Mayor 圈层：慢，保住锁定通道；代价是材料暂时只在少数人手里，玩家必须信任制度内还有人。

预期走向采用后者。

### L-4　关键转折：约章不是玩家的文件

约章文本必须从本地人手里长出来：Judicial 人员引用旧规程，部门代表争论条款，Mayor 一方核算执行成本。玩家提供证据底座与案例，不提供草稿。

**玩家抉择 L-C：替他们起草，还是让他们逐条争吵。**

- 替他们起草：快，但约章带上玩家烙印；玩家一旦暴露，约章随之陪葬。
- 让他们逐条争吵：慢，条款会有妥协与缺陷；但约章有本地主人，能在玩家缺席后存续。

预期走向采用后者。the Witness 的完成判据二（真相有本地承接者）在这里以制度形式出现：**规则也必须有不由玩家直接控制的承接者**。

### L-5　玩家决断时刻：锁定日

Judicial 在公开证据 `Q` 与独立公共事实支持下宣告附着公开约章；IT 的最后反扑压缩窗口——选择性执法、收缴证物、指控约章支持者。

**玩家抉择 L-D：接受一个 IT 能接受的约章版本，还是坚持不可逆锁定。**

- 妥协版本：锁定完成但留有撤销后门，未来可能回摆为《深闭》或《人治》。
- 不可逆锁定：证据托管、证人到场、签署程序完整；代价是 IT 当场翻脸的风险，玩家要用剩余关系与威望为锁定程序争取那一段时间。

预期走向采用后者。这是本线必须由玩家决断的时刻：约章的价值恰在于它不能被单方收回，而让"不可逆"成立的那几分钟，要靠玩家亲自去守。

## 3. 终局那一刻

第一次按约章裁决的案件。有人把一份过去会被默默执行的旧命令递上去；裁决者引用约章与公开证据，而不是等待上级指示。IT 人物仍保有形式职位，但它的隐蔽调度不再能进入执行——法警看着调度单，第一次问"依据哪一条"。

玩家坐在旁听席，不在裁决席。

终局之后有一句诚实的余波，必须写出来：约章法庭迟早会遇到一个它回答不了的问题——**"这条命令到底从哪里来"**——而答案通向专线与控制网。《公议》种下了《共证》的问题，但不回答它。这是它的成就，也是它的边界；本结局停在这个问题被第一次提出之前或刚被提出之时，不把回答写进来。

## 4. 资格对齐与失格边界

| 局面 | 判定 |
| --- | --- |
| 约章锁定＋《共证》的广泛公共理解同时成立 | 两候选竞争；同分时 `INFORMATION` 优先，约章作为制度尾声 |
| Judicial 未附着约章而附着高正统性 Mayor | 进入《人治》资格；两种收束互斥，以实际附着为准 |
| `W` 仍高 | 两者均不成立；继续模拟，或按实际权力状态滑向《深闭》 |
| 锁定完成后驻地遭重置 | 《遗忘》；硬失败护栏先于制度成就 |
| 只有旧计数式"信息公开触发"、没有稳定公共事实 | 不构成锁定资格，继续模拟 |

## 5. 机制接口

- `Judicial.PactLocked / PublicEvidenceQ / IndependentPublicFacts / Regime`、幕后威势 `W`；Mayor 更替或普通威势回升不能随意撤销已锁定的约章。
- 玩家行动沿用既有门控：Gather／Share Info、Build Connection、STATION_INTEL；本线不新增行动、不新增 stage。
- 玩家、派系、具名人物与 Silo 1 仍按统一仲裁参与；公开约章本身不成为投票主体。

## 6. 设定自检

《公议》全程可以只用本地层公开证据完成锁定，不需要任何跨堡往来，与"地堡之间互不往来"无冲突。唯一边界：若约章法庭开始追查命令来源至专线层面，即进入《共证》领域并承担其暴露风险——该边界在[设定自检](./09-setting-self-check.md)中登记。

## 7. 本线需要原创的部分

公开约章与正式权力有原著制度底座；《公议》的剧情台阶——规则断点调查、制度内喂证、约章的本地起草、锁定日攻防，以及"约章种下自己回答不了的问题"的终局余波——均为本项目原创。
