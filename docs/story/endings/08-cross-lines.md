# 十线交叉与互相拆台

> [返回总索引](../silo40-endings.md) · [好结局三线交叉](../good-endings/04-crossovers.md) · [结局体系](../../research/12-ending-system-design.md)

本文把十条结局线放进同一张图：两条中性、五条失败，与三条好结局之间的帮助、拆台与承接关系。好结局三线内部的交叉见[好结局分册](../good-endings/04-crossovers.md)，本文不重复，只补上其余七线与它们的咬合。

## 1. 一张图：十线在同一棵问题树上

十个结局不是十个平行世界，而是同一棵问题树的分支。这棵树恰好就是结局体系 P0→P1→P2/P3 的叙事版：

```text
终局时——
还有可确认的幸存社会吗？
├─ 没有 ────────────────────────────→ 《寂堡》(P0.1)
└─ 有
   它被格式化了吗（减口＋抹忆＋清档完成）？
   ├─ 是，且无独立逃出群体 ──────────→ 《遗忘》(P0.2)
   └─ 否
      社会维存能力已不可逆崩溃？
      ├─ 是，且无独立逃出群体 ────────→ 《断层》(P0.3)
      └─ 否
         玩家还能继续任务吗？
         ├─ 不能（身份暴露封顶）──────→ 《除名》(P0.4)
         └─ 能
            哪些收敛事实成立？（资格先于加权）
            ├─ 实际逃离＋群体存续 ────→ 《越岭》候选
            ├─ 活链外溢＋外部再复制 ──→ 《共证》候选
            ├─ Silo 1 覆灭＋覆灭前开放快照 → 《无人裁决》候选
            ├─ 公开约章锁定 ──────────→ 《公议》候选
            ├─ 低 W＋Mayor 正统性＋Judicial 附着 → 《人治》候选
            └─ 均不成立而封闭主导 ────→ 《深闭》
            （合格候选之间加权，同分按固定顺序裁决）
```

剧情写作必须尊重这棵树：一局不能在没有幸存社会时"主要讲《共证》"，也不能在重置完成后用信息公开的高分翻案。

## 2. 两条中性结局：同一个收敛条件的制度／个人分叉

《公议》与《人治》共享同一个前提结构——**低 `W` 之后，Judicial 必须附着某个东西**——但附着对象互斥：

| | 《公议》 | 《人治》 |
| --- | --- | --- |
| Judicial 附着 | 公开约章 | Mayor 个人 |
| 社会得到的 | 可引用的规则 | 可接受的统治者 |
| 玩家让渡的 | 真相的公共化（只锁程序） | 秩序的制度寿命（系于一人） |
| 内在未竟 | 约章法庭终将追问命令来源（通向《共证》的问题） | 继承空洞（更替即回摆风险） |

两者因此是彼此最近的竞争者：同一局里，玩家把证据喂给制度还是喂给 Mayor 圈层（抉择 L-B 与 P-B），决定本局向哪一边收敛。两者又共同构成三条胜利路线未达成时的**体面收束层**——它们不是"失败得好看一点"，而是另一种成立的政治秩序：程序先于认知，或人格先于程序。

## 3. 五种死法：失败结局各自终结的是什么

| 结局 | 终结的是什么 | 一句话 |
| --- | --- | --- |
| 《深闭》 | 任务的意义 | 什么都没改变，驻地照常运转 |
| 《遗忘》 | 任务的记忆 | 历史被格式化，真相失去全部接收者 |
| 《断层》 | 任务的宿主 | 反抗撕碎了驻地维存本身 |
| 《除名》 | 任务的执行者 | 玩家被抹除，驻地可能照常 |
| 《寂堡》 | 任务的一切 | 没有人剩下 |

五条失败线因此互不重叠：《遗忘》是外力格式化，《断层》是自我撕碎；《除名》只结束玩家，《寂堡》结束所有人；《深闭》谁都不结束，只是让任务失去意义。任何一局的具体终局，应当能说出它死在哪一种。

## 4. 每条线的特征滑坡（从哪来，往哪去）

| 路线 | 最可能滑入它的局面 | 它最可能滑向的结局 |
| --- | --- | --- |
| 《共证》 | 《公议》拒绝外溢的保守版；《无人裁决》的宿主保得太好而从未外溢 | 宿主暴露→《遗忘》或《寂堡》；只成本地真相→《公议》或停滞 |
| 《越岭》 | 《断层》边缘找到了路；《无人裁决》窗口关闭前的最后一搏 | 无组织出走→《断层》；只走少数人→原驻地按实际状态判 |
| 《无人裁决》 | 《共证》宿主活到覆灭且思潮合格 | 思潮闸失败→《人治》或《深闭》；驻地先被毁→《寂堡》 |
| 《公议》 | 《共证》的证据底座＋外溢不可行 | 锁定失败→《深闭》；Mayor 截胡→《人治》；重置→《遗忘》 |
| 《人治》 | 《公议》资格失败但 Mayor 正统性高 | 更替回摆→《深闭》或《断层》；`W` 回升→《深闭》 |
| 《深闭》 | 一切路线的默认底色 | （它是终点，不再滑向别处） |
| 《遗忘》 | 《共证》外溢暴露；《越岭》无路径叛乱；《公议》锁定被打断 | 若逃出群体已先成立→改判《越岭》尾声 |
| 《断层》 | 《越岭》点火无路径；部门战争失控 | 无人幸存→《寂堡》 |
| 《除名》 | 任何路线的暴露积累 | 与任何驻地结局同局，驻地结果只作尾声 |
| 《寂堡》 | 《断层》终点；宿主在外溢前被毁；驻地先于 Silo 1 覆灭 | （它是终点） |

## 5. 十条线争夺的六种共同资产

好结局分册列出四种（证据与接收者、活着的开放人口、组织能力、时间与低暴露窗口）。七线补齐后，完整清单是六种：

1. **证据与接收者**：《共证》《公议》《人治》的底座；《遗忘》的直接清除对象。
2. **活着的开放人口**：《共证》的复制者、《越岭》的逃出者、《无人裁决》的覆灭前主流；人一走，三线同时变薄。
3. **组织能力**：撤离、复制、制度建设共用；低凝聚力只能制造《断层》，不能制造任何胜利。
4. **时间与低暴露窗口**：等待同时是《无人裁决》的资源与《遗忘》《除名》的风险来源。
5. **维生基础**：新增——《断层》《寂堡》的赌注。所有路线都住在它上面；任何路线的激进行动都在损耗它。
6. **玩家的身份盾**：新增——《除名》的赌注。每次深度行动都在盾上留痕；身份安全与任务进度方向相反。

同一份资源在同一时刻只能主要供给一条线——这就是十线不能平行的原因。

## 6. 四个高密度碰撞局面

**甲：锁定日三方挤压。** 约章锁定日、IT 最后反扑、撤离窗口同时打开。玩家的关系与行动能力只够守一边：守锁定→《公议》（但错过撤离，开放人口留下承受反扑）；守撤离→《越岭》（约章流产，制度成果归零）；两头都守→大概率两头都破，滑向《遗忘》。

**乙：收束分叉夜。** `W` 已低，Judicial 待附着：约章力量与 Mayor 圈层同时伸手。玩家把最后一份责任链证据交给谁，决定《公议》还是《人治》；若两边都不交，Judicial 悬空，秩序滑回《深闭》。

**丙：覆灭前夜四角拉扯。**（在好结局三线碰撞的基础上加入失败侧的拉力）Silo 1 衰弱、外溢异常流量已被注意、叛乱上升、覆灭前公开质询在即。此时《寂堡》的拉力真实存在：Silo 1 可能在覆灭前先处置驻地。玩家保质询（《无人裁决》）、保外溢（《共证》）、保撤离（《越岭》），每一个选择都同时是对另外两个的放弃，且都可能在等来覆灭之前先等来终止。

**丁：封顶前夜的遗产。** 玩家怀疑封顶逼近，而他种下的东西即将结果。抢最后一击（赌其他结局先成立）还是保护性拆解（《除名》成立但接收者活）？若选择拆解，驻地此后仍可能走向《公议》《人治》甚至《共证》——但主结局已是《除名》，那些只是尾声。这是"任务可以失败而世界可以继续"的唯一演出位。

## 7. 优先级与同分顺序的叙事含义

- **P0 的内部顺序（寂堡→遗忘→断层→除名）意味着：越硬的事实越先描述终局。** 社会没了，就不谈记忆；记忆没了，就不谈维存；维存没了，就不谈玩家。剧情写作不得倒叙这份残酷。
- **同分顺序（INFORMATION→REBELLION→RULE_OF_LAW→TIME→PERSONAL_RULE→EXCLUSIONIST）意味着：已经完成的改变，优先于单纯的等待。** 一局同时有约章锁定与公共真相时，叙事上必须让《共证》站主位、约章作尾声，不能反过来。
- **纯种地堡绝对排除 TIME** 在剧情上的读法：覆灭前夜的全面忠诚动员（抉择 T-E 的第一项）不是"稳一点再说"，而是亲手关掉《无人裁决》的门——此后只能在《人治》《深闭》等实际收束里落座。

## 8. 与判定体系的对齐声明

本文所有交叉关系只描述**事实之间的承接与互斥**，不引入新的加权、新的主体或新的触发器。资格先于权重、硬失败优先、候选互斥、四类主体仲裁、主结局唯一——全部沿用[结局体系](../../research/12-ending-system-design.md)，一条未破。
