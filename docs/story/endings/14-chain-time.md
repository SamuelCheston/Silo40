# 结局事件链 · `TIME`《无人裁决》

> [返回总索引](../silo40-endings.md) · [机制底座](./10-chain-foundation.md) · [剧情台阶](../good-endings/03-time.md)

链条形态：**长期维持 → 覆灭前夕抉择 → 覆灭结算 → 快照仲裁**。本线的戏在"等待"，但等待不是空转：存续与开放都要靠实际行动维持。覆灭是结算动作：覆灭锚点到达或结算条件满足即视为覆灭发生，直接进仲裁，其后不留内容环节。

## 2. 覆灭前夕三选一的机制投影

| 选择完成键 | 立即效果（封闭集内可表达部分） | 资格后果 |
| --- | --- | --- |
| 忠诚动员 | `rebellion −0.05`、`panic_value −0.04`（sim 校准起点） | 覆灭前夕为纯种地堡思潮：《无人裁决》绝对失格；按实际权力状态落入《人治》或《深闭》 |
| 全面暴乱 | `rebellion +0.15`、`floor_stability_delta −0.1`（sim 校准起点） | 维存受损；按社会状态进入《断层》判定或继续模拟 |
| 维持公开质询 | `history_burden +0.03`（sim 校准起点） | 开放快照合格的叙事前提；实际资格由覆灭前夕快照判定 |

快照与思潮闸已由机制底座实现：`silo1_destroyed` 落地的瞬间取得覆灭前夕思潮快照，人口加权的 cohort 思潮喂给 TIME 开放闸。三选一若需影响 cohort 思潮，走机制底座新增的 `cohort_ideology_delta` 内容写入通路（数值为 sim 校准起点）；快照定格之后的一切变化不再追溯资格。

## 4. 超时与失败结算

- 本线没有独立超时：终局时钟是覆灭结算（覆灭锚点到达或结算条件满足），全局唯一。
- 覆灭后不留内容环节：仲裁紧随结算，本线在结算前必须完成全部节点；`pre_fall_choice` 因此设兜底强制拉起。
- 失败不是"没等到"，而是"等到了但资格不合格"或"没等到（驻地先被处置）"。

## 5. 与结局判定的对接

- 机制底座已实现：`victory_check` 对覆灭触发只**请求终局评估**；仲裁读取覆灭前夕快照与开放闸（纯种地堡绝对排除）。
- `open_discourse_milestone` 与 `pre_fall_choice` 的完成键是快照判定的**叙事输入**：快照审计可引用这两个键作为开放建设的证据链。
