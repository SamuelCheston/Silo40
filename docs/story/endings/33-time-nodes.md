# 《无人裁决》事件链 · 完整节点设计

> 性质：**内容节点设计文档**。沿用 [26《公议》](./26-rule-of-law-nodes.md)／[30《人治》](./30-personal-rule-nodes.md) 的格式与纪律：只写设计，数值一律 `TODO(balance)`，依赖未落地机制处只留注释。
> 口径：覆灭是**结算事件**，不是有日期的世界事件——没有"第几年 1 号一定倒"的时间表；窗口走完或结算条件满足即视为覆灭发生，直接进仲裁，覆灭后不留内容窗口（机制底座 §3 时序纪律）。资格读引擎的覆灭前夕思潮快照，内容不重算思潮。

## 0. 全线总览

```text
共同开局（落脚／裂缝／材料离手）
        │
        ▼
  长期维持（既有行动与事件：职务、STATION_TRADE、grief_release_ritual…）
   │   熬＝维持存续＋把开放思潮保持到结算瞬间；不是等，是熬
   ▼
  A-1 开放表达里程碑（open_discourse_milestone，REPEATABLE 心跳）
   ▼ 相对 Y7 起（或 Y7M10 兜底强制拉起）
  T-1 覆灭前夕抉择卡（pre_fall_choice，三选一）
   ├── 忠诚动员 → 快照判纯种：本线绝对失格（落《深闭》死后复制或《人治》）
   ├── 全面暴乱 → 维存受损（按社会状态入《断层》判定或继续模拟）
   └── 维持公开质询 → 开放快照的叙事前提（资格仍由快照判定）
   ▼
  覆灭结算（silo1_destroyed_signal：窗口走完；引擎截取思潮快照）
   ▼
  仲裁读快照 → TIME 候选（OpenQualified）或《深闭》死后复制（纯种）

并行全程：三条致死来路的规避与反制（终止／物理／整肃，§2）
```

顺序：维持（全程）→ A-1 → T-1 → 结算。并行：致死来路的反制全程进行；《共证》《越岭》候选在结算时与《无人裁决》同池竞争（§6）。

## 1. 资格事实（现有代码口径，先看清再动笔）

- **覆灭**：`silo1_destroyed` 为真。两个写入路径都在引擎侧截取快照：`world_flag_set` 与 `silo_flag_set`（[content_events.go](../../../internal/engine/content_events.go) `writeWorldFlag`／`writeSiloFlag` → `takePreFallIdeologySnapshot`），首次置真时截取一次，其后不变。
- **硬条件**：覆灭前夕思潮快照 `OpenQualified`＝人口加权亲外 > 0 且 ≥ 忠诚（纯种地堡思潮＝忠诚主导，一律不合格）。快照读 **Cohort 人口加权思潮真源**，不是部门派生视图。
- **消费快照，不重算**：本线一切节点不得自行聚合思潮判定资格；仲裁读 `station.PreFallSnapshot`（既有），内容节点只是快照判定的叙事输入。
- **定格纪律**：快照在覆灭落地的瞬间定格；其后的恐慌、宣传、叛乱不追溯资格。

## 2. 覆灭的来路：熬什么、怎么熬

覆灭没有时间表，但有来路。结算时钟（窗口走完）只是其中一条；其余来路会在时钟走完之前杀死驻地，把《无人裁决》变成《寂堡》或《遗忘》。**玩家不是等，是熬**：熬意味着期间维持存续、压住致死来路、把开放保持到结算瞬间。

| 来路 | 机制事实 | 对玩家意味着什么 | 覆灭前能做什么 | 熬不过的下场 |
| --- | --- | --- | --- | --- |
| **结算时钟** | `silo1_destroyed_signal`（相对 Y8M1 窗口走完，既有 histories） | 唯一通向《无人裁决》的来路：1 号自己的衰亡在结算时刻落地 | 维持到那一天：存续、开放、不被除名 | —（这就是"熬到头"） |
| **终止（远程）** | `termination_channel_test`（Y5 起）→ `termination_release`（DEATH 事实，读 `network_jammed` 守卫） | 1 号在死前可能先关掉你：偏离招来处置 | 渠道反制：值夜检修动作 `TERMINATION_CHANNEL_JAM` → `termination_channel_disrupted` 写 `network_jammed`（只免疫这一条渠道）；压低可见偏离 | 《寂堡》（P0.1）；反制只挡远程，物理渠道照旧 |
| **物理（投送）** | `strike_reconnaissance`（Y6 起、rebellion ≥ 0.8）→ `bombing_terminal`（+3 月，DEATH 事实） | 高叛乱喂大侦察，侦察引来投送——物理渠道基本无解 | 把叛乱压在 0.8 下（时点纪律与《共证》隐匿簇同口径）；不借镇压点火 | 《寂堡》（P0.1） |
| **整肃（本地执行）** | `silo1_purge_omen`（通牒后、rebellion ≥ 0.8）→ `silo1_purge_execution`（现为零效果钩子） | 1 号命令堡内 IT/医务执行投药、清档、减口——驻地活着，但记忆与人口被削 | 反制接触（未绑定）；分发托管、保住接收者；压叛乱断其触发 | 当前不直接致死；削弱的宿主更易死于其他来路，公共事实与开放思潮被削则快照失格 |
| **引擎内爆** | safeguard_risk ≥ 1.0 或人口 ≤ 0（`victory_check`） | 过度干预或维生耗尽 | 控制干预强度、维持供给与楼层 | 《寂堡》（P0.1） |

**熬成《深闭》**：熬到了覆灭，但快照是纯种地堡思潮（忠诚动员或长期封闭硬化）→ TIME 失格；覆灭使 `exclusionistEligible` 成立（死后复制），按加权落《深闭》——"以后只能靠自己严守旧规"。
**熬成《寂堡》**：任一致死来路在结算时钟前落地且无存续逃出群体。
**熬的代价**：为保宿主而压低一切风险动作，可能让《共证》活链停在浅层、《越岭》窗口关闭（04-crossovers §2 既有口径）——这是选择，不是损失。

## 3. 节点簇

### A-1 开放表达里程碑（open_discourse_milestone）

| 项 | 内容 |
| --- | --- |
| 触发条件 | `professionIdeologyGteCount("pro_foreign", 0.55, 2)`（≥2 个部门的派生亲外思潮 ≥0.55，sim 校准起点）；`REPEATABLE`，冷却 6 月（sim 校准起点） |
| 含义 | 开放思潮取得公共表达的里程碑。读的是部门派生视图（cohort 真源的投影）——资格仍读快照真源，本节点只是建设过程的可读心跳（抉择 T-A／T-B 的日常层） |
| 效果 | `history_burden +0.02`（sim 校准起点）：开放讨论本身成为驻地历史的一部分 |
| 产出完成键 | `special:open_discourse_milestone`（计数键） |

### T-1 覆灭前夕抉择卡（pre_fall_choice）

| 项 | 内容 |
| --- | --- |
| 形态 | 抉择时刻节点（special，ONCE）＋三个玩家选择行动。节点本身是"最后时刻到来"的世界事实（ADR-0010：时刻不由玩家批准），选择留给玩家 |
| 触发条件 | `all(timestampAtOrAfter(129,1), eventTriggered("special","open_discourse_milestone"))`（相对 Y7 起＋里程碑已亮）；**兜底**：`deadline_year 129 / deadline_month 10`（相对 Y7M10）——若事件链未唤起，到期强制拉起（硬伤 #3 兜底机制）：覆灭前夕的抉择不可被前置时序杀死 |
| 效果 | 无机制效果（纯时刻节点，`apply` 返回空） |
| 产出完成键 | `special:pre_fall_choice` |
| 玩家反馈 | 封闭派系要求暂停全部外部讨论等待下一道命令；开放派系要求按原计划举行公开核验与质询。双方都真心相信自己在拯救驻地（抉择 T-E） |

### T-2 三选一（pre_fall_loyalty_mobilization / pre_fall_total_riot / pre_fall_open_inquiry）

| 项 | 内容 |
| --- | --- |
| 形态 | 三个 `PLAYER_EVENT` 内容行动，`event_completed special:pre_fall_choice` 后解锁 |
| 忠诚动员 | `rebellion −0.05`、全部门 `panic_value −0.04`、`cohortIdeologyDelta("loyalty", +0.10)`（sim 校准起点）：以全面忠诚换秩序。**资格后果**：覆灭前夕快照倾向纯种，《无人裁决》绝对失格；按实际权力状态落《深闭》死后复制或《人治》 |
| 全面暴乱 | `rebellion +0.15`、`floorStabilityDelta(全部楼层, −0.1)`（sim 校准起点）：以暴乱证明开放。**资格后果**：维存受损；社会维存不可逆崩溃且无逃出群体时入《断层》判定，否则继续模拟 |
| 维持公开质询 | `history_burden +0.03`（sim 校准起点）：以既有关系、威望与部门协作维持最低秩序，同时让公开质询照常。**资格后果**：开放快照合格的叙事前提；实际资格由快照判定，不由本键授予 |
| 未选择 | 时刻卡点亮而玩家未选：快照按当时的思潮事实定格——不选择也是一种答案，下落同"维持现状"（不悬空） |
| 已知缺口 | 门控无否定谓词：三选一后兄弟选择不能隐藏；下游只读各键事实（与《公议》《人治》共用缺口） |

## 4. 维持层：熬的日常（不新增节点）

维持不是节点，是既有行动与事件的持续使用（14 分册 §1 维持动作行）：

- **存续**：职务行动、`STATION_TRADE`、资源与楼层管理；危机后 `grief_release_ritual` 减压。
- **开放**：有限分享、公开讨论、`pro_foreign_awakening` 等既有思潮事件；亲外写成求证习惯而不是新教条（剧情台阶 T-2：保留不确定性）。
- **自身**：怀疑度管理——玩家必须在覆灭前不被除名（《除名》是 P0.4，先于一切历史收束）。
- **放弃**：高风险秘密行动与外溢准备（T-D 预期走向：只在不牺牲本地条件时进行外部操作）；不借镇压点火（叛乱 ≥0.8 喂大侦察与整肃）。

## 5. 与《共证》的差别与重叠判定（必须说清）

- **行为差别**：《共证》是**主动把真相送出去**（跨部门公共事实＋外溢评分）；《无人裁决》是**什么都不做地活下来**（维持存续＋把开放保持到结算瞬间）。一个是送，一个是熬。
- **资格不互相顶替**：《共证》读部门信念层覆盖（`allDepartmentsHoldFragments`），《无人裁决》读覆灭事实＋cohort 思潮快照——两份不同的事实，谁也不产生谁。部门信念覆盖不生成快照，快照也不生成信念覆盖。
- **重叠时的判定**（04-crossovers §1／§3-D 既有裁决）：宿主活到覆灭且快照合格、同时活链与公共事实也成立时，两候选**同池竞争**：P2 四类主体加权，同分按 P3 既定序 INFORMATION 先于 TIME。外溢评分项（`PlayerPerSpilloverSilo`）只喂 INFORMATION——主动送出去的局自然倾向《共证》，纯熬的局没有这份加权。
- **快照只被 TIME 消费**：《共证》资格不读快照；快照定格后的一切变化不追溯任何线的资格。

## 6. 顺序、并行与互斥收口

- **顺序**：维持（全程）→ A-1 → T-1（兜底保底）→ T-2 三选一 → 覆灭结算。
- **并行**：致死来路的反制全程并行；《共证》《越岭》建设可同时进行（同池竞争）。
- **收口点一 · 忠诚动员**（线内抉择）：本线绝对失格；落《深闭》死后复制或（资格成立时）《人治》。
- **收口点二 · 宿主先毁**：任一致死来路在结算前落地 → 按 P0 口径结算（《寂堡》《遗忘》《断层》），本线失去驻地前提。
- **收口点三 · 快照失格**：熬到覆灭但纯种思潮 → 《深闭》（覆灭使死后复制合格）。
- **终局时钟**：覆灭结算是全局唯一的终局时钟；本线没有独立超时，`pre_fall_choice` 的兜底保证抉择时刻不被时序杀死。
